Objectifs d'apprentissage — Semaine 7 (LPPO Syntaxe)
  • Distinguer sans équivoque la syntaxe des termes (qui désignent des objets) et des formules (qui ont une valeur de vérité).
  • Comprendre la signature {{ \mathcal{L} = \langle \mathcal{F}, \mathcal{P}, \text{ar} \rangle }} : constantes, fonctions, prédicats et arités.
  • Maîtriser la construction inductive des termes {{ \mathcal{T}_k(\mathcal{F}, \mathcal{V}) }}.
  • Calculer rigoureusement l'ensemble des variables libres {{ Free(F) }} d'une formule arbitraire.
  • Déterminer la portée d'un quantificateur et lier chaque occurrence de variable à son lieur.
  • Effectuer des renommages alphabétiques ({{ lpha }}-conversion) sans jamais introduire de capture de variable.

1. La Distinction Capitale : Termes vs Formules

Définition 7.1 — Terme vs Formule
  • Un Terme : Désigne un élément du domaine de discours (un nombre, une personne, une liste). Il ne possède PAS de valeur de vérité ! On ne peut pas dire qu'un terme est « vrai » ou « faux ».
    • Exemples : {{ x }}, {{ 0 }}, {{ s(0) }}, {{ f(x, y) }}, {{ \text{pere}(\text{jean}) }}.
  • Une Formule : Exprime une assertion sur les objets. Elle est susceptible d'être vraie ou fausse une fois interprétée.
    • Exemples : {{ P(x) }}, {{ x = y }}, {{ R(f(x), c) }}, {{ \forall x \exists y P(x, y) }}.
Pourquoi je me trompe ? — Confondre f(x) et P(x)

Erreur très fréquente : Écrire {{ f(x) \land P(y) }} ou penser que {{ P(x) }} peut être un argument d'une fonction comme {{ f(P(x)) }}.

Règle absolue : Une fonction {{ f }} prend en argument des termes et produit un terme. Un prédicat {{ P }} prend en argument des termes et produit une formule atomique. Les connecteurs ({{ \land, \lor, \Rightarrow }}) ne relient QUE des formules !

2. Définition Inductive de l'Ensemble des Termes ({{ \mathcal{T}_k }})

Définition 7.2 — Les Niveaux Inductifs {{ \mathcal{T}_k }}

Soit {{ \mathcal{V} }} les variables, et {{ \mathcal{F} }} les fonctions (les constantes étant des fonctions d'arité 0). L'ensemble des termes est construit par strates :

  • {{ \mathcal{T}_0 = \mathcal{V} \cup \mathcal{F}_0 }} (l'ensemble des variables et des constantes).
  • {{ \mathcal{T}_{k+1} = \mathcal{T}_k \cup \{ f(t_1, \dots, t_n) \mid f \in \mathcal{F}_n \text{ et } t_1, \dots, t_n \in \mathcal{T}_k \} }}.
  • L'ensemble complet des termes est {{ \mathcal{T}(\mathcal{F}, \mathcal{V}) = \bigcup_{k=0}^\infty \mathcal{T}_k }}.

3. Variables Libres, Variables Liées et Portée

Définition 7.3 — Calcul Récursif de {{ Free(F) }}

Pour déterminer quelles variables sont libres dans une formule, on applique les règles récursives :

  • {{ Free(P(t_1, \dots, t_n)) = \text{Var}(t_1) \cup \dots \cup \text{Var}(t_n) }} ;
  • {{ Free(\neg F) = Free(F) }} ;
  • {{ Free(F_1 \land F_2) = Free(F_1) \cup Free(F_2) }} (de même pour {{ \lor, \Rightarrow, \Leftrightarrow }}) ;
  • {{ Free(\forall x F) = Free(F) \setminus \{x\} }} (le quantificateur lie la variable {{ x }}) ;
  • {{ Free(\exists x F) = Free(F) \setminus \{x\} }}.

Une formule {{ F }} est dite close (ou énoncé / sentence) si {{ Free(F) = \emptyset }}.
