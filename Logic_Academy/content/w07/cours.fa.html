۱. تفاوت بنیادین: ترم در برابر فرمول

تعریف ۷.۱ — ترم (Terme) در برابر فرمول (Formule)
  • ترم: به یک عنصر یا شیء از جهان اشاره دارد (یک عدد، یک انسان، یک تابع). ترم هرگز مقدار درستی (۰ یا ۱) ندارد! نمی‌توان گفت ترم {{ f(x) }} درست است یا نادرست.
    • مثال‌ها : {{ x }}, {{ 0 }}, {{ s(x) }}, {{ f(a, g(y)) }}.
  • فرمول: یک حکم یا گزاره خبری درباره اشیاء بیان می‌کند که پس از ارزیابی دارای مقدار درستی (درست یا غلط) خواهد بود.
    • مثال‌ها : {{ P(x) }}, {{ x = y }}, {{ Q(f(x), a) }}, {{ \forall x P(x) }}.
