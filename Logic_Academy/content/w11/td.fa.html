تمرین ۴۰ — لیست‌ها در پرولوگ و یکسان‌سازی (صفحه ۲۳)

پاسخ تشریحی سؤال ۱
  1. ?- [a, b, c] = [X]. {{ \implies }} شکست (false) چون تعداد اعضا همخوانی ندارد.
  2. ?- [a, b, c] = [X, Y, Z]. {{ \implies }} موفقیت: X = a, Y = b, Z = c.
  3. ?- [a, b, c] = [X | Y]. {{ \implies }} موفقیت: X = a و Y = [b, c]. (سر لیست {{ X }} و دم لیست {{ Y }}).
  4. ?- append(X, [c, Y], [a, b, c, d]). {{ \implies }} موفقیت: X = [a, b] و Y = d.
  5. ?- append(X, Y, [a, b, c, d]). {{ \implies }} با زدن کلید ; تمام ۵ افراز ممکن لیست تولید می‌شود.

تمرین ۴۱ — فرم‌های نرمال در LPPO (صفحه ۲۴)

مراحل گام‌به‌گام اسکولم‌سازی و تفکیک

فرمول داده‌شده: $F = eg ( ( orall x(p(f(x)) \implies eg q(x))) \implies eg \exists x (p(f(x)) \land q(x)) )$.

  • مرحله ۱ (NNF): نقیض به داخل برده می‌شود: $( orall x( eg p(f(x)) \lor eg q(x))) \land \exists x (p(f(x)) \land q(x))$.
  • مرحله ۲ (تغییر نام و پیشوندی): متغیر سور وجودی را به {{ y }} تغییر می‌دهیم و سورها را بیرون می‌کشیم: $ orall x \exists y [( eg p(f(x)) \lor eg q(x)) \land p(f(y)) \land q(y)]$.
  • مرحله ۳ (اسکولم‌سازی): چون {{ \exists y }} بعد از {{ orall x }} است، متغیر {{ y }} با تابع اسکولم {{ g(x) }} جایگزین می‌شود.
  • مرحله ۴ (بندها): سه بند {{ C_1, C_2, C_3 }} استخراج می‌گردد.
  • مرحله ۵ (تفکیک): با تفکیک متوالی، بند پوچ {{ \Box }} حاصل می‌شود؛ بنابراین فرمول {{ F }} ناسازگار (Insatisfiable) است.
