Exercice 40 — Listes en Prolog : Unification et Prédicats (p. 23)

Question 1 : Réponses aux requêtes d'unification
  1. ?- [a, b, c] = [X]. {{ \implies }} false (Échec) car le membre de gauche a 3 éléments et celui de droite un seul.
  2. ?- [a, b, c] = [X, Y, Z]. {{ \implies }} Succès : X = a, Y = b, Z = c.
  3. ?- [a, b, c] = [X | Y]. {{ \implies }} Succès : X = a, Y = [b, c]. (Tête = premier élément, Queue = liste des éléments suivants).
  4. ?- [a, [b, c], d] = [X, Y, Z]. {{ \implies }} Succès : X = a, Y = [b, c], Z = d.
  5. ?- append([a, b], [c, d], [a, b, c, d]). {{ \implies }} true.
  6. ?- append([a, b], [c, d], L). {{ \implies }} L = [a, b, c, d].
  7. ?- append([a, b], [c, d], [c, d, a, b]). {{ \implies }} false.
  8. ?- append(X, [c, Y], [a, b, c, d]). {{ \implies }} X = [a, b], Y = d.
  9. ?- append(X, Y, [a, b, c, d]). {{ \implies }} Génère successivement 5 solutions :
    • X = [], Y = [a, b, c, d]
    • X = [a], Y = [b, c, d]
    • X = [a, b], Y = [c, d]
    • X = [a, b, c], Y = [d]
    • X = [a, b, c, d], Y = []
Question 2 : Définition des Prédicats de Manipulation de Listes

1. Prédicat premier(L, X) :

premier([X | _], X).

2. Prédicat dernier(L, X) :

dernier([X], X).
dernier([_ | Queue], X) :- dernier(Queue, X).

3. Prédicat longueur(L, N) :

longueur([], 0).
longueur([_ | Q], N) :- longueur(Q, N1), N is N1 + 1.

Exercice 41 — Formes Normales en LPPO (p. 24)

Formule initiale : $F = eg ( ( orall x(p(f(x)) \implies eg q(x))) \implies eg \exists x (p(f(x)) \land q(x)) )$.

Résolution Étape par Étape

Étape 1 : Forme Normale Négative (FNN)

On applique $ eg(A \implies B) \equiv A \land eg B$ :

{{ ( orall x(p(f(x)) \implies eg q(x))) \land eg eg \exists x (p(f(x)) \land q(x)) }} {{ \equiv ( orall x( eg p(f(x)) \lor eg q(x))) \land \exists x (p(f(x)) \land q(x)) }}

Étape 2 : Renommage et Forme Prénexe

On renomme la variable de l'existentiel en {{ y }} :

{{ ( orall x( eg p(f(x)) \lor eg q(x))) \land \exists y (p(f(y)) \land q(y)) }}

Extraction des quantificateurs :

{{ orall x \exists y [ ( eg p(f(x)) \lor eg q(x)) \land p(f(y)) \land q(y) ] }}

Étape 3 : Skolémisation

Le quantificateur {{ \exists y }} dépend de {{ orall x }}. On introduit le symbole de fonction de Skolem {{ g }} : {{ y \mapsto g(x) }}.

{{ orall x [ ( eg p(f(x)) \lor eg q(x)) \land p(f(g(x))) \land q(g(x)) ] }}

Étape 4 : Forme Normale Conjonctive (Clauses)

  • $C_1 = eg p(f(x)) \lor eg q(x)$
  • {{ C_2 = p(f(g(x))) }}
  • {{ C_3 = q(g(x)) }}

Étape 5 : Résolution et Conclusion

Résolution entre {{ C_2 }} (avec renommage {{ x' }}) et {{ C_1 }} avec l'unificateur {{ \sigma = \{x \mapsto g(x')\} }} :

{{ ext{Res}(C_2, C_1) = eg q(g(x')) }}

Résolution avec {{ C_3 }} :

{{ ext{Res}( eg q(g(x')), q(g(x))) = \Box }}

Conclusion : On a dérivé la clause vide {{ \Box }}. La formule {{ F }} est donc INSATISFIABLE !
