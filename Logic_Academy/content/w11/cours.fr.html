1. Les Listes en Prolog et le Prédicat append

Définition 11.1 — Structure Inductive d'une Liste

En Prolog, une liste est définie inductivement par :

  • La liste vide : []
  • La cellule cons : [T | Q] où T est le premier élément (la tête) et Q est le reste de la liste (la queue).

Exemple : [a, b, c] est du sucre syntaxique pour [a | [b | [c | []]]].

Le Prédicat Magique : append(L1, L2, L3)
append([], L, L).
append([X | L1], L2, [X | L3]) :- append(L1, L2, L3).

Prolog peut utiliser ce prédicat dans les deux sens :

  • Concaténer : ?- append([a, b], [c, d], R). {{ \implies }} R = [a, b, c, d].
  • Décomposer : ?- append(X, Y, [a, b]). génère par backtracking toutes les partitions possibles de la liste !

2. Formes Normales en LPPO : Prénexe et Skolémisation

Pour appliquer la méthode de résolution à une formule de premier ordre quelconque, on doit la transformer en forme clausale en suivant 4 étapes strictes :

Les 4 Étapes de la Transformation Clausale en LPPO
  1. Forme Normale Négative (FNN) : On élimine les équivalences et implications, puis on pousse les négations jusqu'aux atomes à l'aide des lois de De Morgan : {{ eg orall x A \equiv \exists x eg A \quad ext{et} \quad eg \exists x A \equiv orall x eg A }}
  2. Renommage des variables ({{ lpha }}-conversion) : On s'assure que chaque quantificateur porte sur une variable portant un nom distinct afin d'éviter toute ambiguïté de portée.
  3. Forme Prénexe : On extrait tous les quantificateurs en tête de formule : {{ Q_1 x_1 Q_2 x_2 \dots Q_k x_k \; M(x_1, \dots, x_k) }} où la matrice {{ M }} ne contient plus aucun quantificateur.
  4. Skolémisation (Forme de Skolem) : On élimine les quantificateurs existentiels de gauche à droite :
    • Si {{ \exists y }} n'est précédé d'aucun quantificateur universel, on remplace chaque occurrence libre de {{ y }} par une nouvelle constante de Skolem {{ c }}.
    • Si {{ \exists y }} est précédé par les quantificateurs universels {{ orall x_1, \dots, orall x_n }}, on remplace {{ y }} par un terme fonctionnel {{ f_y(x_1, \dots, x_n) }} où {{ f_y }} est un nouveau symbole de fonction.
Attention Conceptuelle : Équivalence vs Équisatisfiabilité

La formule skolémisée {{ F_{sk} }} n'est PAS logiquement équivalente à la formule de départ {{ F }} (car la signature a été enrichie de nouvelles fonctions) !

En revanche, elles sont ÉQUISATISFIABLES :

{{ F ext{ est satisfiable} \iff F_{sk} ext{ est satisfiable} }}

C'est exactement ce dont la preuve par réfutation a besoin pour conclure !
