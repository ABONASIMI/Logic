سوال ۱ (۳ نمره) فرمول‌بندی ادعاهای هر سه مظنون

متن اصلی صورت مسئله امتحان

اوا، رائول و اسکوبیدو متهم به یک فقره جرم هستند و اظهارات زیر را بیان می‌کنند:

  • اوا: «اگر اسکوبیدو بی‌گناه باشد، آنگاه رائول گناهکار است.»
  • رائول: «اگر اوا گناهکار باشد، آنگاه من هم گناهکارم.»
  • اسکوبیدو: «اگر اوا بی‌گناه باشد، آنگاه رائول گناهکار است.»

با استفاده از گزاره‌های زیر:

  • {{ e }}: «اوا گناهکار است»
  • {{ r }}: «رائول گناهکار است»
  • {{ s }}: «اسکوبیدو گناهکار است»

اظهارات اوا، رائول و اسکوبیدو را فرمول‌بندی صوری کنید.

پاسخ‌نامه رسمی سوال ۱

ترجمه صوری ادعاها

  • اظهارات اوا: بی‌گناهی اسکوبیدو با {{ eg s }} نمایش داده می‌شود. عبارت شرطی مستقیم حاصل می‌شود:

    {{ F_E = eg s \Rightarrow r }}

  • اظهارات رائول: گناهکاری اوا ({{ e }}) نتیجه می‌دهد که رائول گناهکار است ({{ r }}):

    {{ F_R = e \Rightarrow r }}

  • اظهارات اسکوبیدو: بی‌گناهی اوا به صورت {{ eg e }} بیان می‌شود:

    {{ F_S = eg e \Rightarrow r }}

سوال ۲ (۳ نمره) استنتاج گناهکاری از طریق نتیجه معنایی

متن اصلی صورت مسئله امتحان

فرض می‌کنیم هر سه نفر حقیقت را می‌گویند. درباره گناهکاری اوا، رائول و اسکوبیدو چه می‌توان گفت؟ (پاسخ‌های خود را با مفهوم نتیجه معنایی توجیه کنید).

استدلال دقیق بر اساس نتیجه معنایی (Conséquence sémantique)

مشاهده می‌کنیم که دقیقاً چهار تعبیر {{ I_1, I_2, I_3 }} و {{ I_4 }} وجود دارند که هر سه فرمول {{ eg s \Rightarrow r }} و {{ e \Rightarrow r }} و {{ eg e \Rightarrow r }} را هم‌زمان صادق می‌کنند.

  • از آنجا که از یک طرف {{ I_2(e) = 0 }} و {{ I_3(e) = 1 }}، و از طرف دیگر {{ I_1(s) = 0 }} و {{ I_2(s) = 1 }} است، هیچ نتیجه‌ای درباره {{ e }} و {{ s }} نمی‌توان گرفت (وضعیت اوا و اسکوبیدو نامشخص می‌ماند).
  • اما در تمام مدل‌ها بدون هیچ استثنایی داریم:

    {{ I_1(r) = I_2(r) = I_3(r) = I_4(r) = 1 }}

    بنابراین نتیجه صوری به دست می‌آید که رائول قطعاً گناهکار است ({{ \{F_E, F_R, F_S\} \models r }}).
سوال ۳ (۳ نمره) شناسایی دروغگویان بر پایه حقیقت بازپرسی

متن اصلی صورت مسئله امتحان

تحقیقات نهایی بازپرس نشان می‌دهد که اوا گناهکار است و رائول و اسکوبیدو بی‌گناه هستند. مشخص کنید چه کسی دروغ گفته و چه کسی راست گفته است.

پاسخ‌نامه رسمی سوال ۳

یافته‌های پلیس دقیقاً متناظر با تعبیر واقعی زیر است:

{{ I_0 = \{e: 1, r: 0, s: 0\} }}

ارزش درستی ادعای هر فرد را تحت {{ I_0 }} محاسبه می‌کنیم:

  • اوا: {{ [ eg s \Rightarrow r]^{I_0} = [ eg 0 \Rightarrow 0] = [1 \Rightarrow 0] = 0 }}. اوا دروغ گفته است.
  • رائول: {{ [e \Rightarrow r]^{I_0} = [1 \Rightarrow 0] = 0 }}. رائول دروغ گفته است.
  • اسکوبیدو: {{ [ eg e \Rightarrow r]^{I_0} = [ eg 1 \Rightarrow 0] = [0 \Rightarrow 0] = 1 }}. اسکوبیدو راست گفته است.

نتیجه نهایی: اوا و رائول دروغ گفته‌اند، و اسکوبیدو راست گفته است.

سوال ۱ (۳ نمره) فرمول‌بندی ادعاهای مظنونین

متن اصلی صورت مسئله امتحان

کنراد، پل و اورسول متهم به یک جرم هستند و ادعاهای زیر را بیان می‌کنند:

  • کنراد: «حداقل دو نفر از ما گناهکار هستند.»
  • پل: «اگر من گناهکار باشم، آنگاه اورسول هم گناهکار است و کنراد بی‌گناه است.»
  • اورسول: «اگر کنراد گناهکار باشد، آنگاه من و پل بی‌گناهیم.»

گزاره‌ها: {{ p }}: «کنراد گناهکار است»، {{ q }}: «پل گناهکار است»، {{ r }}: «اورسول گناهکار است».

ادعاهای هر سه نفر را فرمول‌بندی کنید.

پاسخ‌نامه رسمی سوال ۱
  • کنراد: «حداقل دو گناهکار» یعنی (کنراد و پل) یا (کنراد و اورسول) یا (پل و اورسول):

    {{ F_C = (p \land q) \lor (p \land r) \lor (q \land r) }}

  • پل: اگر پل گناهکار باشد ({{ q }})، آنگاه اورسول گناهکار است ({{ r }}) و کنراد بی‌گناه است ({{ eg p }}):

    {{ F_P = q \Rightarrow (r \land eg p) }}

  • اورسول: اگر کنراد گناهکار باشد ({{ p }})، آنگاه پل بی‌گناه است ({{ eg q }}) و اورسول نیز بی‌گناه است ({{ eg r }}):

    {{ F_U = p \Rightarrow ( eg q \land eg r) }}

نتیجه‌گیری قطعی طبق برگه اساتید

مشاهده می‌شود که تنها یک تعبیر یکتای {{ I_1 }} وجود دارد که هر سه فرمول را هم‌زمان برقرار می‌کند.

در این تعبیر مشخص است که {{ I_1(p) = 0 }} و {{ I_1(q) = I_1(r) = 1 }}. بنابراین با قطعیت نتیجه می‌گیریم که:

  • کنراد بی‌گناه است ({{ I_1(p) = 0 }}).
  • پل و اورسول گناهکار هستند ({{ I_1(q) = 1 }} و {{ I_1(r) = 1 }}).
سوال ۳ (۳ نمره) تحلیل وضعیت واقعی بازپرسی

متن اصلی صورت مسئله امتحان

تحقیقات نشان می‌دهد کنراد و اورسول گناهکارند و پل بی‌گناه است. چه کسی راست گفته و چه کسی دروغ؟

پاسخ‌نامه رسمی سوال ۳

این وضعیت معادل با تعبیر زیر است:

{{ I_2 = \{p: 1, q: 0, r: 1\} }}

با ارزیابی سطر متناظر با {{ I_2 }} در جدول درستی داریم:

  • {{ [F_C]^{I_2} = 1 }}: کنراد راست گفته است.
  • {{ [F_P]^{I_2} = 1 }}: پل راست گفته است. (زیرا فرض {{ q=0 }} نادرست بوده و استلزام به طور خودکار درست است).
  • {{ [F_U]^{I_2} = 0 }}: اورسول دروغ گفته است. (زیرا کنراد گناهکار است {{ p=1 }} اما نتیجه بی‌گناهی هر دو نفر غلط بود {{ 0 \land 0 = 0 }}، لذا {{ 1 \Rightarrow 0 = 0 }}).

نتیجه نهایی: کنراد و پل راست گفته‌اند، و اورسول دروغ گفته است.
