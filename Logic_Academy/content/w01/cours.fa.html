1. Introduction et motivations en informatique

چرا منطق صوری قلب تپنده علوم کامپیوتر است؟

در مبانی علوم کامپیوتر، ماشین با مفاهیم مبهم کار نمی‌کند بلکه با وضعیت‌های قطعی دوتایی ({{ 0 }} و {{ 1 }}) سر و کار دارد. منطق گزاره‌ای زیربنای ریاضی ضروری برای حوزه‌های زیر است:

  • طراحی مدارهای دیجیتال: مدل‌سازی گیت‌های منطقی (AND, OR, NOT) و ساده‌سازی توابع بولی با جدول‌های کارنو.
  • نوشتن عبارات شرطی در برنامه‌نویسی: عبارت‌های کنترلی نظیر if (A && !B || C) در تمام زبان‌های نرم‌افزاری.
  • اثبات درستی برنامه‌ها (Formal Verification): اثبات ریاضی این‌که سامانه‌های حیاتی (هوانوردی، رمزنگاری) فاقد هرگونه باگ هستند.
  • هوش مصنوعی و حل مسائل قیود: حل‌کننده‌های مدرن SAT/SMT که روزانه مسائل عظیم در ابعاد صنعتی را حل می‌کنند.

2. Syntaxe formelle et arbres syntaxiques (AST)

تعریف استقرایی مجموعه فرمول‌های گزاره‌ای {{ \mathcal{F}_p(\mathcal{P}_0) }}

فرض کنید {{ \mathcal{P}_0 = \{p, q, r, p_0, p_1, \dots\} }} یک مجموعه شمارا از نمادهای گزاره‌ای (اتم‌ها) باشد. مجموعه {{ \mathcal{F}_p(\mathcal{P}_0) }} شامل تمامی فرمول‌های خوش‌ساخت گزاره‌ای به روش استقرایی با سه قاعده زیر تعریف می‌شود (اسلاید ۱۴ درس سوربن):

  1. پایه استقرا: ثابت‌های درستی {{ ext{true} }} (با نماد {{ op }}) و نادرستی {{ ext{false} }} (با نماد {{ ot }}) عضو {{ \mathcal{F}_p(\mathcal{P}_0) }} هستند. هر نماد گزاره‌ای {{ p \in \mathcal{P}_0 }} نیز عضو {{ \mathcal{F}_p(\mathcal{P}_0) }} است.
  2. گام استقرای تک‌تایی: اگر {{ F \in \mathcal{F}_p(\mathcal{P}_0) }} باشد، آنگاه نقیض آن {{ ( eg F) \in \mathcal{F}_p(\mathcal{P}_0) }} است.
  3. گام استقرای دوتایی: اگر {{ F_1, F_2 \in \mathcal{F}_p(\mathcal{P}_0) }} باشند، آنگاه:
    • {{ (F_1 \land F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (عطف منطقی: «و»)
    • {{ (F_1 \lor F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (فصل منطقی: «یا»)
    • {{ (F_1 \Rightarrow F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (شرطی / استلزام: «نتیجه می‌دهد»)
    • {{ (F_1 \Leftrightarrow F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (دوشرطی: «هم‌ارز است با»)

درخت نحو انتزاعی (AST — Abstract Syntax Tree)

هر فرمول خوش‌ساخت دارای یک نمایش یکتا به صورت درخت مرتب است:

  • برگ‌ها دربرگیرنده نمادهای گزاره‌ای اتمی ({{ p, q, r }}) یا مقادیر ثابت ({{ op, ot }}) هستند.
  • گره‌های درونی رابط‌های منطقی ({{ eg, \land, \lor, \Rightarrow, \Leftrightarrow }}) را نشان می‌دهند.
  • ریشه درخت نشان‌دهنده رابط اصلی فرمول است (عملیاتی که در آخرین گام ارزیابی می‌شود).

پیمایش‌های درختی امکان نمایش فرمول در قالب‌های مختلف را فراهم می‌کنند:

  • پیمایش میان‌ترتیب (Infix): زیردرخت چپ، گره ریشه، زیردرخت راست. همان فرمول‌نویسی معمول همراه با پرانتز است: (p ∧ q) ⇒ r.
  • پیمایش پیش‌ترتیب (Prefix - نمادگذاری پولندی لوکاسیویچ): گره ریشه، زیردرخت چپ، زیردرخت راست. مانند: ⇒ ∧ p q r. این فرمت این مزیت شگفت‌انگیز را دارد که بدون نیاز به هیچ پرانتزی، کاملاً فاقد هرگونه ابهام است!

3. Règles de priorité et parenthésage Sorbonne

اولویت کاهشی عملگرها و شرکت‌پذیری از راست در دانشگاه سوربن

برای خلاصه‌سازی فرمول‌ها و حذف پرانتزهای دست‌وپاگیر، کورس منطق دانشگاه سوربن دو قاعده سخت‌گیرانه وضع کرده است (اسلاید ۱۱ درس):

  1. ترتیب اولویت عملگرها از قوی به ضعیف:
    {{ eg \quad > \quad \land \quad > \quad \lor \quad > \quad \Rightarrow \quad > \quad \Leftrightarrow }}
    نقیض {{ eg }} قوی‌ترین اتصال را دارد، سپس عطف {{ \land }}، سپس فصل {{ \lor }}، سپس استلزام {{ \Rightarrow }}، و در نهایت دوشرطی {{ \Leftrightarrow }}.
  2. قاعده شرکت‌پذیری در صورت اولویت برابر: زیرفرمول سمت راست همیشه اولویت دارد! (شرکت‌پذیری از راست).
    مثال‌های اساسی:
    • {{ A \land B \land C \equiv A \land (B \land C) }}
    • {{ A \Rightarrow B \Rightarrow C \equiv A \Rightarrow (B \Rightarrow C) }}

    هشدار مهم و تله امتحانی: در حساب معمولی یا برخی زبان‌ها ارزیابی از چپ به راست است. اما در آزمون‌های سوربن، عبارت A ⇒ B ⇒ C اجباراً به معنای A ⇒ (B ⇒ C) است و هرگز به معنای (A ⇒ B) ⇒ C نخواهد بود!

4. Sémantique et algèbre des valeurs de vérité

تعبیر (ارزیابی) و تابع معنایی استقرایی {{ [F]^I }}

نحو صرفاً رشته‌هایی از حروف بدون معنا تولید می‌کند. معناشناسی با متصل کردن فرمول‌ها به مجموعه بولی {{ \mathbb{B} = \{0, 1\} }} به آن‌ها مفهوم حقیقت می‌بخشد.

  • یک تعبیر (یا ارزیابی / مدل) تابعی است به شکل {{ I : \mathcal{P}_0 o \{0, 1\} }} که به هر نماد اتمی، یک مقدار درستی ({{ 0 }} برای نادرست و {{ 1 }} برای درست) نسبت می‌دهد.
  • ارزش درستی یک فرمول ترکیبی {{ F }} تحت تعبیر {{ I }} که با {{ [F]^I }} نشان داده می‌شود، به روش استقرایی روی ساختار درخت نحو ارزیابی می‌گردد:
    • {{ [ ext{true}]^I = 1 }} و {{ [ ext{false}]^I = 0 }}
    • برای هر نماد اتمی {{ p }} داریم: {{ [p]^I = I(p) }}
    • {{ [ eg F]^I = 1 - [F]^I }}
    • {{ [F_1 \land F_2]^I = \min([F_1]^I, [F_2]^I) }}
    • {{ [F_1 \lor F_2]^I = \max([F_1]^I, [F_2]^I) }}
    • {{ [F_1 \Rightarrow F_2]^I = \max(1 - [F_1]^I, [F_2]^I) }}
    • {{ [F_1 \Leftrightarrow F_2]^I = 1 }} اگر و تنها اگر {{ [F_1]^I = [F_2]^I }} باشد، وگرنه برابر {{ 0 }} است.

5. Tables de vérité et classification des formules

روش گام‌به‌گام ساخت جدول درستی دانشگاهی

فرمول با {{ n }} متغیر مستقل دقیقاً دارای {{ 2^n }} سطر تعبیر مختلف است. برای ساخت جدولی استاندارد و نمره‌آور:

  1. متغیرهای گزاره‌ای را به ترتیب الفبا در ستون‌های نخست قرار دهید.
  2. سطرها را بر اساس ترتیب طبیعی دودویی پر کنید (از {{ 00\dots0 }} تا {{ 11\dots1 }}).
  3. برای هر زیرفرمول سره بر اساس ساختار درخت AST، از کوچک‌ترین به بزرگ‌ترین ستون‌های میانی تشکیل دهید.
  4. آخرین ستون، نتیجه رابط اصلی فرمول نهایی را به نمایش می‌گذارد.

دسته‌بندی سه‌گانه معنایی فرمول‌ها

  • فرمول صدق‌پذیر (Satisfiable): حداقل یک تعبیر {{ I }} وجود دارد به گونه‌ای که {{ [F]^I = 1 }} باشد. تعبیر {{ I }} را یک مدل برای {{ F }} می‌نامند.
  • فرمول معتبر یا توتولوژی (Tautology / Valid - نماد {{ \models F }}): تحت تمامی تعبیرهای ممکن {{ I }}، همواره {{ [F]^I = 1 }} است. فرمولی که تحت هر شرایطی در جهان حقیقت دارد.
  • فرمول ناسازگار یا تناقض (Contradiction / Unsatisfiable): تحت هر تعبیر دلخواه {{ I }}، مقدار {{ [F]^I = 0 }} است و هیچ مدلی ندارد.

6. Modélisation rigoureuse du langage naturel et implication

شرطی مادی {{ A \Rightarrow B }} : حقیقت و تناقض‌های ظاهری آن

از نظر معنایی، {{ A \Rightarrow B }} دقیقاً هم‌ارز با {{ eg A \lor B }} است. این فرمول تنها در یک حالت نادرست می‌شود: مقدم {{ A }} درست باشد ولی نتیجه {{ B }} نادرست باشد.

اصل انفجار (Ex falso quodlibet): هرگاه فرض مقدم {{ A }} نادرست باشد ({{ I(A)=0 }})، کل گزاره شرطی {{ A \Rightarrow B }} به طور خودکار درست خواهد بود، فارغ از این‌که گزاره دوم {{ B }} چه باشد!

مثال مشهور: عبارت «اگر گاوها پرواز کنند، ماه از پنیر سبز ساخته شده است» در منطق کلاسیک گزاره‌ای کاملاً «درست» محسوب می‌شود زیرا فرض اولیه آن باطل است.

فرهنگ واژگان تبدیل عبارات زبان به فرمول‌های منطقی

جدول زیر الگوهای زبانی معمول و ترجمه دقیق آن‌ها را نشان می‌دهد:

عبارت در زبان روزمره مفهوم ریاضی فرمول منطقی صوری
«اگر A آنگاه B» / «به محض وقوع A، گزاره B رخ می‌دهد» A نتیجه می‌دهد B {{ A \Rightarrow B }}
«A فقط اگر B» (تنها در صورتی که B باشد، A می‌تواند باشد) اگر B نباشد، A هم نیست ({{ eg B \Rightarrow eg A }}) {{ A \Rightarrow B }}
«برای B، لازم است که A باشد» (شرط لازم / nécessaire) A برای داشتن B اجباری است {{ B \Rightarrow A }}
«برای B، کافی است که A باشد» (شرط کافی / suffisant) وجود A تضمین‌کننده وقوع B است {{ A \Rightarrow B }}
«A اگر و فقط اگر B» / «A هم‌ارز با B» شرط لازم و کافی دوطرفه {{ A \Leftrightarrow B }}
«نه A و نه B» (هیچ‌کدام) نفی هر دو حالت {{ eg A \land eg B \equiv eg(A \lor B) }}
«حداقل یکی از دو گزاره (A یا B)» فصل منطقی شمول‌پذیر {{ A \lor B }}
«حداکثر یکی از دو گزاره (A یا B)» نمی‌توانند هم‌زمان درست باشند {{ eg(A \land B) \equiv eg A \lor eg B }}
«دقیقاً یکی از دو گزاره (یا منحصراً این، یا آن)» یا مانعة‌الجمع (XOR) {{ (A \lor B) \land eg(A \land B) \equiv eg(A \Leftrightarrow B) }}
