1. Introduction et motivations en informatique

Pourquoi la logique formelle est le cœur de l'informatique

En informatique fondamentale, un ordinateur ne manipule pas des idées vagues mais des états binaires stricts ({{ 0 }} et {{ 1 }}). La logique propositionnelle constitue le socle mathématique indispensable à :

  • La conception des circuits numériques : modélisation des portes logiques (ET, OU, NON) et simplification booléenne par tables de Karnaugh.
  • L'écriture de conditions logicielles : expressions conditionnelles if (A && !B || C) dans les langages de programmation.
  • La vérification formelle de programmes : prouver mathématiquement qu'un algorithme critique (aéronautique, cryptographie) ne contient aucun bug.
  • L'intelligence artificielle et la résolution de contraintes : solveurs SAT/SMT utilisés quotidiennement pour résoudre des problèmes NP-complets industriels.

2. Syntaxe formelle et arbres syntaxiques (AST)

Définition inductive de l'ensemble des formules propositionnelles {{ \mathcal{F}_p(\mathcal{P}_0) }}

Soit {{ \mathcal{P}_0 = \{p, q, r, p_0, p_1, \dots\} }} un ensemble dénombrable de symboles de propositions (ou atomes). L'ensemble {{ \mathcal{F}_p(\mathcal{P}_0) }} des formules propositionnelles bien formées est défini inductivement par les trois règles suivantes (Sorbonne Cours 1, Slide 14) :

  1. Base : Les constantes logiques {{ ext{true} }} (notée aussi {{ op }}) et {{ ext{false} }} (notée aussi {{ ot }}) appartiennent à {{ \mathcal{F}_p(\mathcal{P}_0) }}. Tout symbole de proposition {{ p \in \mathcal{P}_0 }} appartient à {{ \mathcal{F}_p(\mathcal{P}_0) }}.
  2. Induction unaire : Si {{ F \in \mathcal{F}_p(\mathcal{P}_0) }}, alors {{ ( eg F) \in \mathcal{F}_p(\mathcal{P}_0) }} (négation).
  3. Induction binaire : Si {{ F_1, F_2 \in \mathcal{F}_p(\mathcal{P}_0) }}, alors :
    • {{ (F_1 \land F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (conjonction : « ET »)
    • {{ (F_1 \lor F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (disjonction : « OU »)
    • {{ (F_1 \Rightarrow F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (implication : « IMPLIQUE »)
    • {{ (F_1 \Leftrightarrow F_2) \in \mathcal{F}_p(\mathcal{P}_0) }} (équivalence : « ÉQUIVAUT »)

Arbre de Syntaxe Abstraite (AST — Abstract Syntax Tree)

Toute formule bien formée possède une représentation unique sous forme d'arbre ordonné :

  • Les feuilles portent les symboles atomiques ({{ p, q, r }}) ou les constantes ({{ op, ot }}).
  • Les nœuds internes portent les connecteurs logiques ({{ eg, \land, \lor, \Rightarrow, \Leftrightarrow }}).
  • La racine de l'arbre est le connecteur principal de la formule (l'opération effectuée en tout dernier lieu).

Les parcours d'arbres permettent d'exprimer la formule sous différentes notations :

  • Parcours infixe : sous-arbre gauche, nœud racine, sous-arbre droit. C'est la notation standard avec parenthèses : (p ∧ q) ⇒ r.
  • Parcours préfixe (notation polonaise de Łukasiewicz) : nœud racine, sous-arbre gauche, sous-arbre droit. Exemple : ⇒ ∧ p q r. Cette notation a l'immense avantage d'être totalement dénuée d'ambiguïté sans jamais nécessiter la moindre parenthèse !

3. Règles de priorité et parenthésage Sorbonne

Priorité décroissante des opérateurs et associativité à droite

Pour alléger l'écriture des formules et supprimer les parenthèses superflues, le cours de Logique de Sorbonne Université fixe deux conventions impératives (Cours 1, Slide 11) :

  1. Ordre de priorité décroissante :
    {{ eg \quad > \quad \land \quad > \quad \lor \quad > \quad \Rightarrow \quad > \quad \Leftrightarrow }}
    La négation {{ eg }} lie plus fort que tout, suivie du ET {{ \land }}, puis du OU {{ \lor }}, puis de l'implication {{ \Rightarrow }}, et enfin de l'équivalence {{ \Leftrightarrow }}.
  2. Convention d'associativité en cas de priorité égale : La sous-formule de droite est toujours prioritaire ! (Associativité à droite).
    Exemples fondamentaux :
    • {{ A \land B \land C \equiv A \land (B \land C) }}
    • {{ A \Rightarrow B \Rightarrow C \equiv A \Rightarrow (B \Rightarrow C) }}

    ATTENTION PIÈGE D'EXAMEN : En arithmétique ou dans certains langages de programmation, l'évaluation se fait souvent de gauche à droite. À la Sorbonne en UL2IN007, A ⇒ B ⇒ C signifie impérativement A ⇒ (B ⇒ C) et JAMAIS (A ⇒ B) ⇒ C !

4. Sémantique et algèbre des valeurs de vérité

Interprétation et fonction d'évaluation inductive {{ [F]^I }}

La syntaxe décrit des chaînes de caractères sans signification. La sémantique leur donne un sens de vérité en les reliant à l'ensemble booléen {{ \mathbb{B} = \{0, 1\} }}.

  • Une interprétation (ou valuation) est une fonction {{ I : \mathcal{P}_0 o \{0, 1\} }} qui associe à chaque symbole de proposition une valeur de vérité ({{ 0 }} pour Faux, {{ 1 }} pour Vrai).
  • La valeur de vérité d'une formule composée {{ F }} sous l'interprétation {{ I }}, notée {{ [F]^I }}, est calculée par induction sur la structure de son AST :
    • {{ [ ext{true}]^I = 1 }}, {{ [ ext{false}]^I = 0 }}
    • {{ [p]^I = I(p) }} pour tout symbole atomique {{ p }}
    • {{ [ eg F]^I = 1 - [F]^I }}
    • {{ [F_1 \land F_2]^I = \min([F_1]^I, [F_2]^I) }}
    • {{ [F_1 \lor F_2]^I = \max([F_1]^I, [F_2]^I) }}
    • {{ [F_1 \Rightarrow F_2]^I = \max(1 - [F_1]^I, [F_2]^I) }}
    • {{ [F_1 \Leftrightarrow F_2]^I = 1 }} si {{ [F_1]^I = [F_2]^I }}, et {{ 0 }} sinon.

5. Tables de vérité et classification des formules

Construction méthodique d'une table de vérité

Une formule comportant {{ n }} variables distinctes admet exactement {{ 2^n }} interprétations différentes. Pour construire une table irréprochable :

  1. Lister les variables propositionnelles par ordre alphabétique en tête des premières colonnes.
  2. Énumérer les lignes dans l'ordre binaire naturel (de {{ 00\dots0 }} à {{ 11\dots1 }}).
  3. Créer une colonne pour chaque sous-formule stricte, de la plus petite vers la plus grande, en respectant la décomposition de l'AST.
  4. La toute dernière colonne correspond au connecteur principal de la formule complète.

Classification sémantique tripartite des formules

  • Formule satisfiable (ou consistante) : Il existe au moins une interprétation {{ I }} telle que {{ [F]^I = 1 }}. L'interprétation {{ I }} est appelée un modèle de {{ F }}.
  • Formule valide (ou tautologie, notée {{ \models F }}) : Pour toute interprétation {{ I }}, on a {{ [F]^I = 1 }}. La formule est vraie quelles que soient les circonstances.
  • Formule insatisfiable (ou antilogie / contradiction) : Pour toute interprétation {{ I }}, on a {{ [F]^I = 0 }}. La formule ne possède aucun modèle.

6. Modélisation rigoureuse du langage naturel et implication

L'implication matérielle {{ A \Rightarrow B }} : vérité et paradoxes apparents

Par définition sémantique, {{ A \Rightarrow B }} équivaut strictement à {{ eg A \lor B }}. Elle n'est fausse que dans un seul et unique cas : quand la prémisse {{ A }} est Vraie et que la conclusion {{ B }} est Fausse.

Principe d'explosion (Ex falso quodlibet) : Dès lors que {{ A }} est faux ({{ I(A)=0 }}), l'implication {{ A \Rightarrow B }} est automatiquement VRAIE, quelle que soit la valeur de vérité de {{ B }} !

Exemple frappant : L'affirmation « S'il pleut des vaches, alors la Lune est en fromage vert » est une implication formellement VRAIE en logique classique, car son hypothèse est fausse.

Dictionnaire de traduction : Langage naturel ↔ Logique propositionnelle

Ce tableau récapitule les tournures françaises classiques et leur formalisation exacte :

Énoncé en français Sens mathématique Traduction formelle
« Si A, alors B » / « B dès que A » A entraîne B {{ A \Rightarrow B }}
« A seulement si B » / « A uniquement si B » Si B n'est pas réalisé, A ne peut l'être ({{ eg B \Rightarrow eg A }}) {{ A \Rightarrow B }}
« Pour que B, il faut que A » (condition nécessaire) A est obligatoire pour avoir B {{ B \Rightarrow A }}
« Pour que B, il suffit que A » (condition suffisante) La présence de A garantit B {{ A \Rightarrow B }}
« A si et seulement si B » / « A équivaut à B » Condition nécessaire ET suffisante {{ A \Leftrightarrow B }}
« Ni A ni B » Ni l'un ni l'autre n'est vrai {{ eg A \land eg B \equiv eg(A \lor B) }}
« Au moins l'un des deux (A ou B) » Disjonction inclusive {{ A \lor B }}
« Au plus l'un des deux (A ou B) » Ils ne peuvent pas être vrais ensemble {{ eg(A \land B) \equiv eg A \lor eg B }}
« Exactement l'un des deux (OU exclusif) » L'un est vrai mais pas les deux {{ (A \lor B) \land eg(A \land B) \equiv eg(A \Leftrightarrow B) }}
