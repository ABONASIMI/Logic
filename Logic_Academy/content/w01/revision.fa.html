1. Fiche mémo express des 5 règles d'or

۵ قاعده اساسی که باید در ذهن تثبیت شوند

  1. سلسله‌مراتب اولویت عملگرها در سوربن:
    { eg \quad > \quad \land \quad > \quad \lor \quad > \quad \Rightarrow \quad > \quad \Leftrightarrow }
    عملگری که کمترین اولویت را دارد، ریشه درخت AST خواهد بود.
  2. شرکت‌پذیری از راست: در صورت تکرار عملگرهای هم‌ارز، دسته‌بندی همواره از راست انجام می‌شود: { A \Rightarrow B \Rightarrow C \equiv A \Rightarrow (B \Rightarrow C) }.
  3. استلزام مادی: { A \Rightarrow B \equiv eg A \lor B }. تنها در صورتی نادرست است که { A=1 } و { B=0 } باشد.
  4. شرط لازم در برابر شرط کافی:
    • «کافی است A باشد تا B شود» (شرط کافی): { A \Rightarrow B }.
    • «لازم است A باشد تا B شود» (شرط لازم): { B \Rightarrow A }.
  5. تعداد سطرهای جدول درستی: برای { n } متغیر گزاره‌ای، جدول دقیقاً شامل { 2^n } سطر است.

2. Radar des pièges d'examen classiques

رایج‌ترین اشتباهاتی که دانشجویان در تصحیح سوربن نمره از دست می‌دهند

  • تله ۱ — شرکت‌پذیری از چپ ناشی از عادت برنامه‌نویسی: نوشتن ((p ∧ q) ∧ r) به جای (p ∧ (q ∧ r)) تمام نمره بخش نحو را صفر می‌کند.
  • تله ۲ — اشتباه گرفتن «تنها اگر» با «اگر»: عبارت «A تنها اگر B» با فرمول { A \Rightarrow B } نمایش می‌یابد و نه با { B \Rightarrow A }.
  • تله ۳ — فراموشی این‌که فرض باطل هر چیزی را نتیجه می‌دهد: تصور این‌که اگر { I(A)=0 } باشد، شرطی { A \Rightarrow B } نادرست یا مبهم است. در حالی که قطعاً درست است!
  • تله ۴ — بی‌نظمی در پر کردن جدول درستی: عدم رعایت نظم طبیعی باینری ({ 000, 001, 010, \dots }) باعث سردرگمی مصحح و جا افتادن برخی سطرها می‌شود.
  • تله ۵ — نتیجه‌گیری شتاب‌زده بدون بررسی همه مدل‌ها: در یک معما، ادعای این‌که فلان گزاره درست است در حالی که فقط در برخی مدل‌ها درست بوده و در مدل دیگری صفر است. برای استلزام منطقی { \mathcal{T} \models arphi }، باید فرمول در ۱۰۰٪ مدل‌های نظریه مقدار ۱ داشته باشد.
