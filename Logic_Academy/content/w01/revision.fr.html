1. Fiche mémo express des 5 règles d'or

Les 5 règles absolues à graver dans votre mémoire

  1. Hiérarchie des priorités de la Sorbonne :
    { eg \quad > \quad \land \quad > \quad \lor \quad > \quad \Rightarrow \quad > \quad \Leftrightarrow }
    Le connecteur de plus faible priorité est la racine de l'AST.
  2. Associativité à droite : En cas d'opérateurs identiques successifs, on regroupe TOUJOURS par la droite : { A \Rightarrow B \Rightarrow C \equiv A \Rightarrow (B \Rightarrow C) }.
  3. L'implication matérielle : { A \Rightarrow B \equiv eg A \lor B }. Fausse uniquement si { A=1 } et { B=0 }.
  4. Condition nécessaire vs suffisante :
    • « Il suffit de A pour B » (condition suffisante) : { A \Rightarrow B }.
    • « Il faut A pour B » (condition nécessaire) : { B \Rightarrow A }.
  5. Nombre de lignes de la table de vérité : Pour { n } variables propositionnelles, la table comporte exactement { 2^n } lignes.

2. Radar des pièges d'examen classiques

Les erreurs les plus pénalisées par les correcteurs de la Sorbonne

  • Piège 1 — L'associativité à gauche par habitude du code : Écrire ((p ∧ q) ∧ r) au lieu de (p ∧ (q ∧ r)) fait perdre tous les points de syntaxe.
  • Piège 2 — Confondre « seulement si » et « si » : « A seulement si B » se formalise par { A \Rightarrow B }, et NON par { B \Rightarrow A }.
  • Piège 3 — Oublier que le faux implique tout : Penser que si { I(A)=0 }, l'implication { A \Rightarrow B } est fausse ou inconnue. Elle est vraie !
  • Piège 4 — Table de vérité dans le désordre : Ne pas respecter l'ordre binaire naturel ({ 000, 001, 010, \dots }) agace les correcteurs et entraîne souvent des oublis de lignes.
  • Piège 5 — Déduire sans vérifier tous les modèles : Dans une énigme, affirmer qu'une proposition est vraie alors qu'elle ne l'est que dans certains modèles mais pas dans tous. Pour qu'une affirmation soit déductible (conséquence sémantique { \mathcal{T} \models arphi }), elle doit valoir 1 dans 100% des modèles de la théorie.
