Exercice 1 – Arbre de syntaxe abstraite et notation préfixe

زمینه مسئله و مهارت‌های مورد سنجش

این تمرین تسلط بر ساختار درختی فرمول‌ها (AST)، تشخیص عملگر اصلی در فرمول‌های پیچیده، تبدیل به نمادگذاری پیشوندی (لهستانی لوکاسیویچ) و اجرای دقیق قواعد اولویت دانشگاه سوربن (کاهش اولویت و شرکت‌پذیری از راست) را مورد ارزیابی قرار می‌دهد.

زیرمسئله ۱.۱ درخت نحو انتزاعی و نمادگذاری پیشوندی {{ F_1 = eg(p \land (q \Rightarrow ((q \lor r) \land q))) }}

متن اصلی صورت مسئله

برای فرمول زیر که در آن {{ p, q }} و {{ r }} نمادهای گزاره‌ای هستند:

  • درخت نحو انتزاعی (AST) آن را رسم کنید.
  • فرمول را در نمادگذاری پیشوندی بنویسید.

{{ F_1 = eg(p \land (q \Rightarrow ((q \lor r) \land q))) }}

راهبرد و گام‌های تجزیه

فرمول کاملاً پرانتزگذاری شده است. برای یافتن ریشه، قواعد استقرایی را از بیرون به درون دنبال می‌کنیم:

  1. بیرونی‌ترین عملگر نقیض {{ eg }} است که بر کل پرانتز اثر می‌کند؛ بنابراین ریشه درخت {{ eg }} است.
  2. تنها فرزند آن عطف {{ \land }} میان اتم {{ p }} و زیرفرمول {{ (q \Rightarrow ((q \lor r) \land q)) }} است.
  3. فرزند راست {{ \land }}، عملگر شرطی {{ \Rightarrow }} با فرزند چپ {{ q }} و فرزند راست عطف دوتایی {{ \land }} است.
  4. این عطف اخیر دارای فرزند چپ فصل {{ (q \lor r) }} و فرزند راست برگ اتمی {{ q }} است.
پاسخ تشریحی و نمادگذاری پیشوندی

پیمایش پیشوندی (ریشه ← زیردرخت چپ ← زیردرخت راست)

الگوریتم پیمایش پیشوندی را به روش بازگشتی پیاده می‌کنیم:

  • سطح ۱: عملگر ¬ به همراه پیمایش زیردرخت آن.
  • سطح ۲: عملگر ∧ به همراه برگ p و سپس زیردرخت راست.
  • سطح ۳: عملگر ⇒ به همراه برگ q و زیردرخت راست.
  • سطح ۴: عملگر ∧ به همراه زیردرخت چپ و برگ q.
  • سطح ۵: عملگر ∨ به همراه برگ‌های q و r.

با کنار هم قرار دادن تمام نمادها بدون نیاز به حتی یک پرانتز، فرمول پیشوندی نهایی برابر است با:

¬ ∧ p ⇒ q ∧ ∨ q r q

بررسی درستی: ۴ عملگر دوتایی + ۱ عملگر یکتایی = ۵ عملگر. تعداد برگ‌ها ۵ تاست (p, q, q, r, q). رشته پیشوندی حاصل دقیقاً دارای ۱۰ نماد معتبر است.

زیرمسئله ۱.۲ درخت نحو انتزاعی و نمادگذاری پیشوندی {{ F_2 = eg p \land q \Rightarrow q \lor r \land q }}

متن اصلی صورت مسئله

برای فرمول {{ F_2 = eg p \land q \Rightarrow q \lor r \land q }} :

  • درخت نحو انتزاعی آن را رسم کنید.
  • فرمول را در نمادگذاری پیشوندی بنویسید.

بازسازی پرانتزهای ناپیدا طبق قواعد رسمی سوربن

فرمول {{ F_2 }} فاقد پرانتز است. قاعده اولویت {{ eg > \land > \lor > \Rightarrow }} را اعمال می‌کنیم:

  1. نقیض {{ eg }} بالاترین اولویت را دارد: {{ ( eg p) }}.
  2. عطف {{ \land }} بر فصل {{ \lor }} و استلزام {{ \Rightarrow }} اولویت دارد:
    • در سمت چپ: {{ (( eg p) \land q) }}.
    • در سمت راست: {{ (r \land q) }}.
  3. فصل {{ \lor }} بر استلزام {{ \Rightarrow }} اولویت دارد: سمت راست تبدیل می‌شود به {{ (q \lor (r \land q)) }}.
  4. ضعیف‌ترین عملگر، استلزام میانی {{ \Rightarrow }} است که بنابراین عملگر اصلی و ریشه نهایی درخت خواهد بود!

شکل کاملاً پرانتزگذاری‌شده: {{ (( eg p) \land q) \Rightarrow (q \lor (r \land q)) }}.

پاسخ تشریحی و نمادگذاری پیشوندی

نمادگذاری پیشوندی فرمول {{ F_2 }}

ریشه درخت {{ \Rightarrow }} است:

  • زیردرخت چپ: ∧ ¬ p q
  • زیردرخت راست: ∨ q ∧ r q

نتیجه نهایی در نمادگذاری پیشوندی:

⇒ ∧ ¬ p q ∨ q ∧ r q
زیرمسئله ۲.۱ پرانتزگذاری دقیق فرمول {{ F_3 = p \land q \land r \land s }}

متن اصلی صورت مسئله

فرمول زیر را با رعایت دقیق اولویت عملگرها پرانتزگذاری کنید:

{{ F_3 = p \land q \land r \land s }}

پاسخ تشریحی و توجیه طبق ضوابط دانشگاه سوربن

قاعده شرکت‌پذیری از راست (اسلاید ۱۱ درس ۱)

همه عملگرها یکسان ({{ \land }}) هستند و بنابراین اولویت برابری دارند. قاعده رسمی درس سوربن صراحتاً اعلام می‌کند:

«در صورت اولویت برابر: زیرفرمول سمت راست همیشه اولویت دارد.»

مراحل پرانتزگذاری گام‌به‌گام از راست به چپ:

  1. دسته‌بندی دو اتم انتهایی راست: {{ (r \land s) }}.
  2. دسته‌بندی با اتم ماقبل: {{ (q \land (r \land s)) }}.
  3. دسته‌بندی نهایی با اتم نخست {{ p }}: {{ (p \land (q \land (r \land s))) }}.

پاسخ نهایی مورد قبول در برگه امتحان:

{{ (p \land (q \land (r \land s))) }}

اشتباه رایج و مرگبار در آزمون: نوشتن (((p ∧ q) ∧ r) ∧ s). هرچند از نظر معنایی عطف در جبر بولی شرکت‌پذیر است، اما از دیدگاه نحوی در درس سوربن، درخت متناظر با پرانتزگذاری از چپ کاملاً غلط محسوب می‌شود!

زیرمسئله ۲.۲ پرانتزگذاری دقیق فرمول {{ F_4 = p \Rightarrow q \land eg r \Rightarrow p \lor q }}

متن اصلی صورت مسئله

فرمول زیر را با رعایت دقیق اولویت عملگرها پرانتزگذاری کنید:

{{ F_4 = p \Rightarrow q \land eg r \Rightarrow p \lor q }}

پاسخ تشریحی گام‌به‌گام

اعمال دقیق سلسله‌مراتب {{ eg > \land > \lor > \Rightarrow }}

  1. گام ۱ ({{ eg }}): نقیض بر اتم {{ r }} اثر دارد: (¬ r).
  2. گام ۲ ({{ \land }}): عطف q ∧ (¬ r) اتصال می‌یابد: (q ∧ (¬ r)).
  3. گام ۳ ({{ \lor }}): فصل p ∨ q پرانتز می‌گیرد: (p ∨ q).
  4. دو عملگر شرطی باقی می‌ماند: p ⇒ (q ∧ (¬ r)) ⇒ (p ∨ q).
  5. گام ۴ (شرکت‌پذیری از راست عملگر {{ \Rightarrow }}): برای زنجیره شرطی، زیرفرمول سمت راست در اولویت قرار دارد!
    ابتدا بخش راست پرانتز می‌گیرد: ((q ∧ (¬ r)) ⇒ (p ∨ q)).
    سپس کل عبارت با گزاره p شرطی می‌شود:

پاسخ نهایی تشریحی برای آزمون:

{{ (p \Rightarrow ((q \land ( eg r)) \Rightarrow (p \lor q))) }}

Exercice 2 – Implication et formalisation du langage naturel

مقدمه و داده‌های مسئله

گزاره‌های اتمی زیر را در نظر بگیرید:

  • {{ p_1 }}: «هوا خوب است»
  • {{ p_2 }}: «من پیاده‌روی می‌کنم»

وضعیت واقعی مورد بررسی این است که هوا خوب نیست ولی من پیاده‌روی می‌کنم، که نشان‌دهنده تعبیر صوری زیر است:

{{ I(p_1) = 0 \quad ext{et} \quad I(p_2) = 1 }}

سوالات ۱ و ۲ ترجمه صوری و ارزیابی درستی هر ۶ عبارت
تحلیل جامع هر ۶ عبارت زبانی تحت تعبیر {{ I(p_1)=0, I(p_2)=1 }}
شماره عبارت در زبان طبیعی فرمول منطقی صوری محاسبه {{ [F]^I }} تحت {{ I(p_1)=0, I(p_2)=1 }} وضعیت درستی
۱ «اگر هوا خوب باشد، پیاده‌روی می‌کنم» {{ p_1 \Rightarrow p_2 }} {{ 0 \Rightarrow 1 = 1 }} صادق است (درست)
۲ «برای پیاده‌روی من، لازم است که هوا خوب باشد» {{ p_2 \Rightarrow p_1 }} {{ 1 \Rightarrow 0 = 0 }} کاذب است (نادرست)
۳ «من پیاده‌روی نمی‌کنم مگر آن‌که هوا خوب باشد» {{ p_2 \Rightarrow p_1 }} {{ 1 \Rightarrow 0 = 0 }} کاذب است (نادرست)
۴ «به محض این‌که هوا خوب شود، پیاده‌روی می‌کنم» {{ p_1 \Rightarrow p_2 }} {{ 0 \Rightarrow 1 = 1 }} صادق است (درست)
۵ «من پیاده‌روی می‌کنم تنها در صورتی که هوا خوب باشد» {{ p_2 \Rightarrow p_1 }} {{ 1 \Rightarrow 0 = 0 }} کاذب است (نادرست)
۶ «برای پیاده‌روی من، کافی است که هوا خوب باشد» {{ p_1 \Rightarrow p_2 }} {{ 0 \Rightarrow 1 = 1 }} صادق است (درست)

جمع‌بندی نظری فوق‌العاده مهم برای امتحانات

  • شرط کافی («کافی است»، «اگر»، «به محض»): خوب بودن هوا برای پیاده‌روی کفایت می‌کند ← {{ p_1 \Rightarrow p_2 }}. از آنجا که {{ p_1 }} نادرست است ({{ 0 }})، گزاره شرطی طبق اصل انفجار به طور خودکار درست است! بنابراین گزاره‌های ۱، ۴ و ۶ صادق‌اند.
  • شرط لازم («لازم است»، «تنها اگر»، «مگر این‌که»): خوب بودن هوا پیش‌نیاز اجباری پیاده‌روی است ← {{ p_2 \Rightarrow p_1 }}. اما من پیاده‌روی می‌کنم ({{ p_2=1 }}) در حالی که هوا خوب نیست ({{ p_1=0 }}). ارزش {{ 1 \Rightarrow 0 }} برابر با نادرست است؛ بنابراین جملات ۲، ۳ و ۵ کاذب هستند.

سوال ۲ معمای بازجویی جنایی: آنا و ژولی

متن اصلی صورت مسئله

  • آنا: «ژولی گناهکار است.»
  • ژولی: «اگر من گناهکار باشم، آنگاه آنا هم گناهکار است.»

سوال ۳ معمای امتحان منطق: انیسا، خاویر و جنیفر

متن اصلی صورت مسئله

انیسا، خاویر و جنیفر قرار است در امتحان منطق شرکت کنند. می‌دانیم که:

  • {{ H_1 }} : حداقل یکی از این سه نفر برای امتحان درس می‌خواند.
  • {{ H_2 }} : اگر انیسا درس نخواند، آنگاه خاویر هم درس نخواهد خواند.
  • {{ H_3 }} : اگر انیسا درس بخواند، آنگاه جنیفر هم درس خواهد خواند.

گزاره‌ها: {{ A }}: «انیسا درس می‌خواند»، {{ X }}: «خاویر درس می‌خواند»، {{ J }}: «جنیفر درس می‌خواند».

  1. این سه فرض را فرمول‌بندی کنید.
  2. آیا می‌توان مشخص کرد چه کسی قطعاً درس می‌خواند و چه کسی درس نمی‌خواند؟
حل دقیق معناشناسی و تحلیل کامل مدل‌ها

۳. استنتاج‌های قطعی منطقی

دقیقاً ۳ تعبیر وجود دارند که هر سه فرض را به طور هم‌زمان ارضا می‌کنند:

  • {{ I_1 = \{A=0, X=0, J=1\} }}
  • {{ I_2 = \{A=1, X=0, J=1\} }}
  • {{ I_3 = \{A=1, X=1, J=1\} }}

نتیجه‌گیری دانشگاهی نهایی:

  • در هر ۳ مدل بدون استثنا مقدار {{ J = 1 }} است. بنابراین با قطعیت ۱۰۰٪ می‌توان گفت که جنیفر قطعاً درس خواهد خواند ({{ \mathcal{T} \models J }}).
  • درباره انیسا: در دو مدل {{ I_2 }} و {{ I_3 }} مقدارش ۱ است ({{ A=1 }})، اما در مدل {{ I_1 }} درس نمی‌خواند ({{ A=0 }}). بنابراین بدون اطلاعات بیشتر، نمی‌توان با قطعیت گفت که انیسا درس می‌خواند یا خیر.
  • درباره خاویر: در مدل {{ I_3 }} مقدارش ۱ است ({{ X=1 }})، ولی در دو مدل {{ I_1 }} و {{ I_2 }} درس نمی‌خواند ({{ X=0 }}). بنابراین بدون اطلاعات بیشتر، نمی‌توان با قطعیت گفت که خاویر درس می‌خواند یا خیر.
  • تنها می‌توان افزود: اگر خاویر درس بخواند، الزاماً انیسا نیز درس می‌خواند (مطابق مدل {{ I_3 }}).
