Exercice 1 – Arbre de syntaxe abstraite et notation préfixe

Contexte et compétences visées

Cet exercice évalue la maîtrise de la structure arborescente des formules (AST), la capacité à identifier le connecteur principal, la conversion en notation préfixe (notation polonaise), et l'application stricte des conventions de priorité de Sorbonne Université (priorité décroissante et associativité à droite).

Question 1.1 AST et notation préfixe de {{ F_1 = eg(p \land (q \Rightarrow ((q \lor r) \land q))) }}

Énoncé original

Pour la formule suivante où {{ p, q }} et {{ r }} sont des symboles de propositions :

  • dessiner son arbre de syntaxe abstraite
  • écrire la formule en notation préfixe

{{ F_1 = eg(p \land (q \Rightarrow ((q \lor r) \land q))) }}

Stratégie et décomposition

La formule est entièrement parenthésée. Pour trouver la racine, on suit la règle d'induction :

  1. Le symbole le plus externe est {{ eg }}. Il porte sur toute la sous-formule parenthésée. La racine de l'AST est donc {{ eg }}.
  2. Son unique fils est la conjonction {{ \land }} entre {{ p }} et {{ (q \Rightarrow ((q \lor r) \land q)) }}.
  3. Le fils droit de {{ \land }} est une implication {{ \Rightarrow }} ayant pour fils gauche {{ q }} et pour fils droit une conjonction {{ \land }}.
  4. Cette seconde conjonction a pour fils gauche la disjonction {{ (q \lor r) }} et pour fils droit la feuille {{ q }}.
Solution détaillée et notation préfixe

Parcours préfixe (Racine → Fils Gauche → Fils Droit)

Appliquons récursivement l'algorithme de parcours préfixe :

  • Niveau 1 : ¬ suivi du parcours de son sous-arbre.
  • Niveau 2 : ∧ suivi de la feuille p et du sous-arbre droit.
  • Niveau 3 : ⇒ suivi de la feuille q et du sous-arbre droit.
  • Niveau 4 : ∧ suivi du sous-arbre gauche et de la feuille q.
  • Niveau 5 : ∨ suivi des feuilles q et r.

En rassemblant l'ensemble sans aucune parenthèse, la notation préfixe exacte est :

¬ ∧ p ⇒ q ∧ ∨ q r q

Vérification : Le nombre de symboles de connecteurs binaires (4) + connecteur unaire (1) = 5 connecteurs. Le nombre de feuilles est 5 (p, q, q, r, q). La formule préfixe possède bien 10 symboles.

Question 1.2 AST et notation préfixe de {{ F_2 = eg p \land q \Rightarrow q \lor r \land q }}

Énoncé original

Pour la formule {{ F_2 = eg p \land q \Rightarrow q \lor r \land q }} :

  • dessiner son arbre de syntaxe abstraite
  • écrire la formule en notation préfixe

Rétablissement impératif des parenthèses d'après les priorités Sorbonne

La formule {{ F_2 }} comporte zéro parenthèse. Appliquons rigoureusement la règle {{ eg > \land > \lor > \Rightarrow }} :

  1. {{ eg }} est prioritaire : {{ ( eg p) }}.
  2. {{ \land }} est prioritaire sur {{ \lor }} et {{ \Rightarrow }} :
    • À gauche : {{ (( eg p) \land q) }}.
    • À droite : {{ (r \land q) }}.
  3. {{ \lor }} est prioritaire sur {{ \Rightarrow }} : la partie droite devient {{ (q \lor (r \land q)) }}.
  4. Le connecteur de priorité la plus faible est l'implication centrale {{ \Rightarrow }}. C'est donc le connecteur principal (la racine) !

Formule totalement parenthésée : {{ (( eg p) \land q) \Rightarrow (q \lor (r \land q)) }}.

Solution détaillée et notation préfixe

Notation préfixe de {{ F_2 }}

La racine est {{ \Rightarrow }} :

  • Sous-arbre gauche : ∧ ¬ p q
  • Sous-arbre droit : ∨ q ∧ r q

Ce qui donne en notation préfixe :

⇒ ∧ ¬ p q ∨ q ∧ r q
Question 2.1 Parenthésage de {{ F_3 = p \land q \land r \land s }}

Énoncé original

Parenthéser la formule suivante en respectant la priorité des opérateurs :

{{ F_3 = p \land q \land r \land s }}

Solution détaillée et justification Sorbonne

Règle d'associativité à droite (Sorbonne Cours 1, Slide 11)

Tous les opérateurs sont identiques ({{ \land }}), ils ont donc la même priorité. La convention du cours stipule impérativement :

« Priorité égale : sous-formule de droite prioritaire. »

Déroulement des regroupements pas à pas depuis la droite :

  1. Regroupement des deux atomes les plus à droite : {{ (r \land s) }}.
  2. Regroupement avec l'atome précédent : {{ (q \land (r \land s)) }}.
  3. Regroupement final avec {{ p }} : {{ (p \land (q \land (r \land s))) }}.

Réponse finale d'examen :

{{ (p \land (q \land (r \land s))) }}

Erreur fatale à éviter : Écrire (((p ∧ q) ∧ r) ∧ s). Même si la conjonction est sémantiquement associative en algèbre booléenne, syntaxiquement l'arbre obtenu serait faux selon la convention officielle du cours de la Sorbonne !

Question 2.2 Parenthésage de {{ F_4 = p \Rightarrow q \land eg r \Rightarrow p \lor q }}

Énoncé original

Parenthéser la formule suivante en respectant la priorité des opérateurs :

{{ F_4 = p \Rightarrow q \land eg r \Rightarrow p \lor q }}

Solution détaillée pas-à-pas

Application rigoureuse de la hiérarchie {{ eg > \land > \lor > \Rightarrow }}

  1. Niveau 1 ({{ eg }}) : Négation la plus forte sur {{ r }} : on obtient (¬ r).
  2. Niveau 2 ({{ \land }}) : Conjonction q ∧ (¬ r) : on obtient (q ∧ (¬ r)).
  3. Niveau 3 ({{ \lor }}) : Disjonction p ∨ q : on obtient (p ∨ q).
  4. Il reste deux implications : p ⇒ (q ∧ (¬ r)) ⇒ (p ∨ q).
  5. Niveau 4 (associativité à droite de {{ \Rightarrow }}) : En cas d'implications multiples en chaîne, la sous-formule de droite est prioritaire !
    On regroupe donc d'abord : ((q ∧ (¬ r)) ⇒ (p ∨ q)).
    Puis l'implication globale depuis p :

Réponse finale d'examen :

{{ (p \Rightarrow ((q \land ( eg r)) \Rightarrow (p \lor q))) }}

Exercice 2 – Implication et formalisation du langage naturel

Contexte de l'exercice

Soient les propositions atomiques :

  • {{ p_1 }} : « il fait beau »
  • {{ p_2 }} : « je me promène »

On étudie la situation concrète où il ne fait pas beau et je me promène, ce qui correspond à l'interprétation formelle :

{{ I(p_1) = 0 \quad ext{et} \quad I(p_2) = 1 }}

Questions 1 & 2 Traduction formelle et évaluation des 6 énoncés
Analyse détaillée des 6 énoncés sous {{ I(p_1)=0, I(p_2)=1 }}
N° Énoncé en français Formule logique Calcul {{ [F]^I }} sous {{ I(p_1)=0, I(p_2)=1 }} Statut
1 « S'il fait beau, je me promène » {{ p_1 \Rightarrow p_2 }} {{ 0 \Rightarrow 1 = 1 }} VÉRIFIÉ
2 « Pour que je me promène, il faut qu'il fasse beau » {{ p_2 \Rightarrow p_1 }} {{ 1 \Rightarrow 0 = 0 }} NON VÉRIFIÉ
3 « Je ne me promène que s'il fait beau » {{ p_2 \Rightarrow p_1 }} {{ 1 \Rightarrow 0 = 0 }} NON VÉRIFIÉ
4 « Je me promène dès qu'il fait beau » {{ p_1 \Rightarrow p_2 }} {{ 0 \Rightarrow 1 = 1 }} VÉRIFIÉ
5 « Je me promène seulement s'il fait beau » {{ p_2 \Rightarrow p_1 }} {{ 1 \Rightarrow 0 = 0 }} NON VÉRIFIÉ
6 « Pour que je me promène, il suffit qu'il fasse beau » {{ p_1 \Rightarrow p_2 }} {{ 0 \Rightarrow 1 = 1 }} VÉRIFIÉ

Synthèse théorique indispensable

  • Condition suffisante (« il suffit », « si », « dès que ») : Le beau temps suffit à provoquer la promenade → {{ p_1 \Rightarrow p_2 }}. Comme {{ p_1 }} est faux ({{ 0 }}), l'implication est automatiquement vraie par le principe d'explosion ! Donc 1, 4 et 6 sont vérifiés.
  • Condition nécessaire (« il faut », « seulement si », « ne ... que si ») : Le beau temps est obligatoire pour se promener. Si je me promène, c'est qu'il fait beau → {{ p_2 \Rightarrow p_1 }}. Or je me promène ({{ p_2=1 }}) sans beau temps ({{ p_1=0 }}). L'implication {{ 1 \Rightarrow 0 }} est fausse. Donc 2, 3 et 5 sont non vérifiés.

Question 2 Énigme judiciaire : Anna et Julie

Énoncé original

Anna et Julie sont interrogées au sujet d'un crime et déclarent :

  • Anna : « Julie est coupable. »
  • Julie : « Si je suis coupable, alors Anna l'est aussi. »

Propositions : {{ A }} : « Anna est coupable », {{ J }} : « Julie est coupable ».

  1. Donner la formule {{ F_1 }} (affirmation d'Anna) et {{ F_2 }} (affirmation de Julie).
  2. Soit {{ F_3 = F_1 \lor F_2 }} : (a) Calculer sa table de vérité, (b) Que peut-on en conclure ?
  3. Soit {{ F_4 = F_1 \land F_2 }} : (a) Calculer sa table de vérité, (b) Que peut-on en conclure ?
Correction pas à pas et conclusions

1. Formalisation

  • Déclaration d'Anna : {{ F_1 = J }}
  • Déclaration de Julie : {{ F_2 = J \Rightarrow A }}

2. Étude de {{ F_3 = F_1 \lor F_2 = J \lor (J \Rightarrow A) }}

{{ A }} {{ J }} {{ F_1 = J }} {{ F_2 = J \Rightarrow A }} {{ F_3 = F_1 \lor F_2 }}

Conclusion pour {{ F_3 }} : La formule {{ F_3 }} est une tautologie (formule valide). Elle vaut 1 dans toutes les interprétations. On peut donc en conclure avec certitude qu'au moins l'une des deux suspectes dit toujours la vérité, quelle que soit la culpabilité réelle d'Anna ou de Julie !

3. Étude de {{ F_4 = F_1 \land F_2 = J \land (J \Rightarrow A) }}

Conclusion pour {{ F_4 }} : {{ F_4 }} n'admet qu'un seul et unique modèle : {{ A=1, J=1 }}. Par conséquent, si toutes les deux disent la vérité, alors Anna et Julie sont toutes les deux coupables.

Question 3 Énigme de l'examen : Anissa, Xavier et Jennifer

Énoncé original

Anissa, Xavier et Jennifer ont un examen de logique à passer. On suppose que :

  • {{ H_1 }} : L'un des trois au moins révisera pour l'examen.
  • {{ H_2 }} : Si Anissa ne révise pas, alors Xavier non plus.
  • {{ H_3 }} : Si Anissa révise, alors Jennifer aussi.

Propositions : {{ A }} : « Anissa révise », {{ X }} : « Xavier révise », {{ J }} : « Jennifer révise ».

  1. Formaliser ces trois hypothèses.
  2. Peut-on dire qui révisera ? qui ne révisera pas ?
Résolution sémantique rigoureuse

1. Formalisation mathématique

  • {{ H_1 : A \lor X \lor J }} (au moins l'un des trois)
  • {{ H_2 : eg A \Rightarrow eg X }} (ce qui équivaut par contraposition à {{ X \Rightarrow A }})
  • {{ H_3 : A \Rightarrow J }}

2. Recherche des modèles de la théorie {{ \mathcal{T} = \{H_1, H_2, H_3\} }}

Dressons la table de vérité des 3 hypothèses sur les {{ 2^3 = 8 }} interprétations possibles :

{{ A }} {{ X }} {{ J }} {{ H_1 }} {{ H_2 : eg A \Rightarrow eg X }} {{ H_3 : A \Rightarrow J }} {{ H_1 \land H_2 \land H_3 }}

3. Déductions logiques certaines

Il existe exactement 3 interprétations qui satisfont simultanément les trois hypothèses :

  • {{ I_1 = \{A=0, X=0, J=1\} }}
  • {{ I_2 = \{A=1, X=0, J=1\} }}
  • {{ I_3 = \{A=1, X=1, J=1\} }}

Conclusion mathématique d'examen :

  • Dans les trois modèles, on a sans exception {{ J = 1 }}. On peut donc affirmer avec une certitude absolue que Jennifer révisera ({{ \mathcal{T} \models J }}).
  • Pour Anissa : elle révise dans {{ I_2 }} et {{ I_3 }} ({{ A=1 }}), mais ne révise pas dans {{ I_1 }} ({{ A=0 }}). On ne peut donc pas déterminer si Anissa révisera ou non.
  • Pour Xavier : il révise dans {{ I_3 }} ({{ X=1 }}), mais ne révise pas dans {{ I_1 }} et {{ I_2 }} ({{ X=0 }}). On ne peut donc pas déterminer si Xavier révisera ou non.
  • On peut seulement ajouter : si Xavier révise, alors nécessairement Anissa révise aussi (modèle {{ I_3 }}).
