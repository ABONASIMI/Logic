1. Spécification des formules et fonction decompose

Grammaire Python du sujet de TP

Les formules traitées en machine sont représentées sous forme de chaînes de caractères parenthésées selon les règles suivantes :

  • TRUE et FALSE sont des formules logiques.
  • Toute formule atomique (chaîne de caractères alphanumérique comme "p", "bonjour") est une formule logique.
  • Si {{ F }} est une formule, alors NOT F est une formule.
  • Si {{ F_1 }} et {{ F_2 }} sont des formules, alors F1 AND F2, F1 OR F2 et F1 IMPLIES F2 sont des formules.

La fonction primitive : decompose(formule: str)

L'université fournit (ou demande d'utiliser) la fonction decompose qui identifie le connecteur principal à la racine de l'AST et sépare les sous-formules :

def decompose(formule: str) -> tuple[str, list[str]]:
    """Analyse syntaxique d'une formule parenthésée.
    Renvoie le couple (connecteur_principal, [sous_formules])."""
    formule = formule.strip()
    # Cas 1 : négation unaire NOT
    if formule.startswith("NOT "):
        return ("NOT", [formule[4:].strip()])
    # Cas 2 : formule atomique ou constante (pas de connecteur binaire externe)
    # On recherche les connecteurs binaires au niveau 0 de parenthèses
    niveau = 0
    for i, car in enumerate(formule):
        if car == '(':
            niveau += 1
        elif car == ')':
            niveau -= 1
        elif niveau == 0:
            for op in ["IMPLIES", "AND", "OR"]:
                if formule[i:].startswith(op + " "):
                    gauche = formule[:i].strip()
                    droite = formule[i + len(op) + 1:].strip()
                    # Retirer les parenthèses englobantes externes si besoin
                    if gauche.startswith('(') and gauche.endswith(')'): gauche = gauche[1:-1].strip()
                    if droite.startswith('(') and droite.endswith(')'): droite = droite[1:-1].strip()
                    return (op, [gauche, droite])
    # Si aucun connecteur externe n'a été trouvé, c'est une feuille atomique
    return (formule, [])

2. Exercice 1 – Évaluation des formules booléennes pures (eval_TF)

Exercice 1 Fonction récursive eval_TF(formule: str) → bool

Énoncé officiel

Écrivez une fonction récursive eval_TF(formule: str) -> bool qui prend en paramètre une formule construite uniquement à partir de TRUE et FALSE et qui calcule sa valeur de vérité booléenne.

Exemples exigés :

  • eval_TF("TRUE AND FALSE") doit renvoyer False.
  • eval_TF("(TRUE AND FALSE) OR (TRUE OR (TRUE AND FALSE))") doit renvoyer True.
Implémentation et explication pas à pas

Code source complet et commenté

def eval_TF(formule: str) -> bool:
    """Évalue récursivement une formule composée exclusivement de TRUE et FALSE."""
    formule = formule.strip()
    
    # 1. Cas de base : feuilles constantes
    if formule == "TRUE":
        return True
    if formule == "FALSE":
        return False
        
    # 2. Décomposition de la formule par son connecteur principal
    connecteur, sous_formules = decompose(formule)
    
    # Cas de la négation NOT (connecteur unaire)
    if connecteur == "NOT":
        return not eval_TF(sous_formules[0])
        
    # Cas des connecteurs binaires
    if connecteur == "AND":
        return eval_TF(sous_formules[0]) and eval_TF(sous_formules[1])
        
    if connecteur == "OR":
        return eval_TF(sous_formules[0]) or eval_TF(sous_formules[1])
        
    if connecteur == "IMPLIES":
        # A IMPLIES B est équivalent à (not A) or B
        val_gauche = eval_TF(sous_formules[0])
        val_droite = eval_TF(sous_formules[1])
        return (not val_gauche) or val_droite
        
    raise ValueError(f"Connecteur inconnu ou formule mal formée : {connecteur}")

Complexité algorithmique : En notant {{ n }} le nombre de connecteurs dans la formule, l'arbre d'appels récursifs visite chaque nœud de l'AST exactement une fois. La complexité en temps est donc {{ O(n) }}, ce qui est optimal.

3. Exercice 2 – Formules atomiques et valuations (genere_fa, eval_formule)

Exercice 2 – Question 1 Extraction des atomes : genere_fa(formule: str) → set[str]

Énoncé officiel

Écrivez la fonction genere_fa(formule: str) -> set[str] qui renvoie l'ensemble des formules atomiques contenues dans formule (en excluant TRUE et FALSE).

Exemples exigés :

  • genere_fa("TRUE") renvoie set()
  • genere_fa("p AND FALSE") renvoie {'p'}
  • genere_fa("hello OR (aurevoir AND salut)") renvoie {'hello', 'aurevoir', 'salut'}
Implémentation récursive propre 
def genere_fa(formule: str) -> set[str]:
    """Extrait récursivement l'ensemble des symboles de proposition d'une formule."""
    formule = formule.strip()
    
    # Décomposition syntaxique
    connecteur, sous_formules = decompose(formule)
    
    # Si la liste des sous-formules est vide, c'est une feuille de l'AST
    if len(sous_formules) == 0:
        # Les constantes logiques TRUE et FALSE ne sont pas des variables atomiques
        if connecteur in ("TRUE", "FALSE"):
            return set()
        return {connecteur}
        
    # Si c'est un connecteur (NOT, AND, OR, IMPLIES), on réunit les atomes de chaque sous-branche
    atomes = set()
    for sf in sous_formules:
        atomes |= genere_fa(sf)
    return atomes
Exercice 2 – Question 2 Évaluation avec dictionnaire : eval_formule(formule: str, valuation: dict) → bool

Énoncé officiel

Écrivez une fonction récursive eval_formule(formule: str, valuation: dict) -> bool qui prend en paramètre une formule et un dictionnaire associant une valeur booléenne à chaque atome (par exemple {'p': True, 'q': False}) et renvoie la valeur booléenne résultante.

Implémentation et analyse 
def eval_formule(formule: str, valuation: dict[str, bool]) -> bool:
    """Calcule [F]^I sous l'interprétation définie par le dictionnaire valuation."""
    formule = formule.strip()
    connecteur, sous_formules = decompose(formule)
    
    # Cas de base : feuille de l'arbre
    if len(sous_formules) == 0:
        if connecteur == "TRUE":
            return True
        if connecteur == "FALSE":
            return False
        # Récupération de la valeur de vérité dans le dictionnaire I
        if connecteur in valuation:
            return valuation[connecteur]
        raise KeyError(f"Variable atomique non définie dans la valuation : '{connecteur}'")
        
    # Cas unaire : NOT
    if connecteur == "NOT":
        return not eval_formule(sous_formules[0], valuation)
        
    # Cas binaires : AND, OR, IMPLIES
    if connecteur == "AND":
        return eval_formule(sous_formules[0], valuation) and eval_formule(sous_formules[1], valuation)
        
    if connecteur == "OR":
        return eval_formule(sous_formules[0], valuation) or eval_formule(sous_formules[1], valuation)
        
    if connecteur == "IMPLIES":
        gauche = eval_formule(sous_formules[0], valuation)
        droite = eval_formule(sous_formules[1], valuation)
        return (not gauche) or droite
        
    raise ValueError(f"Opérateur invalide : {connecteur}")

4. Exercice 3 – Génération de tables de vérité complètes (cree_table)

Principe de construction de l'ensemble des parties {{ \mathcal{P}(E) }}

Pour tester toutes les interprétations possibles de {{ n }} variables propositionnelles, il faut construire l'ensemble des {{ 2^n }} parties de l'ensemble des atomes. L'énoncé prescrit l'algorithme inductif suivant :

  • {{ \mathcal{P}(E_0) = \{\emptyset\} }}
  • {{ \mathcal{P}(E_{i+1}) = \mathcal{P}(E_i) \cup \{A \cup \{x_i\} \mid A \in \mathcal{P}(E_i)\} }}
Exercice 3 – Questions 1, 2 et 3 Génération des parties, des valuations et construction de la table
Implémentation complète de genere_sous_ensembles, genere_interpretations et cree_table 
def genere_sous_ensembles(ensemble: set) -> list[set]:
    """Calcule P(E) de manière inductive selon la spécification du TP."""
    liste_elements = list(ensemble)
    parties = [set()]  # P(E_0) = {∅}
    
    for x in liste_elements:
        nouvelles_parties = []
        for s in parties:
            nouvelles_parties.append(s | {x})
        parties.extend(nouvelles_parties)
        
    return parties

def genere_interpretations(fa: set[str]) -> list[dict[str, bool]]:
    """Associe à chaque partie P une valuation v_P où v_P(q) = True ssi q in P."""
    parties = genere_sous_ensembles(fa)
    interpretations = []
    
    for P in parties:
        val = {atome: (atome in P) for atome in fa}
        interpretations.append(val)
        
    return interpretations

def cree_table(formule: str) -> list[list]:
    """Construit la table de vérité complète sous forme d'une liste de listes."""
    atomes = sorted(list(genere_fa(formule)))
    val_liste = genere_interpretations(set(atomes))
    
    # 1. En-tête de la table de vérité
    table = [atomes + [formule]]
    
    # 2. Lignes d'évaluation pour chaque interprétation
    for val in val_liste:
        ligne = [val[a] for a in atomes]
        res = eval_formule(formule, val)
        ligne.append(res)
        table.append(ligne)
        
    return table
