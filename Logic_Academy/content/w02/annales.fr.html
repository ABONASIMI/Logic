1. Partiel 2017-2018 – Exercice 3 : Validité et déductions formelles (20 points)

Référence de l'épreuve

Épreuve : Évaluation de mi-semestre (Partiel) 2017-2018 — Logique UL2IN007.
Barème officiel : 20 points (Question 1 : 2 pts ; Question 2 : 5 + 6 + 3 + 2 + 2 = 18 pts).
Règle d'or : Aucune table de vérité n'est autorisée. Tous les calculs s'effectuent par l'algèbre de Boole.

Question 1 (2 points) Définition mathématique d'une formule valide

Énoncé officiel

Donner la définition d'une formule valide.

Corrigé officiel de la Question 1

Une formule {{ F }} est valide si et seulement si pour toute interprétation (ou structure) {{ \mathcal{M} }}, on a :

{{ [F]^{\mathcal{M}} = 1 }}

(Barème officiel : 2/2 si la quantification universelle « pour toute interprétation » est explicitement formulée).

Question 2 (a) & (b) (11 points) Traduction brute et preuve de validité par calcul équationnel

Énoncé officiel

Soit {{ F }} la formule {{ ((A \lor \neg B) \land B) \Rightarrow A }}.

  • (a) (5 points) : Étant donnée une structure {{ \mathcal{M} }}, calculer l'expression booléenne {{ [F]^{\mathcal{M}} }} en fonction de {{ I_{\mathcal{M}}(A) }} et {{ I_{\mathcal{M}}(B) }} (sans effectuer de simplification).
  • (b) (6 points) : En utilisant un raisonnement équationnel, montrer que {{ F }} est une formule valide (indiquer à chaque étape le nom de l'équivalence utilisée).
Corrigé officiel des Questions 2(a) et 2(b)

(a) Traduction inductive brute sans simplification (5 points)

Appliquons pas à pas la définition inductive de l'évaluation :

{{ [F]^{\mathcal{M}} = [((A \lor \neg B) \land B) \Rightarrow A]^{\mathcal{M}} }}
{{ = \overline{[ (A \lor \neg B) \land B ]^{\mathcal{M}}} + [A]^{\mathcal{M}} }} \quad (Définition de l'implication)
{{ = \overline{ [A \lor \neg B]^{\mathcal{M}} \cdot [B]^{\mathcal{M}} } + [A]^{\mathcal{M}} }} \quad (Définition de la conjonction)
{{ = \overline{ ([A]^{\mathcal{M}} + [\neg B]^{\mathcal{M}}) \cdot [B]^{\mathcal{M}} } + [A]^{\mathcal{M}} }} \quad (Définition de la disjonction)
{{ = \overline{ (I_{\mathcal{M}}(A) + \overline{I_{\mathcal{M}}(B)}) \cdot I_{\mathcal{M}}(B) } + I_{\mathcal{M}}(A) }} \quad (Évaluation des atomes et de la négation)

(b) Preuve de validité par raisonnement équationnel (6 points)

Posons pour alléger l'écriture {{ a = I_{\mathcal{M}}(A) }} et {{ b = I_{\mathcal{M}}(B) }} :

{{ [F]^{\mathcal{M}} = \overline{ (a + \overline{b}) \cdot b } + a }}
{{ \equiv (\overline{a + \overline{b}} + \overline{b}) + a }} \quad (Loi de De Morgan sur la négation externe)
{{ \equiv ( (\overline{a} \cdot \overline{\overline{b}}) + \overline{b} ) + a }} \quad (Loi de De Morgan sur {{ \overline{a + \overline{b}} }})
{{ \equiv ( (\overline{a} \cdot b) + \overline{b} ) + a }} \quad (Involution : {{ \overline{\overline{b}} = b }})
{{ \equiv ( (\overline{a} + \overline{b}) \cdot (b + \overline{b}) ) + a }} \quad (Distributivité de + sur {{ \cdot }})
{{ \equiv ( (\overline{a} + \overline{b}) \cdot 1 ) + a }} \quad (Complémentarité : {{ b + \overline{b} = 1 }})
{{ \equiv (\overline{a} + \overline{b}) + a }} \quad (Élément neutre de {{ \cdot }})
{{ \equiv (\overline{a} + a) + \overline{b} }} \quad (Commutativité et associativité de +)
{{ \equiv 1 + \overline{b} }} \quad (Complémentarité : {{ \overline{a} + a = 1 }})
{{ \equiv 1 }} \quad (Élément absorbant : {{ 1 + x = 1 }})

Puisque {{ [F]^{\mathcal{M}} = 1 }} pour toute interprétation {{ \mathcal{M} }}, {{ F }} est une formule valide.

Question 2 (c), (d) & (e) (7 points) Déductions sémantiques et propriétés métamathématiques

Énoncé officiel

  • (c) (3 points) : A-t-on {{ (A \lor \neg B) \land B \models A }} ? (justifier).
  • (d) (2 points) : Soit {{ F_1 }} une formule quelconque. A-t-on {{ \neg F \models F_1 }} ? (justifier).
  • (e) (2 points) : Soit {{ F_2 }} une formule telle que {{ F \models F_2 }}. La formule {{ F_2 }} est-elle satisfiable ? valide ? (justifier).
Corrigé officiel des Questions 2(c), 2(d) et 2(e)

(c) Conséquence sémantique {{ (A \lor \neg B) \land B \models A }} (3 points)

OUI. Par le théorème de déduction sémantique, on a l'équivalence fondamentale :

{{ P \models Q \quad \iff \quad \models (P \Rightarrow Q) }}

Comme on a prouvé à la question (b) que la formule {{ F = ((A \lor \neg B) \land B) \Rightarrow A }} est valide, on en déduit immédiatement que {{ (A \lor \neg B) \land B \models A }}.

(d) Conséquence sémantique avec la négation {{ \neg F \models F_1 }} (2 points)

OUI. Puisque {{ F }} est une formule valide, sa négation {{ \neg F }} est insatisfiable. L'ensemble des structures satisfaisant {{ \neg F }} est donc vide. Dès lors, toute interprétation qui satisfait {{ \neg F }} satisfait trivialement {{ F_1 }} par vacuité (principe ex falso quodlibet). On a donc bien {{ \neg F \models F_1 }}.

(e) Nature de {{ F_2 }} si {{ F \models F_2 }} (2 points)

Puisque {{ F }} est valide, pour toute structure {{ \mathcal{M} }} on a {{ [F]^{\mathcal{M}} = 1 }}.

Comme {{ F \models F_2 }}, toute structure qui satisfait {{ F }} doit satisfaire {{ F_2 }}. Or toutes les structures satisfont {{ F }}, donc toutes les structures satisfont obligatoirement {{ F_2 }} ({{ \forall \mathcal{M}, [F_2]^{\mathcal{M}} = 1 }}).

Conclusion : La formule {{ F_2 }} est donc valide (et donc également satisfiable).

2. Partiel 2019-2020 L2 – Exercice 3 : Preuve algébrique et relations avec G (8 points)

Référence de l'épreuve

Épreuve : Partiel L2 Informatique 2019-2020 — UE UL2IN007 Logique.
Barème officiel : 8 points (1 pt + 1 pt + 2 pts + 4 pts).
Formule étudiée : {{ F = (\neg A \Rightarrow (A \land \neg A)) \Rightarrow A }}.

Questions 1, 2(a) et 2(b) (4 points) Traduction et preuve de validité de F

Énoncé officiel

  1. Donner la définition mathématique d'une formule {{ F }} valide.
  2. Soit {{ F = (\neg A \Rightarrow (A \land \neg A)) \Rightarrow A }} :
    • (a) : Calculer l'expression booléenne {{ [F]^{\mathcal{M}} }} sans simplification.
    • (b) : Par un raisonnement équationnel, montrer que {{ F }} est valide.
Corrigé officiel pas-à-pas

1. Définition (1 point)

{{ F }} est valide ssi pour toute structure {{ \mathcal{M} }}, {{ [F]^{\mathcal{M}} = 1 }}.

2(a) Traduction brute sans simplification (1 point)

{{ [F]^{\mathcal{M}} = \overline{ [\neg A \Rightarrow (A \land \neg A)]^{\mathcal{M}} } + [A]^{\mathcal{M}} }}
{{ = \overline{ \overline{[\neg A]^{\mathcal{M}}} + [A \land \neg A]^{\mathcal{M}} } + [A]^{\mathcal{M}} }}
{{ = \overline{ \overline{\overline{I_{\mathcal{M}}(A)}} + (I_{\mathcal{M}}(A) \cdot \overline{I_{\mathcal{M}}(A)}) } + I_{\mathcal{M}}(A) }}

2(b) Raisonnement équationnel (2 points)

En posant {{ x = I_{\mathcal{M}}(A) }} :

{{ [F]^{\mathcal{M}} \equiv \overline{ x + (x \cdot \overline{x}) } + x }} \quad (Involution : {{ \overline{\overline{x}} = x }})
{{ \equiv \overline{ x + 0 } + x }} \quad (Complémentarité : {{ x \cdot \overline{x} = 0 }})
{{ \equiv \overline{x} + x }} \quad (Élément neutre : {{ x + 0 = x }})
{{ \equiv 1 }} \quad (Complémentarité : {{ \overline{x} + x = 1 }})

La formule {{ F }} est donc formellement valide.

Question 2(c) (4 points) Analyse des 4 conséquences sémantiques avec G quelconque

Énoncé officiel

Soit {{ G }} une formule quelconque. A-t-on :

  • (i) {{ G \models F }} ?
  • (ii) {{ F \models G }} ?
  • (iii) {{ G \models \neg F }} ?
  • (iv) {{ \neg F \models G }} ?

Justifier vos réponses.

Corrigé officiel des 4 déductions
  • (i) A-t-on {{ G \models F }} ? → OUI (1 point)
    Toutes les structures qui satisfont {{ G }} satisfont nécessairement {{ F }}, puisque {{ F }} est valide et est donc satisfaite par toutes les structures sans exception.
  • (ii) A-t-on {{ F \models G }} ? → NON (1 point)
    Comme {{ G }} est une formule quelconque, elle peut par exemple être une formule non satisfaite par une certaine structure {{ \mathcal{M} }} (par exemple {{ G = \text{false} }}). Cette structure satisfait pourtant {{ F }} puisque {{ F }} est valide. C'est donc un contre-modèle.
  • (iii) A-t-on {{ G \models \neg F }} ? → NON (1 point)
    {{ G }} étant quelconque, elle peut être satisfaite par une certaine structure {{ \mathcal{M} }} (par exemple {{ G = \text{true} }}). Or {{ \neg F }} est insatisfiable (car {{ F }} est valide), donc aucune structure ne satisfait {{ \neg F }}.
  • (iv) A-t-on {{ \neg F \models G }} ? → OUI (1 point)
    Puisque {{ F }} est valide, {{ \neg F }} est insatisfiable. L'ensemble des structures qui satisfont {{ \neg F }} est donc vide, ce qui rend l'implication universellement vraie par vacuité.
