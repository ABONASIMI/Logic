1. Au-delà des tables de vérité : l'explosion combinatoire

چرا باید جدول‌های درستی را کنار بگذاریم؟

یک فرمول با {{ n }} متغیر مستقل به جدول درستی با {{ 2^n }} سطر نیاز دارد. در مسائل صنعتی واقعی (تأیید درستی پردازنده‌ها، حل‌کننده‌های صنعتی قیود)، فرمول‌ها با هزاران متغیر سر و کار دارند. حتی برای ۳۰ متغیر ({{ n = 30 }})، جدول بیش از یک میلیارد سطر ({{ 2^{30} pprox 10^9 }}) خواهد داشت! هیچ کامپیوتر مدرنی قادر به پیمایش چنین جدولی نیست.

به همین دلیل، درس منطق دانشگاه سوربن روش جبری و استنتاجی را آموزش می‌دهد: دستکاری نمادین ارزش حقیقت {{ [F]^I }} با قوانین جبر بولی، تا خواص کلی برای تمامی تعبیرها به طور هم‌زمان و یک‌جا اثبات گردند.

2. L'Algèbre de Boole minimale {{ (\mathbb{B}, \cdot, +, \overline{\phantom{x}}) }}

ساختار جبر بولی دانشگاه سوربن (اسلاید ۴ درس ۲)

جبر بولی کمینه به صورت چهارگانه {{ (\mathbb{B}, \cdot, +, \overline{\phantom{x}}) }} تعریف می‌شود که در آن {{ \mathbb{B} = \{0, 1\} }} مجموعه‌ای دارای دو عنصر متمایز است ({{ 0 eq 1 }}). برای تمام مقادیر {{ a, b, c \in \mathbb{B} }} خواص بنیادی زیر برقرار است:

خاصیت جبری عملگر عطفی ضرب ({{ \cdot }}) عملگر فصلی جمع ({{ + }})
جابجایی {{ a \cdot b = b \cdot a }} {{ a + b = b + a }}
شرکت‌پذیری {{ a \cdot (b \cdot c) = (a \cdot b) \cdot c }} {{ a + (b + c) = (a + b) + c }}
توزیع‌پذیری متقابل {{ a \cdot (b + c) = (a \cdot b) + (a \cdot c) }} {{ a + (b \cdot c) = (a + b) \cdot (a + c) }} (تله مهم!)
عنصر همانی (خنثی) {{ a \cdot 1 = a }} {{ a + 0 = a }}
عنصر جاذب (پوچ‌ساز) {{ a \cdot 0 = 0 }} {{ a + 1 = 1 }}
بت‌خواری (خاصیت ایندمپوتنت) {{ a \cdot a = a }} {{ a + a = a }}
متمم‌داری {{ a \cdot \overline{a} = 0 }} {{ a + \overline{a} = 1 }}
نفی مضاعف {{ \overline{\overline{a}} = a }}
قوانین دمرگان {{ \overline{a \cdot b} = \overline{a} + \overline{b} }} {{ \overline{a + b} = \overline{a} \cdot \overline{b} }}
جذب {{ a \cdot (a + b) = a }} {{ a + (a \cdot b) = a }}
قاعده ساده‌سازی {{ a \cdot (\overline{a} + b) = a \cdot b }} {{ a + \overline{a} \cdot b = a + b }}

تله امتحانی بسیار حساس: در حساب معمولی اعداد حقیقی، جمع هرگز بر روی ضرب توزیع نمی‌شود. اما در جبر بولی، جمع بولی بر روی ضرب توزیع‌پذیر است: {{ a + (b \cdot c) = (a + b) \cdot (a + c) }} !

3. Traduction inductive et raisonnement équationnel sur {{ [F]^I }}

ترجمه استقرایی فرمول منطقی به عبارت جبر بولی

فرض کنید تعبیر {{ I }} داده شده باشد. تبدیل فرمول {{ F }} به عبارت بولی به صورت کاملاً مکانیکی انجام می‌شود:

  • {{ [ ext{true}]^I = 1 }} \quad و \quad {{ [ ext{false}]^I = 0 }}
  • برای هر نماد اتمی {{ p }} داریم: {{ [p]^I = I(p) }}
  • {{ [ eg F]^I = \overline{[F]^I} }}
  • {{ [F_1 \land F_2]^I = [F_1]^I \cdot [F_2]^I }}
  • {{ [F_1 \lor F_2]^I = [F_1]^I + [F_2]^I }}
  • {{ [F_1 \Rightarrow F_2]^I = \overline{[F_1]^I} + [F_2]^I }}
  • {{ [F_1 \Leftrightarrow F_2]^I = [F_1]^I \cdot [F_2]^I + \overline{[F_1]^I} \cdot \overline{[F_2]^I} }}

نمونه استدلال معادلاتی رسمی درس سوربن (اسلاید ۱۲)

فرمول مشهور پِیرس را در نظر بگیرید: {{ F = (F_1 \Rightarrow F_2) \Rightarrow F_1 }}. ارزش تعبیر {{ [F]^I }} را ساده می‌کنیم:

{{ [F]^I = \overline{[F_1 \Rightarrow F_2]^I} + [F_1]^I }} \quad (تعریف شرطی بیرونی)
{{ \equiv \overline{\overline{[F_1]^I} + [F_2]^I} + [F_1]^I }} \quad (تعریف شرطی درونی)
{{ \equiv (\overline{\overline{[F_1]^I}} \cdot \overline{[F_2]^I}) + [F_1]^I }} \quad (قانون دمرگان)
{{ \equiv ([F_1]^I \cdot \overline{[F_2]^I}) + [F_1]^I }} \quad (نفی مضاعف)
{{ \equiv [F_1]^I }} \quad (قانون جذب : {{ x + x \cdot y = x }})

بدین ترتیب در ۴ خط استدلال جبری محض اثبات شد که تحت هر تعبیر ممکن {{ I }}، همواره {{ [F]^I = [F_1]^I }} است؛ اگر {{ F_1 }} و {{ F_2 }} دارای متغیرهای متعدد بودند، اثبات با جدول به هزاران سطر نیاز داشت!

4. Validité, satisfiabilité et insatisfiabilité sans table de vérité

تعاریف دقیق ریاضی و روش‌های اثبات برگه امتحانی

  • فرمول صدق‌پذیر (Satisfiable): {{ \exists I, [F]^I = 1 }}.
    روش بدون جدول: کافی است یک تعبیر مشخص {{ I_0 }} ارائه داده و نشان دهید {{ [F]^{I_0} = 1 }}.
  • فرمول معتبر (Tautology / Valid - نماد {{ \models F }}): {{ orall I, [F]^I = 1 }}.
    روش بدون جدول: با استدلال معادلاتی نشان دهید {{ [F]^I \equiv 1 }} تحت هر تعبیر دلخواه {{ I }}، یا با برهان خلف با فرض {{ [F]^I = 0 }} به تناقض برسید.
  • فرمول ناسازگار یا تناقض (Unsatisfiable): {{ orall I, [F]^I = 0 }}.
    روش بدون جدول: اثبات جبری این‌که {{ [F]^I \equiv 0 }} برای هر {{ I }}.
  • فرمول غیرمعتبر (رد اعتبار): کافی است یک پادمدل (Counter-model) ارائه دهید، یعنی تعبیری {{ I_c }} که در آن {{ [F]^{I_c} = 0 }} باشد.

5. Conséquence sémantique formelle ({{ \mathcal{H} \models F }}) et contre-modèles

تعریف دقیق استلزام معنایی (اسلاید ۱۸ درس ۲)

فرض کنید {{ \mathcal{H} = \{H_1, H_2, \dots, H_k\} }} مجموعه‌ای متناهی از فرضیات و {{ F }} فرمول نتیجه باشد. می‌گوییم {{ F }} یک نتیجه معنایی از {{ \mathcal{H} }} است (با نماد {{ \mathcal{H} \models F }}) اگر و فقط اگر:

تحت هر تعبیر {{ I }}، اگر {{ [H_1 \land H_2 \land \dots \land H_k]^I = 1 }} باشد، آنگاه {{ [F]^I = 1 }} است.

به بیان ساده‌تر: هر مدلی که تمام فرضیات {{ \mathcal{H} }} را برآورده کند، الزاماً مدلی برای نتیجه {{ F }} نیز هست.

چگونه {{ \mathcal{H} \models F }} را بدون جدول درستی اثبات یا رد کنیم؟

  1. برای اثبات درستی استلزام {{ \mathcal{H} \models F }} :
    یک تعبیر دلخواه {{ I }} در نظر می‌گیریم که در آن {{ [H_1]^I = 1, \dots, [H_k]^I = 1 }} باشد. با زنجیره‌ای از استنتاج‌های صوری اجتناب‌ناپذیر نشان می‌دهیم که اجباراً {{ [F]^I = 1 }} خواهد بود.
  2. برای رد استلزام (اثبات نادرستی {{ \mathcal{H} \models F }}) :
    کافی است یک پادمدل صریح {{ I_{cm} }} معرفی کنیم به طوری که:
    {{ [H_1]^{I_{cm}} = 1, \quad \dots, \quad [H_k]^{I_{cm}} = 1 \quad ext{et} \quad [F]^{I_{cm}} = 0 }}
    وجود تنها یک پادمدل، ادعای استلزام کلی را باطل می‌کند.

6. Équivalence logique et théorème de déduction sémantique

قضیه بنیادین استنتاج معنایی (Deduction Theorem)

برای هر مجموعه فرضیات {{ \mathcal{H} }} و هر دو فرمول دلخواه {{ A }} و {{ B }} داریم:

{{ \mathcal{H} \cup \{A\} \models B \quad \iff \quad \mathcal{H} \models (A \Rightarrow B) }}

به ویژه هنگامی که مجموعه فرضیات تهی باشد ({{ \mathcal{H} = \emptyset }}):

{{ A \models B \quad \iff \quad \models (A \Rightarrow B) }}

این قضیه شکوهمند پیوند ناگسستنی میان استنتاج فرامنطقی ({{ \models }}) و عملگر شرطی درون‌منطقی ({{ \Rightarrow }}) را برقرار می‌سازد.

هم‌ارزی منطقی {{ F_1 \equiv F_2 }} (با نماد {{ F_1 |\equiv| F_2 }} در جزوه سوربن)

دو فرمول را هم‌ارز منطقی می‌نامند اگر و تنها اگر تحت تمامی تعبیرها ارزش یکسانی تولید کنند:

{{ F_1 \equiv F_2 \quad \iff \quad orall I, [F_1]^I = [F_2]^I \quad \iff \quad (F_1 \models F_2 ext{ et } F_2 \models F_1) }}

میزکار تعاملی تحلیل‌های معنایی
