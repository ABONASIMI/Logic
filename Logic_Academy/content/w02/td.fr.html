Exercice 4 – Formules satisfiables et valides sans table de vérité

Question 1 Étude de {{ F_1 = (p \land \neg q) \lor (\neg p \land q) }} et {{ \neg F_1 }}

Énoncé original

On considère la formule {{ F_1 = (p \land \neg q) \lor (\neg p \land q) }}. Les formules {{ F_1 }} et {{ \neg F_1 }} sont-elles satisfiables ? Sont-elles valides ?

Solution détaillée sans table de vérité

1. Étude de la formule {{ F_1 }}

  • Satisfiabilité de {{ F_1 }} :
    Considérons l'interprétation {{ I_1 }} définie par {{ I_1(p) = 1 }} et {{ I_1(q) = 0 }}.
    Calculons {{ [F_1]^{I_1} }} :
    {{ [F_1]^{I_1} = (I_1(p) \cdot \overline{I_1(q)}) + (\overline{I_1(p)} \cdot I_1(q)) = (1 \cdot 1) + (0 \cdot 0) = 1 + 0 = 1 }}
    Puisqu'il existe au moins une interprétation {{ I_1 }} telle que {{ [F_1]^{I_1} = 1 }}, la formule {{ F_1 }} est satisfiable.
  • Validité de {{ F_1 }} :
    Pour prouver qu'une formule n'est pas valide, il suffit d'exhiber un contre-modèle.
    Considérons l'interprétation {{ I_0 }} définie par {{ I_0(p) = 0 }} et {{ I_0(q) = 0 }}.
    {{ [F_1]^{I_0} = (0 \cdot 1) + (1 \cdot 0) = 0 + 0 = 0 }}
    Puisqu'il existe une interprétation {{ I_0 }} telle que {{ [F_1]^{I_0} = 0 }}, la formule {{ F_1 }} n'est pas valide.

2. Étude de la formule {{ \neg F_1 }}

  • Satisfiabilité de {{ \neg F_1 }} :
    Sous l'interprétation {{ I_0 }} ci-dessus, on a :
    {{ [\neg F_1]^{I_0} = 1 - [F_1]^{I_0} = 1 - 0 = 1 }}
    Donc {{ I_0 }} est un modèle de {{ \neg F_1 }}. La formule {{ \neg F_1 }} est satisfiable.
  • Validité de {{ \neg F_1 }} :
    Sous l'interprétation {{ I_1 }} ci-dessus, on a :
    {{ [\neg F_1]^{I_1} = 1 - [F_1]^{I_1} = 1 - 1 = 0 }}
    Donc {{ I_1 }} est un contre-modèle de {{ \neg F_1 }}. La formule {{ \neg F_1 }} n'est pas valide.

Synthèse d'examen : {{ F_1 }} et {{ \neg F_1 }} sont toutes deux satisfiables mais non valides (formules contingentes).

Question 2 Étude de {{ F_3 = F_1 \lor F_2 }} et {{ F_4 = F_1 \land F_2 }}

Énoncé original

Soit {{ F_2 = (p \land q) \lor (\neg p \land \neg q) }}. Les formules suivantes sont-elles satisfiables ? Sont-elles valides ?

  • {{ F_3 = F_1 \lor F_2 }}
  • {{ F_4 = F_1 \land F_2 }}
Calcul algébrique rigoureux

1. Étude de {{ F_3 = F_1 \lor F_2 }}

Traduisons en expression booléenne sous une interprétation quelconque {{ I }} en posant {{ x = I(p) }} et {{ y = I(q) }} :

{{ [F_3]^I = [F_1]^I + [F_2]^I }}
{{ = (x \cdot \overline{y} + \overline{x} \cdot y) + (x \cdot y + \overline{x} \cdot \overline{y}) }}
{{ = (x \cdot \overline{y} + x \cdot y) + (\overline{x} \cdot y + \overline{x} \cdot \overline{y}) }} \quad (Commutativité et associativité)
{{ = x \cdot (\overline{y} + y) + \overline{x} \cdot (y + \overline{y}) }} \quad (Distributivité)
{{ = x \cdot 1 + \overline{x} \cdot 1 }} \quad (Complémentarité)
{{ = x + \overline{x} = 1 }} \quad (Complémentarité finale)

Puisque {{ [F_3]^I = 1 }} pour toute interprétation {{ I }}, {{ F_3 }} est valide (et donc trivialement satisfiable).

2. Étude de {{ F_4 = F_1 \land F_2 }}

Calculons {{ [F_4]^I = [F_1]^I \cdot [F_2]^I }} sous une interprétation quelconque {{ I }} :

{{ [F_4]^I = (x \cdot \overline{y} + \overline{x} \cdot y) \cdot (x \cdot y + \overline{x} \cdot \overline{y}) }}
{{ = (x \cdot \overline{y}) \cdot (x \cdot y) + (x \cdot \overline{y}) \cdot (\overline{x} \cdot \overline{y}) + (\overline{x} \cdot y) \cdot (x \cdot y) + (\overline{x} \cdot y) \cdot (\overline{x} \cdot \overline{y}) }}
{{ = (x \cdot x) \cdot (\overline{y} \cdot y) + (x \cdot \overline{x}) \cdot (\overline{y} \cdot \overline{y}) + (\overline{x} \cdot x) \cdot (y \cdot y) + (\overline{x} \cdot \overline{x}) \cdot (y \cdot \overline{y}) }}
{{ = x \cdot 0 + 0 \cdot \overline{y} + 0 \cdot y + \overline{x} \cdot 0 = 0 + 0 + 0 + 0 = 0 }}

Puisque {{ [F_4]^I = 0 }} pour toute interprétation {{ I }}, {{ F_4 }} est insatisfiable (et donc non valide).

Exercice 5 – Conséquence sémantique formelle

Exercice 5 Analyse théorique de conséquence avec formule insatisfiable {{ F }} et contingente {{ G }}

Énoncé original

Soit {{ F }} une formule insatisfiable et {{ G }} une formule ni valide, ni non satisfiable (c'est-à-dire contingente : satisfiable et non valide). Répondre et justifier :

  • (a) A-t-on {{ F \models G }} ?
  • (b) A-t-on {{ G \models F }} ?
  • (c) A-t-on {{ \neg F \models G }} ?
  • (d) A-t-on {{ G \models \neg F }} ?
Justifications mathématiques rigoureuses

(a) A-t-on {{ F \models G }} ? → OUI

Justification : Par définition, {{ F \models G }} signifie que pour toute interprétation {{ I }}, si {{ [F]^I = 1 }}, alors {{ [G]^I = 1 }}.

Or, la formule {{ F }} est insatisfiable, ce qui signifie qu'il n'existe aucune interprétation {{ I }} telle que {{ [F]^I = 1 }}. L'implication est donc universellement vraie par vacuité (principe du faux qui implique tout : ex falso quodlibet). On a donc bien {{ F \models G }}.

(b) A-t-on {{ G \models F }} ? → NON

Justification par contre-modèle : Par hypothèse, {{ G }} est satisfiable, il existe donc au moins une interprétation {{ I_1 }} telle que {{ [G]^{I_1} = 1 }}.

Cependant, comme {{ F }} est insatisfiable, on a obligatoirement {{ [F]^{I_1} = 0 }}. L'interprétation {{ I_1 }} vérifie donc l'hypothèse ({{ [G]^{I_1} = 1 }}) mais ne vérifie pas la conclusion ({{ [F]^{I_1} = 0 }}). {{ I_1 }} est un contre-modèle explicite. Donc {{ G \not\models F }}.

(c) A-t-on {{ \neg F \models G }} ? → NON

Justification par contre-modèle : Puisque {{ F }} est insatisfiable, sa négation {{ \neg F }} est valide (pour toute interprétation {{ I }}, {{ [\neg F]^I = 1 - 0 = 1 }}).

D'autre part, comme {{ G }} n'est pas valide, il existe au moins une interprétation {{ I_0 }} telle que {{ [G]^{I_0} = 0 }}. Pour cette interprétation {{ I_0 }}, on a {{ [\neg F]^{I_0} = 1 }} et {{ [G]^{I_0} = 0 }}. L'interprétation {{ I_0 }} constitue un contre-modèle. Donc {{ \neg F \not\models G }}.

(d) A-t-on {{ G \models \neg F }} ? → OUI

Justification : Comme établi au point (c), la formule {{ \neg F }} est valide, ce qui implique que pour toute interprétation {{ I }}, {{ [\neg F]^I = 1 }}.

Dès lors, pour toute interprétation {{ I }} satisfaisant {{ G }} ({{ [G]^I = 1 }}), on a immédiatement {{ [\neg F]^I = 1 }}. Par conséquent, {{ G \models \neg F }}.

Exercice 6 – Équivalence logique et propriétés d'absorption

Exercice 6 Preuves formelles d'équivalences avec formules valides et insatisfiables

Énoncé original

Soient {{ F_1 }} et {{ F_2 }} deux formules de la logique propositionnelle.

  1. Montrer que si {{ F_1 }} est valide, alors {{ F_1 \land F_2 \equiv F_2 }}.
  2. Montrer que si {{ F_1 }} est insatisfiable, alors {{ F_1 \lor F_2 \equiv F_2 }}.
Démonstrations algébriques formelles

1. Preuve : si {{ F_1 }} est valide, alors {{ F_1 \land F_2 \equiv F_2 }}

Soit {{ I }} une interprétation quelconque. Par hypothèse, {{ F_1 }} est valide, donc {{ [F_1]^I = 1 }}.

Calculons la valeur de vérité de {{ F_1 \land F_2 }} sous {{ I }} :

{{ [F_1 \land F_2]^I = [F_1]^I \cdot [F_2]^I = 1 \cdot [F_2]^I = [F_2]^I }} \quad (1 est élément neutre de la conjonction)

Puisque cette égalité {{ [F_1 \land F_2]^I = [F_2]^I }} est vérifiée pour toute interprétation {{ I }}, on conclut par définition de l'équivalence logique que :

{{ F_1 \land F_2 \equiv F_2 }}

2. Preuve : si {{ F_1 }} est insatisfiable, alors {{ F_1 \lor F_2 \equiv F_2 }}

Soit {{ I }} une interprétation quelconque. Par hypothèse, {{ F_1 }} est insatisfiable, donc {{ [F_1]^I = 0 }}.

Calculons la valeur de vérité de {{ F_1 \lor F_2 }} sous {{ I }} :

{{ [F_1 \lor F_2]^I = [F_1]^I + [F_2]^I = 0 + [F_2]^I = [F_2]^I }} \quad (0 est élément neutre de la disjonction)

Puisque cette égalité {{ [F_1 \lor F_2]^I = [F_2]^I }} est vérifiée pour toute interprétation {{ I }}, on conclut par définition de l'équivalence logique que :

{{ F_1 \lor F_2 \equiv F_2 }}

Exercice 7 – Expressions booléennes et résolution équationnelle d'énigme

Question 1 Simplification équationnelle de {{ [F]^I }}

Énoncé original

Soit la formule {{ F = (p \land q) \land ((q \Rightarrow p) \lor \neg(p \lor q)) }} où {{ p }} et {{ q }} sont des propositions. Calculer et simplifier l'expression booléenne {{ [F]^I }} en fonction de {{ I(p) }} et {{ I(q) }} en indiquant l'équivalence utilisée à chaque étape.

Calcul pas à pas avec justifications des règles

Posons pour alléger l'écriture {{ x = I(p) }} et {{ y = I(q) }}. Développons l'expression {{ [F]^I }} :

{{ [F]^I = [p \land q]^I \cdot [(q \Rightarrow p) \lor \neg(p \lor q)]^I }}
{{ = (x \cdot y) \cdot ( [q \Rightarrow p]^I + [\neg(p \lor q)]^I ) }}
{{ = (x \cdot y) \cdot ( (\overline{y} + x) + \overline{x + y} ) }} \quad (Traduction sémantique de l'implication et de la négation)
{{ \equiv (x \cdot y) \cdot ( (\overline{y} + x) + (\overline{x} \cdot \overline{y}) ) }} \quad (Loi de De Morgan sur {{ \overline{x + y} }})
{{ \equiv (x \cdot y) \cdot ( x + (\overline{y} + \overline{x} \cdot \overline{y}) ) }} \quad (Commutativité et associativité de +)
{{ \equiv (x \cdot y) \cdot ( x + \overline{y} \cdot (1 + \overline{x}) ) }} \quad (Factorisation par {{ \overline{y} }})
{{ \equiv (x \cdot y) \cdot ( x + \overline{y} \cdot 1 ) }} \quad (Élément absorbant : {{ 1 + \overline{x} = 1 }})
{{ \equiv (x \cdot y) \cdot ( x + \overline{y} ) }} \quad (Élément neutre de {{ \cdot }})
{{ \equiv (x \cdot y) \cdot x + (x \cdot y) \cdot \overline{y} }} \quad (Distributivité de {{ \cdot }} sur {{ + }})
{{ \equiv (x \cdot x) \cdot y + x \cdot (y \cdot \overline{y}) }} \quad (Associativité et commutativité)
{{ \equiv x \cdot y + x \cdot 0 }} \quad (Idempotence {{ x \cdot x = x }} et complémentarité {{ y \cdot \overline{y} = 0 }})
{{ \equiv x \cdot y + 0 }} \quad (Élément absorbant : {{ x \cdot 0 = 0 }})
{{ \equiv x \cdot y }} \quad (Élément neutre : {{ a + 0 = a }})

Conclusion finale : {{ [F]^I = I(p) \cdot I(q) }}. La formule {{ F }} se réduit algébriquement à la simple conjonction {{ p \land q }}.

Question 2 Résolution équationnelle de l'énigme d'Anissa, Xavier et Jennifer

Énoncé original

On reprend l'énigme du Thème 1 : {{ H_1 }} : l'un au moins révise ; {{ H_2 }} : si Anissa ne révise pas, Xavier non plus ; {{ H_3 }} : si Anissa révise, Jennifer aussi.

En notant {{ A }}, {{ X }} et {{ J }} les propositions booléennes correspondantes, formaliser puis déterminer par un raisonnement équationnel qui révisera et qui ne révisera pas.

Résolution équationnelle complète

1. Formalisation algébrique

Dans toute interprétation {{ I }} satisfaisant les trois hypothèses simultanément, le produit de leurs valeurs de vérité vaut 1 :

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = 1 }}

Exprimons chaque terme en posant {{ a = I(A), x = I(X), j = I(J) }} :

  • {{ [H_1]^I = a + x + j }}
  • {{ [H_2]^I = [\neg A \Rightarrow \neg X]^I = \overline{\overline{a}} + \overline{x} = a + \overline{x} }}
  • {{ [H_3]^I = [A \Rightarrow J]^I = \overline{a} + j }}

2. Calcul algébrique du produit

Calculons d'abord {{ [H_2]^I \cdot [H_3]^I }} :

{{ (a + \overline{x}) \cdot (\overline{a} + j) = a \cdot \overline{a} + a \cdot j + \overline{x} \cdot \overline{a} + \overline{x} \cdot j }}
{{ = 0 + a \cdot j + \overline{a} \cdot \overline{x} + \overline{x} \cdot j = a \cdot j + \overline{a} \cdot \overline{x} + \overline{x} \cdot j }}

Multiplions maintenant par {{ [H_1]^I = a + x + j }} :

{{ (a + x + j) \cdot (a \cdot j + \overline{a} \cdot \overline{x} + \overline{x} \cdot j) }}
{{ = a \cdot (a \cdot j) + a \cdot (\overline{a} \cdot \overline{x}) + a \cdot (\overline{x} \cdot j) + x \cdot (a \cdot j) + x \cdot (\overline{a} \cdot \overline{x}) + x \cdot (\overline{x} \cdot j) + j \cdot (a \cdot j) + j \cdot (\overline{a} \cdot \overline{x}) + j \cdot (\overline{x} \cdot j) }}

Simplifions chaque monôme :

  • {{ a \cdot a \cdot j = a \cdot j }}
  • {{ a \cdot \overline{a} \cdot \overline{x} = 0 }}
  • {{ a \cdot \overline{x} \cdot j }}
  • {{ x \cdot a \cdot j = a \cdot x \cdot j }}
  • {{ x \cdot \overline{a} \cdot \overline{x} = 0 }}
  • {{ x \cdot \overline{x} \cdot j = 0 }}
  • {{ j \cdot a \cdot j = a \cdot j }}
  • {{ j \cdot \overline{a} \cdot \overline{x} = \overline{a} \cdot \overline{x} \cdot j }}
  • {{ j \cdot \overline{x} \cdot j = \overline{x} \cdot j }}

La somme globale devient :

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = a \cdot j + a \cdot \overline{x} \cdot j + a \cdot x \cdot j + \overline{a} \cdot \overline{x} \cdot j + \overline{x} \cdot j }}

Factorisons par {{ j }} (qui apparaît dans chaque terme restant !) :

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = j \cdot ( a + a \cdot \overline{x} + a \cdot x + \overline{a} \cdot \overline{x} + \overline{x} ) }}

Par absorption, {{ a + a \cdot \overline{x} + a \cdot x = a }} et {{ \overline{x} + \overline{a} \cdot \overline{x} = \overline{x} }}, donc l'expression se simplifie en :

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = j \cdot (a + \overline{x}) }}

3. Conclusion formelle

Pour que cette expression soit égale à 1, il est strictement nécessaire que {{ j = 1 }} (car si {{ j = 0 }}, le produit vaut 0 quel que soit le reste). En revanche, le facteur {{ (a + \overline{x}) }} peut être égal à 1 soit avec {{ a = 1 }}, soit avec {{ x = 0 }}.

Conclusion d'examen :

  • Jennifer révisera avec certitude ({{ I(J) = 1 }}).
  • On ne peut rien affirmer avec certitude sur la révision d'Anissa ou de Xavier.

Exercice 8 – Analyse critique : faut-il toujours croire ChatGPT ?

Question 1 Réfutation de la réponse de ChatGPT de juin 2025

Énoncé original

À la question « Donne-moi une formule logiquement équivalente à {{ A \land B }} mais plus complexe », ChatGPT a répondu en juin 2025 que la formule {{ G = \neg((A \Rightarrow \neg B) \lor (\neg A \Rightarrow B)) }} était équivalente à {{ F = A \land B }}.

  1. En calculant {{ [F]^I }} et {{ [G]^I }}, montrer que la réponse de ChatGPT est fausse.
  2. Identifier l'erreur dans le raisonnement donné par ChatGPT.
Réfutation algébrique et analyse de l'erreur

1. Calcul algébrique de {{ [F]^I }} et {{ [G]^I }}

Posons {{ a = I(A) }} et {{ b = I(B) }}. On a évidemment {{ [F]^I = a \cdot b }}.

Calculons {{ [G]^I }} :

{{ [G]^I = \overline{ [A \Rightarrow \neg B]^I + [\neg A \Rightarrow B]^I } }}
{{ = \overline{ (\overline{a} + \overline{b}) + (\overline{\overline{a}} + b) } }}
{{ = \overline{ \overline{a} + \overline{b} + a + b } }}
{{ = \overline{ (a + \overline{a}) + (b + \overline{b}) } }} \quad (Commutativité et associativité)
{{ = \overline{ 1 + 1 } = \overline{1} = 0 }}

On constate que pour toute interprétation {{ I }}, {{ [G]^I = 0 }}. La formule {{ G }} est donc insatisfiable (une contradiction absolue) !

Considérons maintenant l'interprétation {{ I_1 }} telle que {{ I_1(A) = 1 }} et {{ I_1(B) = 1 }} :

  • {{ [F]^{I_1} = 1 \cdot 1 = 1 }}
  • {{ [G]^{I_1} = 0 }}

Puisque {{ [F]^{I_1} \neq [G]^{I_1} }}, les formules {{ F }} et {{ G }} ne sont pas logiquement équivalentes. La réponse fournie par ChatGPT est donc mathématiquement fausse.

2. Identification de l'erreur commise par ChatGPT

ChatGPT a écrit : « cette négation force que ni l'un ni l'autre ne soit vrai, ce qui au final impose A ∧ B ».

L'erreur fatale réside dans le fait que la sous-formule disjonctive {{ (A \Rightarrow \neg B) \lor (\neg A \Rightarrow B) }} est une tautologie (toujours vraie). En effet, quelle que soit la valeur de vérité de {{ A }} et de {{ B }}, il est impossible que les deux implications soient fausses en même temps. En niant une tautologie, on obtient une formule insatisfiable (identiquement fausse), et non pas {{ A \land B }} !

Question 2 Analyse des deux formules avec variable auxiliaire proposées en juillet 2026

Énoncé original

En juillet 2026, ChatGPT propose deux nouvelles formules :

  • {{ F = (A \lor C) \land (B \lor \neg C) \land (A \lor \neg C) }}
  • {{ G = (A \lor C) \land (A \lor \neg C) \land (B \lor C) \land (B \lor \neg C) }}

Montrer que l'une des formules est équivalente à {{ A \land B }} mais pas l'autre.

Démonstration algébrique comparative

1. Étude de la formule {{ G }}

Regroupons les conjonctions de {{ G }} deux à deux :

  • Premier groupe : {{ (A \lor C) \land (A \lor \neg C) }}
    Par distributivité de {{ \lor }} sur {{ \land }} : {{ (A \lor C) \land (A \lor \neg C) \equiv A \lor (C \land \neg C) \equiv A \lor 0 \equiv A }}.
  • Second groupe : {{ (B \lor C) \land (B \lor \neg C) }}
    De même : {{ (B \lor C) \land (B \lor \neg C) \equiv B \lor (C \land \neg C) \equiv B \lor 0 \equiv B }}.

En recombinant les deux groupes :

{{ G \equiv A \land B }}

La formule {{ G }} est donc parfaitement équivalente à {{ A \land B }}.

2. Étude de la formule {{ F }}

Simplifions l'expression de {{ F }} en regroupant le premier et le troisième terme :

{{ (A \lor C) \land (A \lor \neg C) \equiv A \lor (C \land \neg C) \equiv A }}

La formule {{ F }} se simplifie donc en :

{{ F \equiv A \land (B \lor \neg C) }}

Est-elle équivalente à {{ A \land B }} ? NON ! Réfutons-le par un contre-modèle explicite :

Considérons l'interprétation {{ I_c }} définie par :

{{ I_c(A) = 1, \quad I_c(B) = 0, \quad I_c(C) = 0 }}

  • Évaluation de {{ A \land B }} : {{ [A \land B]^{I_c} = 1 \cdot 0 = 0 }}.
  • Évaluation de {{ F }} : {{ [F]^{I_c} = [A]^{I_c} \cdot ([B]^{I_c} + \overline{[C]^{I_c}}) = 1 \cdot (0 + 1) = 1 \cdot 1 = 1 }}.

Puisque {{ [F]^{I_c} = 1 \neq [A \land B]^{I_c} = 0 }}, l'interprétation {{ I_c }} prouve de manière irréfutable que {{ F }} n'est pas équivalente à {{ A \land B }}.
