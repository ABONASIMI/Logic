1. Exercice 4 – Prédicats sémantiques efficaces sans table de vérité

Principe d'optimisation (Court-circuit / Early Exit)

L'énoncé de TP précise : « Il est souvent inutile de calculer toutes les interprétations pour déterminer si une formule est satisfiable ou valide. »

  • Pour la satisfiabilité : dès qu'une interprétation {{ I }} donne {{ [F]^I = 1 }}, on s'arrête immédiatement et on renvoie True sans explorer les autres lignes.
  • Pour la validité : dès qu'une interprétation {{ I }} donne {{ [F]^I = 0 }} (contre-modèle), on s'arrête immédiatement et on renvoie False.
Exercice 4 – Questions 1 & 2 Fonctions is_satisfiable et is_valid avec arrêt anticipé

Énoncé officiel

Écrivez les fonctions suivantes :

  • is_satisfiable(formule: str) -> bool : renvoie True si la formule est satisfiable, False sinon.
  • is_valid(formule: str) -> bool : renvoie True si la formule est valide, False sinon.
Implémentations optimisées commentées 
def is_satisfiable(formule: str) -> bool:
    """Détermine si formule admet au moins un modèle (arrêt dès le premier modèle)."""
    atomes = genere_fa(formule)
    interpretations = genere_interpretations(atomes)
    
    for val in interpretations:
        if eval_formule(formule, val):
            return True  # Modèle trouvé : arrêt anticipé immédiat
            
    return False  # Aucun modèle trouvé : insatisfiable

def is_valid(formule: str) -> bool:
    """Détermine si formule est une tautologie (arrêt dès le premier contre-modèle)."""
    atomes = genere_fa(formule)
    interpretations = genere_interpretations(atomes)
    
    for val in interpretations:
        if not eval_formule(formule, val):
            return False  # Contre-modèle trouvé : arrêt anticipé immédiat
            
    return True  # Vraie sous toutes les interprétations : valide
Exercice 4 – Questions 3 & 4 Calcul des modèles et vérification de conséquence sémantique

Énoncé officiel

Écrivez les fonctions suivantes :

  • models(formule: str) -> list[dict] : renvoie la liste des interprétations pour lesquelles la formule s'interprète à True.
    Exemple : models("p OR q") renvoie [{'p': False, 'q': True}, {'p': True, 'q': False}, {'p': True, 'q': True}].
  • consequence_sem(formule1: str, formule2: str) -> bool : renvoie True si {{ F_2 }} est conséquence sémantique de {{ F_1 }} ({{ F_1 \models F_2 }}), False sinon.
Implémentations et analyse 
def models(formule: str) -> list[dict[str, bool]]:
    """Construit la liste exhaustive de tous les modèles de la formule."""
    atomes = genere_fa(formule)
    interpretations = genere_interpretations(atomes)
    
    liste_modeles = []
    for val in interpretations:
        if eval_formule(formule, val):
            liste_modeles.append(val)
            
    return liste_modeles

def consequence_sem(formule1: str, formule2: str) -> bool:
    """Vérifie si formule1 |= formule2 (tout modèle de F1 doit satisfaire F2)."""
    # L'ensemble des atomes doit couvrir les variables des deux formules
    tous_atomes = genere_fa(formule1) | genere_fa(formule2)
    interpretations = genere_interpretations(tous_atomes)
    
    for val in interpretations:
        # Si val est un modèle de F1, il doit obligatoirement rendre F2 vraie
        if eval_formule(formule1, val):
            if not eval_formule(formule2, val):
                return False  # Contre-modèle trouvé : [F1]^I = 1 et [F2]^I = 0
                
    return True

Remarque sur le théorème de déduction : On aurait pu aussi écrire simplement :
return is_valid(f"({formule1}) IMPLIES ({formule2})") ! Les deux approches sont sémantiquement équivalentes.

2. Exercice 5 – Parseur complet et analyse syntaxique robuste

Exercice 5 – Question 1 Décomposition sans parenthèses : decompose_simple(formule: str)

Énoncé officiel

Écrivez la fonction decompose_simple(formule: str) -> tuple[str, list[str]] qui s'applique aux formules sans parenthèses contenant au plus un connecteur.

Exemples exigés :

  • decompose_simple("p") renvoie ('p', [])
  • decompose_simple("NOT p") renvoie ('NOT', ['p'])
  • decompose_simple("p IMPLIES q") renvoie ('IMPLIES', ['p', 'q'])
Implémentation robuste 
def decompose_simple(formule: str) -> tuple[str, list[str]]:
    """Décompose une formule élémentaire sans parenthèses (au plus un connecteur)."""
    formule = formule.strip()
    
    # 1. Négation unaire NOT
    if formule.startswith("NOT "):
        return ("NOT", [formule[4:].strip()])
        
    # 2. Connecteurs binaires (IMPLIES, AND, OR)
    for op in ["IMPLIES", "AND", "OR"]:
        mot_cle = " " + op + " "
        if mot_cle in formule:
            parties = formule.split(mot_cle, 1)
            return (op, [parties[0].strip(), parties[1].strip()])
            
    # 3. Formule atomique simple ou constante
    return (formule, [])
Exercice 5 – Questions 2 & 3 Analyse générale avec équilibre des parenthèses et recherche de connecteur

Énoncé officiel

Écrivez les fonctions :

  • trouve_prochain_connec(formule: str, index: int) -> tuple[str, int] : renvoie le nom et la position du premier connecteur dont la position est supérieure ou égale à index.
    Exemple : trouve_prochain_connec("(NOT b) AND (q OR r)", 2) renvoie ('AND', 8).
  • decompose(formule: str) -> tuple[str, list[str]] | None : traite le cas général en vérifiant l'équilibre des parenthèses (renvoie None en cas d'erreur de parenthésage) et en supprimant les parenthèses superflues.
Implémentation complète et commentée 
def trouve_prochain_connec(formule: str, index: int) -> tuple[str, int]:
    """Trouve le premier connecteur apparaissant à partir de l'indice index."""
    sous_chaine = formule[index:]
    positions = []
    
    for op in ["IMPLIES", "AND", "OR", "NOT"]:
        pos = sous_chaine.find(op)
        if pos != -1:
            positions.append((pos + index, op))
            
    if not positions:
        return ("", -1)
        
    # On prend celui qui apparaît le plus tôt
    positions.sort(key=lambda x: x[0])
    pos_min, op_min = positions[0]
    return (op_min, pos_min)

def decompose(formule: str) -> tuple[str, list[str]] | None:
    """Analyse syntaxique complète d'une formule arbitraire."""
    formule = formule.strip()
    
    # 1. Vérification de l'équilibre des parenthèses
    ouvrantes = formule.count('(')
    fermantes = formule.count(')')
    if ouvrantes != fermantes:
        return None  # Formule mal parenthésée
        
    # Cas d'une formule sans aucune parenthèse
    if ouvrantes == 0:
        return decompose_simple(formule)
        
    # 2. Suppression des parenthèses externes inutiles englobant toute la formule
    # Attention : "(A) AND (B)" a '(' au début et ')' à la fin, mais ne forme pas un seul bloc !
    while formule.startswith('(') and formule.endswith(')'):
        # Vérifions si la parenthèse ouvrante initiale ne se ferme qu'au tout dernier caractère
        niveau = 0
        englobante = True
        for i in range(len(formule) - 1):
            if formule[i] == '(': niveau += 1
            elif formule[i] == ')': niveau -= 1
            if niveau == 0:
                englobante = False
                break
        if englobante:
            formule = formule[1:-1].strip()
        else:
            break
            
    # Cas de la négation NOT en début de formule
    if formule.startswith("NOT "):
        # Vérifier si NOT s'applique à toute la formule
        if formule.startswith("NOT ("):
            return ("NOT", [formule[4:].strip()])
            
    # 3. Recherche du connecteur principal au niveau 0 de parenthèses
    niveau = 0
    coupure = -1
    for i, c in enumerate(formule):
        if c == '(':
            niveau += 1
        elif c == ')':
            niveau -= 1
        elif niveau == 0 and c == ' ' and coupure == -1:
            coupure = i
            break
            
    if coupure != -1:
        op, pos = trouve_prochain_connec(formule, coupure)
        if pos != -1:
            gauche = formule[:pos].strip()
            droite = formule[pos + len(op):].strip()
            return (op, [gauche, droite])
            
    return decompose_simple(formule)
