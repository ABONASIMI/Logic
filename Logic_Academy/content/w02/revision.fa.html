1. Fiche mémo express des 5 règles d'or

۵ قاعده اساسی که باید در ذهن تثبیت شوند

  1. ترجمه خام استقرایی بدون ساده‌سازی:
    هنگامی که امتحان مقدار {{ [F]^{\mathcal{M}} }} را می‌خواهد، ابتدا درخت کامل را با خطوط متمم بنویسید بدون این‌که کوچک‌ترین ساده‌سازی پیش‌رس انجام دهید (۵ نمره میان‌ترم!).
  2. توزیع‌پذیری متقابل در جبر بولی:
    {{ a + (b \cdot c) = (a + b) \cdot (a + c) }} و {{ a \cdot (b + c) = (a \cdot b) + (a \cdot c) }}.
  3. قضیه بنیادین استنتاج معنایی:
    {{ \mathcal{H} \cup \{A\} \models B \quad \iff \quad \mathcal{H} \models (A \Rightarrow B) }}. به ویژه {{ A \models B \iff \models (A \Rightarrow B) }}.
  4. اصل دوگانگی اعتبار / ناسازگاری:
    فرمول {{ F }} معتبر است اگر و فقط اگر {{ \neg F }} ناسازگار باشد.
  5. اصل ابطال با پادمدل:
    برای رد ادعای {{ \mathcal{H} \models F }}، ارائه تنها یک تعبیر {{ I }} که در آن {{ [H]^I = 1 }} برای تمام {{ H \in \mathcal{H} }} و {{ [F]^I = 0 }} باشد کفایت می‌کند.

2. Radar des pièges d'examen classiques

رایج‌ترین اشتباهاتی که دانشجویان در تصحیح سوربن نمره از دست می‌دهند

  • تله ۱ — استفاده از جدول درستی: صورت مسئله اکیداً جدول را ممنوع کرده است؛ رسم جدول نمره صفر را به همراه دارد.
  • تله ۲ — ننوشتن نام قواعد جبری: در اثبات معادلاتی، ننوشتن عناوینی چون «قانون دمرگان»، «عنصر خنثی» یا «قانون متمم» نیمی از نمره را کسر می‌کند.
  • تله ۳ — خلط نماد {{ \models }} با {{ \Rightarrow }}: نماد {{ \models }} یک رابطه فرامنطقی در جهان تعبیرهاست در حالی که {{ \Rightarrow }} عملگری متنی درون خود فرمول است.
  • تله ۴ — فراموشی اصل انفجار: اگر {{ F }} ناسازگار باشد، رابطه {{ F \models G }} برای هر فرمول دلخواهی چون {{ G }} درست است!
  • تله ۵ — نتیجه‌گیری شتاب‌زده درباره اعتبار: اگر {{ F \models G }} باشد و {{ G }} معتبر باشد، هیچ نتیجه‌ای درباره اعتبار {{ F }} نمی‌توان گرفت. اما اگر {{ F }} معتبر باشد و {{ F \models G }}، آنگاه {{ G }} قطعاً معتبر است!
