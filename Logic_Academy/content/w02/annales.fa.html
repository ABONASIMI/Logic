1. Partiel 2017-2018 – Exercice 3 : Validité et déductions formelles (20 points)

مشخصات برگه امتحانی

آزمون: امتحان میان‌ترم (Partiel) ۲۰۱۷-۲۰۱۸ — درس منطق UL2IN007.
بارم رسمی: ۲۰ نمره (سوال ۱: ۲ نمره ؛ سوال ۲: ۵ + ۶ + ۳ + ۲ + ۲ = ۱۸ نمره).
قانون طلایی: کشیدن جدول درستی اکیداً ممنوع بوده و تمام محاسبات باید با جبر بولی انجام پذیرد.

سوال ۱ (۲ نمره) تعریف ریاضی فرمول معتبر (توتولوژی)

متن اصلی صورت مسئله

تعریف فرمول معتبر را بنویسید.

پاسخ‌نامه رسمی سوال ۱

فرمول {{ F }} معتبر است اگر و تنها اگر تحت هر تعبیر (یا ساختار) دلخواه {{ \mathcal{M} }} داشته باشیم:

{{ [F]^{\mathcal{M}} = 1 }}

(ضابطه تصحیح: ۲ نمره کامل در صورتی داده می‌شود که قید «به ازای هر تعبیر» صراحتاً قید شده باشد).

سوال ۲ (الف) و (ب) (۱۱ نمره) ترجمه خام و اثبات اعتبار با استدلال معادلاتی

متن اصلی صورت مسئله

فرض کنید {{ F }} فرمول {{ ((A \lor \neg B) \land B) \Rightarrow A }} باشد.

  • (الف) (۵ نمره) : تحت ساختار {{ \mathcal{M} }}، عبارت بولی {{ [F]^{\mathcal{M}} }} را بر حسب {{ I_{\mathcal{M}}(A) }} و {{ I_{\mathcal{M}}(B) }} بدون هیچ‌گونه ساده‌سازی بنویسید.
  • (ب) (۶ نمره) : با استفاده از استدلال معادلاتی نشان دهید فرمول {{ F }} معتبر است (در هر گام نام قاعده جبری را ذکر کنید).
پاسخ‌نامه رسمی سوالات ۲(الف) و ۲(ب)

(الف) ترجمه خام استقرایی بدون ساده‌سازی (۵ نمره)

قواعد تبدیل استقرایی را گام‌به‌گام پیاده می‌کنیم:

{{ [F]^{\mathcal{M}} = [((A \lor \neg B) \land B) \Rightarrow A]^{\mathcal{M}} }}
{{ = \overline{[ (A \lor \neg B) \land B ]^{\mathcal{M}}} + [A]^{\mathcal{M}} }} \quad (تعریف شرطی)
{{ = \overline{ [A \lor \neg B]^{\mathcal{M}} \cdot [B]^{\mathcal{M}} } + [A]^{\mathcal{M}} }} \quad (تعریف عطف)
{{ = \overline{ ([A]^{\mathcal{M}} + [\neg B]^{\mathcal{M}}) \cdot [B]^{\mathcal{M}} } + [A]^{\mathcal{M}} }} \quad (تعریف فصل)
{{ = \overline{ (I_{\mathcal{M}}(A) + \overline{I_{\mathcal{M}}(B)}) \cdot I_{\mathcal{M}}(B) } + I_{\mathcal{M}}(A) }} \quad (ارزیابی اتم‌ها و نقیض)

(ب) اثبات اعتبار با استدلال معادلاتی (۶ نمره)

برای اختصار می‌نویسیم {{ a = I_{\mathcal{M}}(A) }} و {{ b = I_{\mathcal{M}}(B) }} :

{{ [F]^{\mathcal{M}} = \overline{ (a + \overline{b}) \cdot b } + a }}
{{ \equiv (\overline{a + \overline{b}} + \overline{b}) + a }} \quad (قانون دمرگان روی نقیض کلی)
{{ \equiv ( (\overline{a} \cdot \overline{\overline{b}}) + \overline{b} ) + a }} \quad (قانون دمرگان روی عبارت داخلی {{ \overline{a + \overline{b}} }})
{{ \equiv ( (\overline{a} \cdot b) + \overline{b} ) + a }} \quad (نفی مضاعف : {{ \overline{\overline{b}} = b }})
{{ \equiv ( (\overline{a} + \overline{b}) \cdot (b + \overline{b}) ) + a }} \quad (توزیع‌پذیری جمع روی ضرب {{ \cdot }})
{{ \equiv ( (\overline{a} + \overline{b}) \cdot 1 ) + a }} \quad (قانون متمم : {{ b + \overline{b} = 1 }})
{{ \equiv (\overline{a} + \overline{b}) + a }} \quad (عنصر همانی ضرب {{ \cdot }})
{{ \equiv (\overline{a} + a) + \overline{b} }} \quad (جابجایی و شرکت‌پذیری جمع)
{{ \equiv 1 + \overline{b} }} \quad (قانون متمم : {{ \overline{a} + a = 1 }})
{{ \equiv 1 }} \quad (عنصر جاذب : {{ 1 + x = 1 }})

از آنجا که {{ [F]^{\mathcal{M}} = 1 }} تحت هر تعبیر {{ \mathcal{M} }} برقرار است، فرمول {{ F }} معتبر است.

سوال ۲ (ج)، (د) و (هـ) (۷ نمره) استنتاج‌های معنایی و خواص فرامنطقی

متن اصلی صورت مسئله

  • (ج) (۳ نمره) : آیا رابطه {{ (A \lor \neg B) \land B \models A }} برقرار است؟ (توجیه کنید).
  • (د) (۲ نمره) : فرض کنید {{ F_1 }} یک فرمول دلخواه باشد. آیا {{ \neg F \models F_1 }} برقرار است؟ (توجیه کنید).
  • (هـ) (۲ نمره) : فرض کنید {{ F_2 }} فرمولی باشد به طوری که {{ F \models F_2 }}. آیا {{ F_2 }} صدق‌پذیر است؟ آیا معتبر است؟ (توجیه کنید).
پاسخ‌نامه رسمی سوالات ۲(ج)، ۲(د) و ۲(هـ)

(ج) استلزام معنایی {{ (A \lor \neg B) \land B \models A }} (۳ نمره)

بله. طبق قضیه بنیادین استنتاج معنایی، هم‌ارزی زیر برقرار است:

{{ P \models Q \quad \iff \quad \models (P \Rightarrow Q) }}

از آنجا که در بخش (ب) اثبات شد فرمول {{ F = ((A \lor \neg B) \land B) \Rightarrow A }} معتبر است، بلافاصله نتیجه می‌گیریم که {{ (A \lor \neg B) \land B \models A }}.

(د) استلزام با نقیض فرمول معتبر {{ \neg F \models F_1 }} (۲ نمره)

بله. از آنجا که {{ F }} معتبر است، نقیض آن {{ \neg F }} ناسازگار (تناقض) است. بنابراین مجموعه ساختارهایی که {{ \neg F }} را برآورده کنند تهی است. در نتیجه هر ساختاری که {{ \neg F }} را صادق کند، به طور بدیهی فرضیه را به انتفای مقدم برآورده ساخته و {{ F_1 }} را نتیجه می‌دهد. پس {{ \neg F \models F_1 }} صادق است.

(هـ) ماهیت فرمول {{ F_2 }} در صورت {{ F \models F_2 }} (۲ نمره)

چون فرمول {{ F }} معتبر است، تحت تمامی ساختارها {{ \mathcal{M} }}، مقدار {{ [F]^{\mathcal{M}} = 1 }} است.

از طرفی رابطه {{ F \models F_2 }} بیان می‌کند هر مدلی از {{ F }} باید مدلی برای {{ F_2 }} باشد. از آنجا که تمام ساختارهای جهان مدل {{ F }} هستند، نتیجه می‌شود که تمام ساختارها مدل فرمول {{ F_2 }} خواهند بود ({{ \forall \mathcal{M}, [F_2]^{\mathcal{M}} = 1 }}).

نتیجه نهایی: بنابراین فرمول {{ F_2 }} الزاماً معتبر (توتولوژی) است (و در نتیجه صدق‌پذیر نیز می‌باشد).

2. Partiel 2019-2020 L2 – Exercice 3 : Preuve algébrique et relations avec G (8 points)

مشخصات برگه امتحانی

آزمون: میان‌ترم کارشناسی ۲۰۱۹-۲۰۲۰ — درس منطق UL2IN007.
بارم رسمی: ۸ نمره (۱ نمره + ۱ نمره + ۲ نمره + ۴ نمره).
فرمول مورد بررسی: {{ F = (\neg A \Rightarrow (A \land \neg A)) \Rightarrow A }}.

سوالات ۱، ۲(الف) و ۲(ب) (۴ نمره) ترجمه و اثبات اعتبار جبری فرمول F

متن اصلی صورت مسئله

  1. تعریف ریاضی فرمول معتبر {{ F }} را بنویسید.
  2. فرمول {{ F = (\neg A \Rightarrow (A \land \neg A)) \Rightarrow A }} را در نظر بگیرید:
    • (الف) : عبارت بولی {{ [F]^{\mathcal{M}} }} را بدون ساده‌سازی بنویسید.
    • (ب) : با استدلال معادلاتی نشان دهید {{ F }} معتبر است.
پاسخ‌نامه رسمی تشریحی

۱. تعریف صوری (۱ نمره)

فرمول {{ F }} معتبر است اگر و تنها اگر برای هر ساختار {{ \mathcal{M} }} داشته باشیم: {{ [F]^{\mathcal{M}} = 1 }}.

۲(الف) ترجمه خام بدون ساده‌سازی (۱ نمره)

{{ [F]^{\mathcal{M}} = \overline{ [\neg A \Rightarrow (A \land \neg A)]^{\mathcal{M}} } + [A]^{\mathcal{M}} }}
{{ = \overline{ \overline{[\neg A]^{\mathcal{M}}} + [A \land \neg A]^{\mathcal{M}} } + [A]^{\mathcal{M}} }}
{{ = \overline{ \overline{\overline{I_{\mathcal{M}}(A)}} + (I_{\mathcal{M}}(A) \cdot \overline{I_{\mathcal{M}}(A)}) } + I_{\mathcal{M}}(A) }}

۲(ب) استدلال معادلاتی (۲ نمره)

با تعریف متغیر {{ x = I_{\mathcal{M}}(A) }} داریم:

{{ [F]^{\mathcal{M}} \equiv \overline{ x + (x \cdot \overline{x}) } + x }} \quad (نفی مضاعف : {{ \overline{\overline{x}} = x }})
{{ \equiv \overline{ x + 0 } + x }} \quad (قانون متمم : {{ x \cdot \overline{x} = 0 }})
{{ \equiv \overline{x} + x }} \quad (عنصر همانی : {{ x + 0 = x }})
{{ \equiv 1 }} \quad (قانون متمم : {{ \overline{x} + x = 1 }})

بنابراین فرمول {{ F }} یک توتولوژی صوری و معتبر است.

سوال ۲(ج) (۴ نمره) تحلیل ۴ استلزام با فرمول دلخواه G

متن اصلی صورت مسئله

فرض کنید {{ G }} فرمولی دلخواه باشد. آیا روابط زیر برقرارند؟

  • (i) آیا {{ G \models F }} برقرار است؟
  • (ii) آیا {{ F \models G }} برقرار است؟
  • (iii) آیا {{ G \models \neg F }} برقرار است؟
  • (iv) آیا {{ \neg F \models G }} برقرار است؟

پاسخ‌های خود را توجیه نمایید.

پاسخ‌نامه رسمی هر ۴ حالت
  • (i) آیا {{ G \models F }} برقرار است؟ ← بله (۱ نمره)
    تمامی ساختارهایی که {{ G }} را برآورده می‌سازند اجباراً {{ F }} را نیز برآورده می‌کنند، چرا که {{ F }} معتبر بوده و در تمامی ساختارهای ممکن مقدار ۱ دارد.
  • (ii) آیا {{ F \models G }} برقرار است؟ ← خیر (۱ نمره)
    چون {{ G }} فرمولی دلخواه است، می‌تواند گزاره‌ای باشد که در ساختاری خاص {{ \mathcal{M} }} مقدار صفر بگیرد (مثلاً {{ G = \text{false} }}). با این حال آن ساختار، {{ F }} را صادق می‌نماید چون {{ F }} معتبر است. پس یک پادمدل وجود دارد.
  • (iii) آیا {{ G \models \neg F }} برقرار است؟ ← خیر (۱ نمره)
    فرمول دلخواه {{ G }} می‌تواند توسط یک ساختار {{ \mathcal{M} }} برآورده شود (مثلاً {{ G = \text{true} }}). اما فرمول {{ \neg F }} ناسازگار است (چون {{ F }} معتبر است) و بنابراین هیچ ساختاری {{ \neg F }} را برآورده نمی‌کند.
  • (iv) آیا {{ \neg F \models G }} برقرار است؟ ← بله (۱ نمره)
    از آنجا که {{ F }} معتبر است، فرمول {{ \neg F }} ناسازگار است و مجموعه ساختارهایی که {{ \neg F }} را صادق کنند تهی است، که استلزام را به طور بدیهی درست می‌گرداند.
