1. Au-delà des tables de vérité : l'explosion combinatoire

Pourquoi abandonner les tables de vérité ?

Une formule comportant {{ n }} variables atomiques nécessite une table de vérité de {{ 2^n }} lignes. En pratique industrielle (vérification de microprocesseurs, solveurs de contraintes industriels), les formules manipulent des milliers de variables. Pour {{ n = 30 }}, {{ 2^{30} pprox 10^9 }} lignes ! Aucun ordinateur ne peut énumérer une telle table.

Le cours de Logique de Sorbonne Université introduit donc l'approche algébrique et déductive : manipuler symboliquement la valeur de vérité {{ [F]^I }} par le calcul booléen équationnel pour établir des propriétés universelles valables pour toutes les interprétations d'un seul coup.

2. L'Algèbre de Boole minimale {{ (\mathbb{B}, \cdot, +, \overline{\phantom{x}}) }}

Structure de l'algèbre de Boole de la Sorbonne (Cours 2, Slide 4)

L'algèbre minimale est le quadruplet {{ (\mathbb{B}, \cdot, +, \overline{\phantom{x}}) }} où {{ \mathbb{B} = \{0, 1\} }} avec deux éléments distincts ({{ 0 eq 1 }}). Les opérations vérifient les axiomes et propriétés fondamentales pour tous {{ a, b, c \in \mathbb{B} }} :

Propriété Opération Conjonctive ({{ \cdot }}) Opération Disjonctive ({{ + }})
Commutativité {{ a \cdot b = b \cdot a }} {{ a + b = b + a }}
Associativité {{ a \cdot (b \cdot c) = (a \cdot b) \cdot c }} {{ a + (b + c) = (a + b) + c }}
Distributivité croisée {{ a \cdot (b + c) = (a \cdot b) + (a \cdot c) }} {{ a + (b \cdot c) = (a + b) \cdot (a + c) }} (Piège !)
Élément neutre {{ a \cdot 1 = a }} {{ a + 0 = a }}
Élément absorbant {{ a \cdot 0 = 0 }} {{ a + 1 = 1 }}
Idempotence {{ a \cdot a = a }} {{ a + a = a }}
Complémentarité {{ a \cdot \overline{a} = 0 }} {{ a + \overline{a} = 1 }}
Involution {{ \overline{\overline{a}} = a }}
Lois de De Morgan {{ \overline{a \cdot b} = \overline{a} + \overline{b} }} {{ \overline{a + b} = \overline{a} \cdot \overline{b} }}
Absorption {{ a \cdot (a + b) = a }} {{ a + (a \cdot b) = a }}
Règle de simplification {{ a \cdot (\overline{a} + b) = a \cdot b }} {{ a + \overline{a} \cdot b = a + b }}

ATTENTION PIÈGE D'EXAMEN : En algèbre classique sur les réels, l'addition n'est jamais distributive sur la multiplication. En algèbre de Boole, l'addition booléenne est distributive sur la multiplication : {{ a + (b \cdot c) = (a + b) \cdot (a + c) }} !

3. Traduction inductive et raisonnement équationnel sur {{ [F]^I }}

Traduction inductive d'une formule vers son expression booléenne

Soit {{ I }} une interprétation fixée. On traduit la formule {{ F }} de manière purement mécanique depuis sa syntaxe vers l'algèbre de Boole :

  • {{ [ ext{true}]^I = 1 }} \quad et \quad {{ [ ext{false}]^I = 0 }}
  • {{ [p]^I = I(p) }} pour toute variable atomique {{ p }}
  • {{ [ eg F]^I = \overline{[F]^I} }}
  • {{ [F_1 \land F_2]^I = [F_1]^I \cdot [F_2]^I }}
  • {{ [F_1 \lor F_2]^I = [F_1]^I + [F_2]^I }}
  • {{ [F_1 \Rightarrow F_2]^I = \overline{[F_1]^I} + [F_2]^I }}
  • {{ [F_1 \Leftrightarrow F_2]^I = [F_1]^I \cdot [F_2]^I + \overline{[F_1]^I} \cdot \overline{[F_2]^I} }}

Exemple de raisonnement équationnel du cours (Cours 2, Slide 12)

Soit la formule de Peirce : {{ F = (F_1 \Rightarrow F_2) \Rightarrow F_1 }}. Calculons son interprétation {{ [F]^I }} :

{{ [F]^I = \overline{[F_1 \Rightarrow F_2]^I} + [F_1]^I }} \quad (Définition de l'implication)
{{ \equiv \overline{\overline{[F_1]^I} + [F_2]^I} + [F_1]^I }} \quad (Définition de l'implication interne)
{{ \equiv (\overline{\overline{[F_1]^I}} \cdot \overline{[F_2]^I}) + [F_1]^I }} \quad (Loi de De Morgan)
{{ \equiv ([F_1]^I \cdot \overline{[F_2]^I}) + [F_1]^I }} \quad (Involution)
{{ \equiv [F_1]^I }} \quad (Loi d'absorption : {{ x + x \cdot y = x }})

On a ainsi prouvé en 4 lignes algébriques que pour toute interprétation {{ I }}, {{ [F]^I = [F_1]^I }}, ce qui aurait nécessité une table immense si {{ F_1 }} et {{ F_2 }} étaient composées de nombreuses variables !

4. Validité, satisfiabilité et insatisfiabilité sans table de vérité

Définitions mathématiques exactes et méthodes de preuve

  • Formule satisfiable : {{ \exists I, [F]^I = 1 }}.
    Méthode sans table : Il suffit d'exhiber explicitement une interprétation {{ I_0 }} et de calculer {{ [F]^{I_0} = 1 }}.
  • Formule valide (tautologie, {{ \models F }}) : {{ orall I, [F]^I = 1 }}.
    Méthode sans table : Soit par calcul équationnel direct en montrant que {{ [F]^I \equiv 1 }} quelle que soit l'interprétation {{ I }}, soit par l'absurde en supposant {{ [F]^I = 0 }} et en aboutissant à une contradiction.
  • Formule insatisfiable (antilogie) : {{ orall I, [F]^I = 0 }}.
    Méthode sans table : Montrer que {{ [F]^I \equiv 0 }} pour tout {{ I }}.
  • Formule non valide : Il suffit d'exhiber un contre-modèle, c'est-à-dire une interprétation {{ I_c }} telle que {{ [F]^{I_c} = 0 }}.

5. Conséquence sémantique formelle ({{ \mathcal{H} \models F }}) et contre-modèles

Définition de la conséquence sémantique (Cours 2, Slide 18)

Soit {{ \mathcal{H} = \{H_1, H_2, \dots, H_k\} }} un ensemble fini d'hypothèses et {{ F }} une formule conclusion. On dit que {{ F }} est conséquence sémantique de {{ \mathcal{H} }}, noté {{ \mathcal{H} \models F }}, si et seulement si :

Pour toute interprétation {{ I }}, si {{ [H_1 \land H_2 \land \dots \land H_k]^I = 1 }}, alors {{ [F]^I = 1 }}.

Autrement dit : Tout modèle de l'ensemble d'hypothèses {{ \mathcal{H} }} est obligatoirement un modèle de la conclusion {{ F }}.

Comment prouver ou réfuter {{ \mathcal{H} \models F }} sans table de vérité ?

  1. Pour prouver que {{ \mathcal{H} \models F }} est VRAIE :
    Soit {{ I }} une interprétation quelconque telle que {{ [H_1]^I = 1, \dots, [H_k]^I = 1 }}. Par déductions logiques nécessaires à partir de ces égalités, montrons que nécessairement {{ [F]^I = 1 }}.
  2. Pour prouver que {{ \mathcal{H} \models F }} est FAUSSE (Réfutation) :
    Il suffit de construire un contre-modèle explicite {{ I_{cm} }} tel que :
    {{ [H_1]^{I_{cm}} = 1, \quad \dots, \quad [H_k]^{I_{cm}} = 1 \quad ext{et} \quad [F]^{I_{cm}} = 0 }}
    Ce contre-modèle suffit à anéantir l'implication universelle.

6. Équivalence logique et théorème de déduction sémantique

Théorème de Déduction Sémantique

Pour tout ensemble de formules {{ \mathcal{H} }} et toutes formules {{ A }} et {{ B }} :

{{ \mathcal{H} \cup \{A\} \models B \quad \iff \quad \mathcal{H} \models (A \Rightarrow B) }}

En particulier, avec {{ \mathcal{H} = \emptyset }} :

{{ A \models B \quad \iff \quad \models (A \Rightarrow B) }}

Ce théorème magistral établit le pont fondamental entre la relation métamathématique de déduction ({{ \models }}) et le connecteur syntaxique d'implication ({{ \Rightarrow }}).

Équivalence logique {{ F_1 \equiv F_2 }} (notée {{ F_1 |\equiv| F_2 }} dans le cours)

Deux formules sont logiquement équivalentes ssi elles ont la même valeur sous toute interprétation :

{{ F_1 \equiv F_2 \quad \iff \quad orall I, [F_1]^I = [F_2]^I \quad \iff \quad (F_1 \models F_2 ext{ et } F_2 \models F_1) }}
