Exercice 4 – Formules satisfiables et valides sans table de vérité

سوال ۱ بررسی فرمول‌های {{ F_1 = (p \land \neg q) \lor (\neg p \land q) }} و {{ \neg F_1 }}

متن اصلی صورت مسئله

فرمول {{ F_1 = (p \land \neg q) \lor (\neg p \land q) }} را در نظر بگیرید. آیا فرمول‌های {{ F_1 }} و {{ \neg F_1 }} صدق‌پذیر هستند؟ آیا معتبر (توتولوژی) هستند؟

پاسخ تشریحی بدون استفاده از جدول درستی

۱. بررسی ویژگی‌های فرمول {{ F_1 }}

  • صدق‌پذیری {{ F_1 }} :
    تعبیر {{ I_1 }} را با مقادیر {{ I_1(p) = 1 }} و {{ I_1(q) = 0 }} در نظر می‌گیریم.
    مقدار {{ [F_1]^{I_1} }} را محاسبه می‌کنیم:
    {{ [F_1]^{I_1} = (I_1(p) \cdot \overline{I_1(q)}) + (\overline{I_1(p)} \cdot I_1(q)) = (1 \cdot 1) + (0 \cdot 0) = 1 + 0 = 1 }}
    از آنجا که حداقل یک تعبیر {{ I_1 }} وجود دارد به طوری که {{ [F_1]^{I_1} = 1 }} باشد، فرمول {{ F_1 }} صدق‌پذیر (Satisfiable) است.
  • اعتبار (توتولوژی بودن) {{ F_1 }} :
    برای رد اعتبار یک فرمول، کافی است یک پادمدل صریح ارائه دهیم.
    تعبیر {{ I_0 }} را با مقادیر {{ I_0(p) = 0 }} و {{ I_0(q) = 0 }} در نظر می‌گیریم:
    {{ [F_1]^{I_0} = (0 \cdot 1) + (1 \cdot 0) = 0 + 0 = 0 }}
    از آنجا که یک تعبیر {{ I_0 }} وجود دارد به طوری که {{ [F_1]^{I_0} = 0 }} باشد، فرمول {{ F_1 }} معتبر نیست.

۲. بررسی ویژگی‌های فرمول {{ \neg F_1 }}

  • صدق‌پذیری {{ \neg F_1 }} :
    تحت تعبیر {{ I_0 }} بالا داریم:
    {{ [\neg F_1]^{I_0} = 1 - [F_1]^{I_0} = 1 - 0 = 1 }}
    بنابراین {{ I_0 }} یک مدل برای {{ \neg F_1 }} است. فرمول {{ \neg F_1 }} صدق‌پذیر است.
  • اعتبار {{ \neg F_1 }} :
    تحت تعبیر {{ I_1 }} بالا داریم:
    {{ [\neg F_1]^{I_1} = 1 - [F_1]^{I_1} = 1 - 1 = 0 }}
    بنابراین {{ I_1 }} یک پادمدل برای {{ \neg F_1 }} است. فرمول {{ \neg F_1 }} معتبر نیست.

جمع‌بندی امتحانی: هر دو فرمول {{ F_1 }} و {{ \neg F_1 }} صدق‌پذیر اما غیرمعتبر هستند (گزاره‌های محتمل / ممکن الوقوع).

سوال ۲ بررسی فرمول‌های {{ F_3 = F_1 \lor F_2 }} و {{ F_4 = F_1 \land F_2 }}

متن اصلی صورت مسئله

فرض کنید {{ F_2 = (p \land q) \lor (\neg p \land \neg q) }} باشد. آیا فرمول‌های زیر صدق‌پذیر هستند؟ آیا معتبر هستند؟

  • {{ F_3 = F_1 \lor F_2 }}
  • {{ F_4 = F_1 \land F_2 }}
محاسبات دقیق جبر بولی

۱. بررسی فرمول {{ F_3 = F_1 \lor F_2 }}

تحت یک تعبیر دلخواه {{ I }}، با قرار دادن {{ x = I(p) }} و {{ y = I(q) }} عبارت را ساده می‌کنیم:

{{ [F_3]^I = [F_1]^I + [F_2]^I }}
{{ = (x \cdot \overline{y} + \overline{x} \cdot y) + (x \cdot y + \overline{x} \cdot \overline{y}) }}
{{ = (x \cdot \overline{y} + x \cdot y) + (\overline{x} \cdot y + \overline{x} \cdot \overline{y}) }} \quad (خاصیت جابجایی و شرکت‌پذیری)
{{ = x \cdot (\overline{y} + y) + \overline{x} \cdot (y + \overline{y}) }} \quad (خاصیت توزیع‌پذیری)
{{ = x \cdot 1 + \overline{x} \cdot 1 }} \quad (قانون متمم)
{{ = x + \overline{x} = 1 }} \quad (متمم نهایی)

از آنجا که مقدار {{ [F_3]^I = 1 }} برای هر تعبیر ممکن {{ I }} برقرار است، فرمول {{ F_3 }} معتبر (توتولوژی) است (و بالطبع صدق‌پذیر نیز هست).

۲. بررسی فرمول {{ F_4 = F_1 \land F_2 }}

ارزش {{ [F_4]^I = [F_1]^I \cdot [F_2]^I }} را تحت تعبیر اختیاری {{ I }} حساب می‌کنیم:

{{ [F_4]^I = (x \cdot \overline{y} + \overline{x} \cdot y) \cdot (x \cdot y + \overline{x} \cdot \overline{y}) }}
{{ = (x \cdot \overline{y}) \cdot (x \cdot y) + (x \cdot \overline{y}) \cdot (\overline{x} \cdot \overline{y}) + (\overline{x} \cdot y) \cdot (x \cdot y) + (\overline{x} \cdot y) \cdot (\overline{x} \cdot \overline{y}) }}
{{ = (x \cdot x) \cdot (\overline{y} \cdot y) + (x \cdot \overline{x}) \cdot (\overline{y} \cdot \overline{y}) + (\overline{x} \cdot x) \cdot (y \cdot y) + (\overline{x} \cdot \overline{x}) \cdot (y \cdot \overline{y}) }}
{{ = x \cdot 0 + 0 \cdot \overline{y} + 0 \cdot y + \overline{x} \cdot 0 = 0 + 0 + 0 + 0 = 0 }}

از آنجا که مقدار {{ [F_4]^I = 0 }} برای هر تعبیر ممکن {{ I }} برقرار است، فرمول {{ F_4 }} ناسازگار (تناقض) است (و در نتیجه معتبر نیست).

Exercice 5 – Conséquence sémantique formelle

تمرین ۵ تحلیل نظری استلزام با فرمول ناسازگار {{ F }} و محتمل {{ G }}

متن اصلی صورت مسئله

فرض کنید {{ F }} یک فرمول ناسازگار (تناقض) و {{ G }} یک فرمول نه معتبر و نه ناسازگار (یعنی گزاره محتمل) باشد. مشخص کنید و توجیه نمایید:

  • (الف) آیا رابطه {{ F \models G }} برقرار است؟
  • (ب) آیا رابطه {{ G \models F }} برقرار است؟
  • (ج) آیا رابطه {{ \neg F \models G }} برقرار است؟
  • (د) آیا رابطه {{ G \models \neg F }} برقرار است؟
پاسخ تشریحی همراه با برهان‌های ریاضی

(الف) آیا {{ F \models G }} برقرار است؟ ← بله

توجیه صوری: بنا بر تعریف، {{ F \models G }} بدان معناست که به ازای هر تعبیر دلخواه {{ I }}، اگر {{ [F]^I = 1 }} باشد، آنگاه {{ [G]^I = 1 }} است.

اما فرمول {{ F }} ناسازگار است، یعنی هیچ تعبیری {{ I }} وجود ندارد که در آن {{ [F]^I = 1 }} شود. بنابراین این گزاره شرطی به صورت انتزاعی به دلیل انتفای مقدم همواره درست است (اصل انفجار منطقی: از باطل هر نتیجه‌ای حاصل می‌شود). بنابراین {{ F \models G }} برقرار است.

(ب) آیا {{ G \models F }} برقرار است؟ ← خیر

توجیه با پادمدل: بنا بر فرض مسئله، {{ G }} صدق‌پذیر است، پس حداقل یک تعبیر {{ I_1 }} وجود دارد که در آن {{ [G]^{I_1} = 1 }} باشد.

اما چون {{ F }} ناسازگار است، در این تعبیر الزاماً {{ [F]^{I_1} = 0 }} خواهد بود. تعبیر {{ I_1 }} فرض را برآورده می‌کند ({{ [G]^{I_1} = 1 }}) ولی نتیجه را نقض می‌نماید ({{ [F]^{I_1} = 0 }}). تعبیر {{ I_1 }} یک پادمدل صریح است؛ بنابراین {{ G ot\models F }}.

(ج) آیا {{ \neg F \models G }} برقرار است؟ ← خیر

توجیه با پادمدل: از آنجا که {{ F }} ناسازگار است، نقیض آن {{ \neg F }} معتبر (توتولوژی) است (برای هر {{ I }}، {{ [\neg F]^I = 1 - 0 = 1 }}).

از طرفی چون {{ G }} معتبر نیست، حداقل یک تعبیر {{ I_0 }} وجود دارد که در آن {{ [G]^{I_0} = 0 }} باشد. برای این تعبیر {{ I_0 }}، داریم {{ [\neg F]^{I_0} = 1 }} و {{ [G]^{I_0} = 0 }}. تعبیر {{ I_0 }} یک پادمدل است و رابطه {{ \neg F \not\models G }} نقض می‌شود.

(د) آیا {{ G \models \neg F }} برقرار است؟ ← بله

توجیه صوری: همان‌طور که در بخش (ج) اثبات شد، فرمول {{ \neg F }} یک فرمول معتبر است، یعنی تحت تمام تعبیرهای ممکن {{ I }}، همواره {{ [\neg F]^I = 1 }} است.

بنابراین تحت هر تعبیری {{ I }} که {{ G }} صادق باشد ({{ [G]^I = 1 }})، مقدار {{ [\neg F]^I = 1 }} حاصل می‌شود. در نتیجه {{ G \models \neg F }}.

Exercice 6 – Équivalence logique et propriétés d'absorption

تمرین ۶ اثبات‌های صوری هم‌ارزی با فرمول‌های معتبر و ناسازگار

متن اصلی صورت مسئله

فرض کنید {{ F_1 }} و {{ F_2 }} دو فرمول دلخواه در منطق گزاره‌ای باشند.

  1. نشان دهید اگر {{ F_1 }} معتبر باشد، آنگاه {{ F_1 \land F_2 \equiv F_2 }} است.
  2. نشان دهید اگر {{ F_1 }} ناسازگار باشد، آنگاه {{ F_1 \lor F_2 \equiv F_2 }} است.
برهان‌های جبری صوری برگه امتحان

۱. اثبات: اگر {{ F_1 }} معتبر باشد، آنگاه {{ F_1 \land F_2 \equiv F_2 }}

تعبیر دلخواه {{ I }} را در نظر می‌گیریم. بنا بر فرض، فرمول {{ F_1 }} معتبر است، پس {{ [F_1]^I = 1 }}.

ارزش درستی عطف {{ F_1 \land F_2 }} را تحت {{ I }} محاسبه می‌کنیم:

{{ [F_1 \land F_2]^I = [F_1]^I \cdot [F_2]^I = 1 \cdot [F_2]^I = [F_2]^I }} \quad (عدد ۱ عنصر همانی عمل ضرب است)

از آنجا که تساوی {{ [F_1 \land F_2]^I = [F_2]^I }} برای هر تعبیر اختیاری {{ I }} برقرار است، بنا بر تعریف هم‌ارزی نتیجه می‌گیریم:

{{ F_1 \land F_2 \equiv F_2 }}

۲. اثبات: اگر {{ F_1 }} ناسازگار باشد، آنگاه {{ F_1 \lor F_2 \equiv F_2 }}

تعبیر دلخواه {{ I }} را در نظر می‌گیریم. بنا بر فرض، فرمول {{ F_1 }} ناسازگار است، پس {{ [F_1]^I = 0 }}.

ارزش درستی فصل {{ F_1 \lor F_2 }} را تحت {{ I }} محاسبه می‌کنیم:

{{ [F_1 \lor F_2]^I = [F_1]^I + [F_2]^I = 0 + [F_2]^I = [F_2]^I }} \quad (عدد ۰ عنصر همانی عمل جمع است)

از آنجا که تساوی {{ [F_1 \lor F_2]^I = [F_2]^I }} برای هر تعبیر اختیاری {{ I }} برقرار است، بنا بر تعریف هم‌ارزی نتیجه می‌گیریم:

{{ F_1 \lor F_2 \equiv F_2 }}

Exercice 7 – Expressions booléennes et résolution équationnelle d'énigme

سوال ۱ ساده‌سازی جبری عبارت {{ [F]^I }}

متن اصلی صورت مسئله

فرمول {{ F = (p \land q) \land ((q \Rightarrow p) \lor \neg(p \lor q)) }} که در آن {{ p }} و {{ q }} گزاره هستند را در نظر بگیرید. عبارت بولی {{ [F]^I }} را بر حسب {{ I(p) }} و {{ I(q) }} محاسبه کرده و با ذکر نام قاعده جبری در هر گام ساده کنید.

محاسبه گام‌به‌گام با نام قواعد

برای اختصار می‌نویسیم {{ x = I(p) }} و {{ y = I(q) }}. عبارت {{ [F]^I }} را باز می‌کنیم:

{{ [F]^I = [p \land q]^I \cdot [(q \Rightarrow p) \lor \neg(p \lor q)]^I }}
{{ = (x \cdot y) \cdot ( [q \Rightarrow p]^I + [\neg(p \lor q)]^I ) }}
{{ = (x \cdot y) \cdot ( (\overline{y} + x) + \overline{x + y} ) }} \quad (تعریف شرطی و نقیض)
{{ \equiv (x \cdot y) \cdot ( (\overline{y} + x) + (\overline{x} \cdot \overline{y}) ) }} \quad (قانون دمرگان روی {{ \overline{x + y} }})
{{ \equiv (x \cdot y) \cdot ( x + (\overline{y} + \overline{x} \cdot \overline{y}) ) }} \quad (جابجایی و شرکت‌پذیری)
{{ \equiv (x \cdot y) \cdot ( x + \overline{y} \cdot (1 + \overline{x}) ) }} \quad (فاکتورگیری از {{ \overline{y} }})
{{ \equiv (x \cdot y) \cdot ( x + \overline{y} \cdot 1 ) }} \quad (عنصر جاذب : {{ 1 + \overline{x} = 1 }})
{{ \equiv (x \cdot y) \cdot ( x + \overline{y} ) }} \quad (عنصر همانی ضرب {{ \cdot }})
{{ \equiv (x \cdot y) \cdot x + (x \cdot y) \cdot \overline{y} }} \quad (توزیع‌پذیری {{ \cdot }} روی {{ + }})
{{ \equiv (x \cdot x) \cdot y + x \cdot (y \cdot \overline{y}) }} \quad (شرکت‌پذیری و جابجایی)
{{ \equiv x \cdot y + x \cdot 0 }} \quad (بت‌خواری {{ x \cdot x = x }} و متمم {{ y \cdot \overline{y} = 0 }})
{{ \equiv x \cdot y + 0 }} \quad (پوچ‌سازی : {{ x \cdot 0 = 0 }})
{{ \equiv x \cdot y }} \quad (عنصر همانی جمع : {{ a + 0 = a }})

نتیجه نهایی: {{ [F]^I = I(p) \cdot I(q) }}. فرمول {{ F }} از دیدگاه جبری کاملاً با عطف ساده {{ p \land q }} هم‌ارز است.

سوال ۲ حل معادلاتی معمای انیسا، خاویر و جنیفر

متن اصلی صورت مسئله

معمای هفته گذشته را با استدلال معادلاتی بررسی می‌کنیم: {{ H_1 }}: حداقل یکی درس می‌خواند؛ {{ H_2 }}: اگر انیسا نخواند، خاویر هم نمی‌خواند؛ {{ H_3 }}: اگر انیسا بخواند، جنیفر هم می‌خواند.

با تعریف گزاره‌های {{ A }}، {{ X }} و {{ J }}، با استدلال معادلاتی نشان دهید چه کسی قطعاً درس می‌خواند.

اثبات جبری کامل

۱. فرمول‌بندی جبری مسئله

در هر تعبیر دلخواه {{ I }} که هر سه فرض را برآورده کند، حاصل‌ضرب مقادیر آن‌ها برابر ۱ است:

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = 1 }}

با تعریف متغیرهای {{ a = I(A), x = I(X), j = I(J) }} داریم:

  • {{ [H_1]^I = a + x + j }}
  • {{ [H_2]^I = [\neg A \Rightarrow \neg X]^I = \overline{\overline{a}} + \overline{x} = a + \overline{x} }}
  • {{ [H_3]^I = [A \Rightarrow J]^I = \overline{a} + j }}

۲. محاسبات جبری ضرب عبارات

ابتدا عبارت {{ [H_2]^I \cdot [H_3]^I }} را محاسبه می‌کنیم:

{{ (a + \overline{x}) \cdot (\overline{a} + j) = a \cdot \overline{a} + a \cdot j + \overline{x} \cdot \overline{a} + \overline{x} \cdot j }}
{{ = 0 + a \cdot j + \overline{a} \cdot \overline{x} + \overline{x} \cdot j = a \cdot j + \overline{a} \cdot \overline{x} + \overline{x} \cdot j }}

سپس در عبارت {{ [H_1]^I = a + x + j }} ضرب می‌کنیم:

{{ (a + x + j) \cdot (a \cdot j + \overline{a} \cdot \overline{x} + \overline{x} \cdot j) }}
{{ = a \cdot (a \cdot j) + a \cdot (\overline{a} \cdot \overline{x}) + a \cdot (\overline{x} \cdot j) + x \cdot (a \cdot j) + x \cdot (\overline{a} \cdot \overline{x}) + x \cdot (\overline{x} \cdot j) + j \cdot (a \cdot j) + j \cdot (\overline{a} \cdot \overline{x}) + j \cdot (\overline{x} \cdot j) }}

ساده‌سازی تک‌تک جملات حاصل‌ضرب:

  • {{ a \cdot a \cdot j = a \cdot j }}
  • {{ a \cdot \overline{a} \cdot \overline{x} = 0 }}
  • {{ a \cdot \overline{x} \cdot j }}
  • {{ x \cdot a \cdot j = a \cdot x \cdot j }}
  • {{ x \cdot \overline{a} \cdot \overline{x} = 0 }}
  • {{ x \cdot \overline{x} \cdot j = 0 }}
  • {{ j \cdot a \cdot j = a \cdot j }}
  • {{ j \cdot \overline{a} \cdot \overline{x} = \overline{a} \cdot \overline{x} \cdot j }}
  • {{ j \cdot \overline{x} \cdot j = \overline{x} \cdot j }}

عبارت حاصل برابر است با:

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = a \cdot j + a \cdot \overline{x} \cdot j + a \cdot x \cdot j + \overline{a} \cdot \overline{x} \cdot j + \overline{x} \cdot j }}

از متغیر {{ j }} (که در تمامی جملات باقی‌مانده تکرار شده است) فاکتور می‌گیریم:

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = j \cdot ( a + a \cdot \overline{x} + a \cdot x + \overline{a} \cdot \overline{x} + \overline{x} ) }}

طبق قانون جذب، چون {{ a + a \cdot \overline{x} + a \cdot x = a }} و {{ \overline{x} + \overline{a} \cdot \overline{x} = \overline{x} }}، جملات ساده شده و حاصل نهایی به دست می‌آید:

{{ [H_1]^I \cdot [H_2]^I \cdot [H_3]^I = j \cdot (a + \overline{x}) }}

۳. نتیجه‌گیری صوری نهایی

برای این‌که حاصل‌ضرب فوق برابر با ۱ شود، اجباراً باید {{ j = 1 }} باشد (زیرا اگر {{ j = 0 }} باشد حاصل‌ضرب در هر صورت صفر خواهد بود). در مقابل، جمله دوم {{ (a + \overline{x}) }} هم با {{ a = 1 }} و هم با {{ x = 0 }} می‌تواند یک شود.

پاسخ نهایی برگه آزمون:

  • جنیفر با قطعیت ۱۰۰٪ درس خواهد خواند ({{ I(J) = 1 }}).
  • درباره انیسا و خاویر هیچ حکم قطعی و یقینی بدون مفروضات اضافی نمی‌توان داد.

Exercice 8 – Analyse critique : faut-il toujours croire ChatGPT ?

سوال ۱ رد ادعای چت‌جی‌پی‌تی در ژوئن ۲۰۲۵

متن اصلی صورت مسئله

در پاسخ به درخواست «فرمول معادل {{ A \land B }} ولی پیچیده‌تر»، ChatGPT فرمول {{ G = \neg((A \Rightarrow \neg B) \lor (\neg A \Rightarrow B)) }} را معادل {{ F = A \land B }} اعلام کرده است.

  1. با محاسبه {{ [F]^I }} و {{ [G]^I }} نشان دهید این پاسخ نادرست است.
  2. خطای بنیادین استدلال ChatGPT را مشخص کنید.
رد جبری ادعا و ریشه‌یابی خطا

۱. محاسبه جبری {{ [F]^I }} و {{ [G]^I }}

با تعریف {{ a = I(A) }} و {{ b = I(B) }}، ارزش {{ [F]^I = a \cdot b }} است.

ارزش {{ [G]^I }} را ساده می‌کنیم:

{{ [G]^I = \overline{ [A \Rightarrow \neg B]^I + [\neg A \Rightarrow B]^I } }}
{{ = \overline{ (\overline{a} + \overline{b}) + (\overline{\overline{a}} + b) } }}
{{ = \overline{ \overline{a} + \overline{b} + a + b } }}
{{ = \overline{ (a + \overline{a}) + (b + \overline{b}) } }} \quad (خاصیت جابجایی و شرکت‌پذیری)
{{ = \overline{ 1 + 1 } = \overline{1} = 0 }}

مشاهده می‌کنیم که تحت هر تعبیر دلخواه {{ I }}، همواره {{ [G]^I = 0 }} است. یعنی فرمول {{ G }} یک تناقض مطلق (ناسازگار) است!

اکنون تعبیر {{ I_1 }} با مقادیر {{ I_1(A) = 1 }} و {{ I_1(B) = 1 }} را در نظر بگیرید:

  • {{ [F]^{I_1} = 1 \cdot 1 = 1 }}
  • {{ [G]^{I_1} = 0 }}

چون در این تعبیر {{ [F]^{I_1} \neq [G]^{I_1} }} است، دو فرمول {{ F }} و {{ G }} به هیچ وجه هم‌ارز نیستند و پاسخ هوش مصنوعی مردود است.

۲. منشأ خطای استدلال هوش مصنوعی

هوش مصنوعی ادعا کرده بود نفی این عبارت دو گزاره را مجبور به درستی هم‌زمان می‌کند. اما در حقیقت عبارت فصلی {{ (A \Rightarrow \neg B) \lor (\neg A \Rightarrow B) }} یک توتولوژی محض بوده که فارغ از ارزش حقیقت گزاره‌های {{ A }} و {{ B }} در تمام جهان‌ها درست است. نقیض یک توتولوژی، فرمول همواره نادرست (ناسازگار) است، نه عطف {{ A \land B }} !

سوال ۲ بررسی دو فرمول با متغیر کمکی ارائه‌شده در ژوئیه ۲۰۲۶

متن اصلی صورت مسئله

در ژوئیه ۲۰۲۶، چت‌جی‌پی‌تی این دو فرمول را پیشنهاد می‌کند:

  • {{ F = (A \lor C) \land (B \lor \neg C) \land (A \lor \neg C) }}
  • {{ G = (A \lor C) \land (A \lor \neg C) \land (B \lor C) \land (B \lor \neg C) }}

نشان دهید یکی از این دو فرمول دقیقاً هم‌ارز {{ A \land B }} است ولی دیگری هم‌ارز نیست.

برهان تطبیقی جبری

۱. بررسی فرمول {{ G }}

جملات عطفی فرمول {{ G }} را دوبه‌دو دسته‌بندی می‌کنیم:

  • دسته اول: {{ (A \lor C) \land (A \lor \neg C) }}
    با توزیع‌پذیری {{ \lor }} بر روی {{ \land }} داریم: {{ (A \lor C) \land (A \lor \neg C) \equiv A \lor (C \land \neg C) \equiv A \lor 0 \equiv A }}.
  • دسته دوم: {{ (B \lor C) \land (B \lor \neg C) }}
    به همین ترتیب: {{ (B \lor C) \land (B \lor \neg C) \equiv B \lor (C \land \neg C) \equiv B \lor 0 \equiv B }}.

با ترکیب دوباره دو دسته به دست می‌آید:

{{ G \equiv A \land B }}

بنابراین فرمول {{ G }} دقیقاً هم‌ارز منطقی {{ A \land B }} است.

۲. بررسی فرمول {{ F }}

با ترکیب عبارت اول و سوم فرمول {{ F }} داریم:

{{ (A \lor C) \land (A \lor \neg C) \equiv A \lor (C \land \neg C) \equiv A }}

بنابراین فرمول {{ F }} به عبارت زیر خلاصه می‌شود:

{{ F \equiv A \land (B \lor \neg C) }}

آیا این عبارت با {{ A \land B }} هم‌ارز است؟ خیر! با یک پادمدل صریح آن را رد می‌کنیم:

تعبیر {{ I_c }} را به صورت زیر برمی‌گزینیم:

{{ I_c(A) = 1, \quad I_c(B) = 0, \quad I_c(C) = 0 }}

  • ارزش {{ A \land B }} : {{ [A \land B]^{I_c} = 1 \cdot 0 = 0 }}.
  • ارزش {{ F }} : {{ [F]^{I_c} = [A]^{I_c} \cdot ([B]^{I_c} + \overline{[C]^{I_c}}) = 1 \cdot (0 + 1) = 1 \cdot 1 = 1 }}.

از آنجا که {{ [F]^{I_c} = 1 \neq [A \land B]^{I_c} = 0 }}، تعبیر {{ I_c }} یک پادمدل صریح است که ثابت می‌کند فرمول {{ F }} با {{ A \land B }} هم‌ارز نیست.
