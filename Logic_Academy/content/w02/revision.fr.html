1. Fiche mémo express des 5 règles d'or

Les 5 règles absolues à graver dans votre mémoire

  1. Traduction brute sans simplification :
    Quand l'examen demande de calculer {{ [F]^{\mathcal{M}} }}, écrivez d'abord l'arbre complet avec les barres et les produits sans jamais simplifier au préalable (5 points au partiel !).
  2. Distributivité croisée en algèbre de Boole :
    {{ a + (b \cdot c) = (a + b) \cdot (a + c) }} et {{ a \cdot (b + c) = (a \cdot b) + (a \cdot c) }}.
  3. Théorème de déduction sémantique :
    {{ \mathcal{H} \cup \{A\} \models B \quad \iff \quad \mathcal{H} \models (A \Rightarrow B) }}. En particulier, {{ A \models B \iff \models (A \Rightarrow B) }}.
  4. Dualité validité / insatisfiabilité :
    {{ F }} est valide ssi {{ \neg F }} est insatisfiable.
  5. Principe de réfutation par contre-modèle :
    Pour infirmer {{ \mathcal{H} \models F }}, il suffit de fournir UNE seule interprétation {{ I }} telle que {{ [H]^I = 1 }} pour tout {{ H \in \mathcal{H} }} et {{ [F]^I = 0 }}.

2. Radar des pièges d'examen classiques

Les erreurs les plus pénalisées par les correcteurs de la Sorbonne

  • Piège 1 — Utiliser une table de vérité : La consigne interdit formellement les tables au Thème 2. Tout tableau de vérité entraîne la note 0 à l'exercice.
  • Piège 2 — Oublier de nommer les équivalences : Dans une preuve équationnelle, omettre d'écrire « loi de De Morgan », « élément neutre » ou « complémentarité » coûte la moitié des points de la question.
  • Piège 3 — Confondre {{ \models }} et {{ \Rightarrow }} : {{ \models }} est une relation métamathématique de déduction, tandis que {{ \Rightarrow }} est un symbole syntaxique de la formule.
  • Piège 4 — Oublier que le faux implique tout : Si {{ F }} est insatisfiable, alors {{ F \models G }} est VRAIE pour n'importe quelle formule {{ G }} !
  • Piège 5 — Déduire la validité de la conclusion : Si {{ F \models G }} et {{ G }} est valide, on ne peut RIEN en déduire sur {{ F }} (elle peut être contingente ou fausse). En revanche, si {{ F }} est valide et {{ F \models G }}, alors {{ G }} est obligatoirement valide !
