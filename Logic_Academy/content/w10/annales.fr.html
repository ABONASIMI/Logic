Exercice Type 1 — Unification de Robinson avec Occurs Check

Énoncé

Appliquer l'algorithme de Robinson pour trouver le mgu du système :

{{ \{ f(x, g(y)) \doteq f(h(z), x), \quad y \doteq a \} }}
Correction

1. Décomposition sur {{ f }} : {{ x \doteq h(z) }} et {{ g(y) \doteq x }}.

2. Remplacement de {{ x }} par {{ h(z) }} : {{ g(y) \doteq h(z) }}.

3. Clash entre les symboles de fonction {{ g }} et {{ h }} : ÉCHEC d'unification !
