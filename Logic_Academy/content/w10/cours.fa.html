اهداف یادگیری — هفته ۱۰ (روش تفکیک، یکسان‌سازی رابینسون و پرولوگ)
  • درک قاعده تفکیک (Resolution Principle) در منطق گزاره‌ای و اثبات با نقیض برای رسیدن به بند پوچ ({{ \Box }}).
  • تسلط بر الگوریتم یکسان‌سازی رابینسون (Robinson's MGU) با تبدیل گام‌به‌گام سیستم معادلات.
  • فهم عمیق بررسی رخداد (Occurs Check) و علت بروز حلقه‌های بی‌نهایت در صورت غفلت از آن.
  • اجرای تفکیک در منطق مرتبه اول LPPO همراه با تغییر نام متغیرهای هر بند (Standardizing apart).
  • آشنایی با برنامه‌نویسی منطقی با Prolog، بندهای هورن (Horn Clauses) و درخت‌های تفکیک SLD.

۱. قاعده تفکیک در منطق گزاره‌ای

تعریف ۱۰.۱ — قاعده تفکیک (Resolution)

فرض کنیم دو بند {{ C_1 = A \lor p }} و $C_2 = B \lor eg p$ داشته باشیم. تفکیک‌یافته (Resolvent) این دو روی لیترال مکمل {{ p }} برابر است با:

{{ \text{Res}(C_1, C_2) = A \lor B }}

اگر {{ C_1 = p }} و $C_2 = eg p$ باشد، تفکیک‌یافته یک بند پوچ یا خالی است که با {{ \Box }} نمایش داده می‌شود و ذاتاً ناسازگار (معادل {{ \bot }}) است.

چرا اشتباه می‌کنم؟ — حذف همزمان دو حرف مکمل!

هشدار مهم: اگر {{ C_1 = p \lor q }} و $C_2 = eg p \lor eg q{{ باشد، تفکیک روی }}p{{ عبارت }}q \lor eg q \equiv \top$ را می‌دهد. اکیداً مجاز نیستید هر دو متغیر {{ p }} و {{ q }} را هم‌زمان حذف کنید و بنویسید {{ \Box }}! زیرا ارزش‌دهی {{ v(p)=1, v(q)=0 }} هر دو بند را صادق می‌کند، پس این دو بند به هیچ وجه ناسازگار نیستند!

۲. الگوریتم یکسان‌سازی رابینسون (MGU)

تعریف ۱۰.۲ — جایگزینی یکسان‌ساز و MGU

دو ترم {{ t_1 }} و {{ t_2 }} یکسان‌پذیرند اگر جانشانی {{ \sigma }} وجود داشته باشد به طوری که {{ t_1\sigma = t_2\sigma }}. فراگیرترین یکسان‌ساز (mgu) جانشانی پایه‌ای است که هر جانشانی یکسان‌ساز دیگر، نمونه‌ای از آن باشد.

قواعد سیستم معادلات الگوریتم رابینسون
  • حذف اتحاد (Delete): معادله تکراری {{ \{t \doteq t\} }} بدون اثر حذف می‌شود.
  • تجزیه (Decomposition): {{ \{f(u_1, \dots, u_n) \doteq f(v_1, \dots, v_n)\} \implies \{u_1 \doteq v_1, \dots, u_n \doteq v_n\} }}.
  • تضاد نماد (Clash): {{ \{f(\dots) \doteq g(\dots)\} \implies }} شکست قطعی.
  • جهت‌دهی (Orient): تبدیل {{ \{t \doteq x\} }} به {{ \{x \doteq t\} }} در حالتی که {{ t }} متغیر نباشد.
  • بررسی رخداد (Occurs Check): در {{ \{x \doteq t\} }}، اگر متغیر {{ x }} درون {{ t }} آمده باشد و $x eq t$، بلافاصله شکست رخ می‌دهد! مثلاً معادله {{ x \doteq f(x) }} هیچ جواب محدودی ندارد. در غیر این صورت، در تمام معادلات دیگر به جای {{ x }} عبارت {{ t }} را قرار می‌دهیم.

۳. برنامه‌نویسی منطقی پرولوگ و بندهای هورن

تعریف ۱۰.۳ — بندهای هورن در پرولوگ

یک بند هورن (Horn Clause) حداکثر شامل یک لیترال مثبت است:

  • واقعیت (Fact): {{ P(t) \leftarrow }} (بدون لیترال منفی). در پرولوگ: p(t).
  • قاعده (Rule): {{ P(t) \leftarrow Q_1 \land \dots \land Q_n }}. در پرولوگ: p(t) :- q1, ..., qn.
  • پرسش یا هدف (Query/Goal): {{ \leftarrow Q_1 \land \dots \land Q_n }}. در پرولوگ: ?- q1, ..., qn.
