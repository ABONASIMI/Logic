Exercice 36 — Diagnostic Médical par Résolution (p. 21)

Mise en Clauses & Preuve par Réfutation

Variables : {{ G }} (grippe), {{ T }} (tamiflu), {{ F }} (fièvre), {{ K }} (toux), {{ S }} (sup38).

Clauses de la base de connaissances :

  • $F \iff S \implies ( eg F \lor S){{ et }}( eg S \lor F)$.
  • $G \implies T \implies ( eg G \lor T)$.
  • $(F \land K) \implies G \implies ( eg F \lor eg K \lor G)$.
  • Faits : {{ K }} et {{ S }}.

But à prouver : Le patient doit prendre du tamiflu ({{ T }}). Pour réfuter, on ajoute la négation du but : $ eg T$.

Dérivation par résolution :

  1. $ ext{Res}(S, eg S \lor F) \implies F$.
  2. $ ext{Res}(F, eg F \lor eg K \lor G) \implies eg K \lor G$.
  3. $ ext{Res}(K, eg K \lor G) \implies G$.
  4. $ ext{Res}(G, eg G \lor T) \implies T$.
  5. $ ext{Res}(T, eg T) \implies \Box$.

La clause vide {{ \Box }} est obtenue. Par conséquent, la négation du but est insatisfiable avec la base, ce qui démontre rigoureusement que le patient doit prendre du tamiflu !

Exercice 39 — Arbre de Résolution SLD Prolog (p. 22)

Arbre SLD pour la requête ?- p(a, Y, Z).

Base de règles :

(1) p(X,Y,Z) :- q(X,Y), q(Y,Z).
(2) p(X,Y,X) :- q(b,X), q(Y,a).
(3) q(a,b).  (4) q(b,a).  (5) q(b,c).  (6) q(a,c).

Déroulement SLD :

  • Branche 1 (règle 1 avec {{ X \mapsto a }}) : But résiduel ?- q(a, Y), q(Y, Z).
    • Avec fait (3) {{ q(a,b) }}, {{ Y=b }}. Nouveau sous-but : ?- q(b, Z).
      • Avec fait (4) {{ q(b,a) }} : {{ Z=a \implies }} Succès : Y=b, Z=a.
      • Avec fait (5) {{ q(b,c) }} : {{ Z=c \implies }} Succès : Y=b, Z=c.
    • Avec fait (6) {{ q(a,c) }}, {{ Y=c }}. Nouveau sous-but : ?- q(c, Z).
      • Aucun fait ne commence par {{ c }} {{ \implies }} Échec (Backtracking).
  • Branche 2 (règle 2 avec {{ X \mapsto a }}) : Unifie {{ p(a, Y, a) }} avec {{ Z=a }}. But résiduel : ?- q(b, a), q(Y, a).
    • q(b,a) est immédiatement résolu par le fait (4). Reste ?- q(Y, a).
      • Résolu par le fait (4) avec {{ Y=b \implies }} Succès : Y=b, Z=a.
