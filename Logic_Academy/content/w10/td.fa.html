تمرین ۳۵ — قاعده تفکیک گزاره‌ای (صفحه ۲۱)

محاسبه تفکیک‌یافته‌ها (Resolvents)
  1. {{ C_1 = p \lor r }} و $C_2 = eg p \lor eg s \lor t{{ با متغیر محوری }}p$:
    {{ ext{Res}(C_1, C_2) = r \lor eg s \lor t }}
  2. {{ C_1 = p \lor q \lor r }} و $C_2 = p \lor eg q \lor s \lor eg t{{ روی }}q$:
    {{ ext{Res}(C_1, C_2) = p \lor r \lor s \lor eg t }}
  3. {{ C_1 = p \lor q }} و $C_2 = eg p \lor eg q \lor s$:
    اگر روی {{ p }} تفکیک کنیم: $q \lor eg q \lor s \equiv op$ (همیشه‌درست و بی‌اثر). حذف همزمان هر دو اکیداً غلط است!
  4. $C_1 = p \lor q \lor eg r{{ و }}C_2 = p \lor q \lor r{{ روی }}r$:
    {{ ext{Res}(C_1, C_2) = p \lor q }}
  5. {{ C_1 = p }} و $C_2 = eg p{{ روی }}p$:
    {{ ext{Res}(C_1, C_2) = \Box \quad ext{(بند پوچ؛ اثبات ناسازگاری و تناقض!)} }}

تمرین ۳۶ — تشخیص پزشکی با روش تفکیک (صفحه ۲۱)

تبدیل به بندها و اثبات به روش تناقض

هدف اثبات لزوم مصرف تامیفلو ({{ T }}) توسط بیمار است. نقیض هدف یعنی $ eg T{{ را به پایگاه دانش اضافه می‌کنیم و تفکیک متوالی انجام می‌دهیم تا به بند پوچ }}\Box$ برسیم:

  • تفکیک {{ S }} با $ eg S \lor F{{ منجر به تب ( }}F$) می‌شود.
  • تفکیک {{ F }} و سرفه ({{ K }}) با قاعده ابتلا به آنفولانزا منجر به {{ G }} (گریپ) می‌شود.
  • تفکیک {{ G }} با $ eg G \lor T{{ نتیجه می‌دهد بیمار باید داروی تامیفلو ( }}T$) مصرف کند.
  • در نهایت تفکیک {{ T }} با نقیض هدف ($ eg T{{ ) بند پوچ }}\Box$ را تولید می‌کند که اثبات را کامل می‌سازد!

تمرین ۳۹ — درخت تفکیک SLD در پرولوگ (صفحه ۲۲)

تحلیل درخت اجرای پرولوگ برای پرسش ?- p(a, Y, Z).

پرولوگ از اولین قاعده شروع می‌کند و زیرهدف‌های q(a, Y) و q(Y, Z) را بررسی می‌کند. با حقیقت q(a,b) مقدار {{ Y=b }} یکسان می‌شود و برای زیرهدف دوم مقادیر {{ Z=a }} و {{ Z=c }} حاصل می‌گردد. با حقیقت q(a,c) چون هیچ واقعیتی با حرف {{ c }} آغاز نمی‌شود، جستجو با شکست (Fail) مواجه شده و عقب‌گرد (Backtracking) صورت می‌گیرد.
