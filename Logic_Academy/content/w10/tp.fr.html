Exercice 16 — Premières requêtes Prolog

On crée un fichier exercice0.pl contenant les faits :

toto(a, b).
toto(c, b).

Dans l'interpréteur :

  • Chargement : ?- [exercice0].
  • Requête avec variable majuscule : ?- toto(X, b).
    Prolog répond d'abord X = a. En appuyant sur ; (point-virgule), Prolog cherche par backtracking la solution suivante : X = c.

Exercice 17 — Arbre Généalogique des Simpson

% Définition des règles familiales
parent(X, Y) :- pere(X, Y).
parent(X, Y) :- mere(X, Y).

grandPere(X, Y) :- pere(X, Z), parent(Z, Y).
frere(X, Y) :- parent(Z, X), parent(Z, Y), homme(X), X \= Y.

Exercice 18 — Parcours de Graphe Orienté Sans Cycle

arc(a, b). arc(a, c). arc(b, d). arc(c, d). arc(d, e).

% Nœuds immédiatement intermédiaires
entre(X, S, D) :- arc(S, X), arc(X, D).

% Accessibilité transitive
accessible(X, Y) :- arc(X, Y).
accessible(X, Y) :- arc(X, Z), accessible(Z, Y).
