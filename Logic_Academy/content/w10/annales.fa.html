مسأله نمونه ۱ — یکسان‌سازی رابینسون همراه با Occurs Check

صورت مسأله

محاسبه MGU به روش رابینسون برای سیستم معادلات زیر:

{{ \{ f(x, g(y)) \doteq f(h(z), x), \quad y \doteq a \} }}
پاسخ تشریحی

پس از تجزیه تابع {{ f }} به معادلات {{ x \doteq h(z) }} و {{ g(y) \doteq x }}، با جایگذاری {{ x }} به معادله {{ g(y) \doteq h(z) }} می‌رسیم. به دلیل تناقض در نماد تابع سربرگ ({{ g }} در برابر {{ h }})، الگوریتم فوراً با شکست مواجه می‌شود و هیچ یکسان‌سازی وجود ندارد.
