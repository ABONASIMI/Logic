Objectifs d'apprentissage — Semaine 3
  • Comprendre la notion de fonction booléenne et son dénombrement ({{ 2^{2^n} }}).
  • Définir rigoureusement les littéraux, clauses disjonctives, termes, FNC et FND.
  • Maîtriser l'algorithme canonique de passage de la table de vérité vers la FND (mintermes) et vers la FNC (maxtermes).
  • Convertir une formule arbitraire en FNC ou FND par calcul algébrique pur sans table.
  • Reconnaître instantanément la satisfiabilité triviale d'une FND et la validité triviale d'une FNC.
  • Comprendre la complétude fonctionnelle d'un jeu de connecteurs et les connecteurs universels NAND et NOR.

1. Fonctions Booléennes et Dénombrement

Définition 3.1 — Fonction Booléenne

Une fonction booléenne à {{ n }} variables est une application :

{{ f : \{0, 1\}^n \longrightarrow \{0, 1\} }}

Puisque le domaine {{ \{0, 1\}^n }} contient exactement {{ 2^n }} n-uplets (lignes de la table de vérité), et que pour chacun de ces n-uplets {{ f }} peut valoir 0 ou 1, il existe exactement :

{{ 2^{2^n} \quad \text{fonctions booléennes distinctes à } n \text{ variables}. }}

2. Formes Normales : FNC et FND

Définition 3.2 — Vocabulaire Normalisé
  • Littéral : Une variable propositionnelle {{ p }} (littéral positif) ou sa négation {{ \neg p }} (littéral négatif).
  • Clause disjonctive (ou simplement Clause) : Une disjonction de littéraux : {{ (l_1 \lor l_2 \lor \dots \lor l_k) }}.
  • Terme (ou Clause conjonctive) : Une conjonction de littéraux : {{ (l_1 \land l_2 \land \dots \land l_k) }}.
  • Forme Normale Conjonctive (FNC / CNF) : Une conjonction de clauses : {{ \bigwedge_{i=1}^m \left( \bigvee_{j=1}^{k_i} l_{i,j} \right) }}
  • Forme Normale Disjonctive (FND / DNF) : Une disjonction de termes : {{ \bigvee_{i=1}^m \left( \bigwedge_{j=1}^{k_i} l_{i,j} \right) }}

3. Passage de la Table de Vérité aux Formes Normales

Algorithme canonique à partir d'une table de vérité
  • Pour construire la FND : On repère chaque ligne de la table où la formule vaut 1. Pour chaque telle ligne, on forme un minterme (conjonction où la variable apparaît positive si elle vaut 1, et négative si elle vaut 0). On prend la disjonction ({{ \lor }}) de tous ces mintermes.
  • Pour construire la FNC : On repère chaque ligne où la formule vaut 0. Pour chaque telle ligne, on forme un maxterme (disjonction où la variable apparaît négative si elle vaut 1, et positive si elle vaut 0). On prend la conjonction ({{ \land }}) de tous ces maxtermes.

4. Complétude Fonctionnelle des Jeux de Connecteurs

Définition 3.3 — Système Complet de Connecteurs

Un ensemble de connecteurs {{ \mathcal{C} }} est dit complet si toute fonction booléenne peut être représentée par une formule utilisant uniquement les connecteurs de {{ \mathcal{C} }}.

  • $\{ eg, \land, \lor\}$ est complet (démontré par la construction de la FND pour toute table).
  • $\{ eg, \land\}{{ est complet (car }}A \lor B \equiv \neg(\neg A \land \neg B)$).
  • $\{ eg, \lor\}{{ est complet (car }}A \land B \equiv \neg(\neg A \lor \neg B)$).
  • $\{ eg, \Rightarrow\}{{ est complet (car }}\neg A \lor B \equiv A \Rightarrow B$).
  • {{ \{\land, \lor\} }} est INCOMPLET : toute formule construite uniquement avec {{ \land }} et {{ \lor }} est monotone croissante ; elle ne peut jamais exprimer la négation {{ \neg p }}.
  • Connecteur universel NAND (barre de Sheffer {{ | }}) : {{ \{|\} }} est complet à lui seul ! ({{ p | q \equiv \neg(p \land q) }}).
  • Connecteur universel NOR (flèche de Peirce {{ \downarrow }}) : {{ \{\downarrow\} }} est complet à lui seul ! ({{ p \downarrow q \equiv \neg(p \lor q) }}).
