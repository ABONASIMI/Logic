اهداف آموزشی و خروجی‌های یادگیری — هفته ۳
  • درک تابع بولی و فرمول شمارش تعداد آن‌ها ({{ 2^{2^n} }}).
  • تعریف دقیق لیترال، بند فصلی (Clause)، ترم عطفی، فرم FNC و فرم FND.
  • تسلط بر الگوریتم استاندارد استخراج FND (مین‌ترم‌ها) و FNC (مکس‌ترم‌ها) از روی جدول درستی.
  • تبدیل مستقیم فرمول به فرم نرمال از طریق قوانین جبر بولی بدون رسم جدول.
  • تشخیص سریع و خطی صدق‌پذیری در FND و اعتبار در FNC.
  • مفهوم تمامیت مجموعه‌های رابط‌های منطقی و رابط‌های فراگیر نند (NAND) و نور (NOR).

۱. توابع بولی و شمارش آن‌ها

تعریف ۳.۱ — تابع بولی

یک تابع بولی با {{ n }} متغیر، نگاشتی است به صورت :

{{ f : \{0, 1\}^n \longrightarrow \{0, 1\} }}

چون دامنه دارای {{ 2^n }} بردار ورودی است، تعداد کل توابع بولی ممکن دقیقاً برابر است با :

{{ 2^{2^n} \quad \text{تابع بولی متمایز با } n \text{ متغیر}. }}

۲. فرم‌های نرمال: FNC و FND

تعریف ۳.۲ — واژگان استاندارد فرم‌های نرمال
  • لیترال (Littéral): یک متغیر گزاره‌ای {{ p }} یا نقیض آن {{ \neg p }}.
  • بند فصلی (Clause): فصلی از چند لیترال : {{ (l_1 \lor l_2 \lor \dots \lor l_k) }}.
  • ترم عطفی (Terme): عطفی از چند لیترال : {{ (l_1 \land l_2 \land \dots \land l_k) }}.
  • فرم نرمال عطفی (FNC / CNF): عطف چند بند : {{ \bigwedge_{i=1}^m \left( \bigvee_{j=1}^{k_i} l_{i,j} \right) }}
  • فرم نرمال فصلی (FND / DNF): فصل چند ترم : {{ \bigvee_{i=1}^m \left( \bigwedge_{j=1}^{k_i} l_{i,j} \right) }}

۳. استخراج فرم‌های نرمال از جدول درستی

الگوریتم ساخت فرم‌های نرمال از جدول درستی
  • برای ساخت FND : تمام سطرهایی را که خروجی فرمول در آن‌ها ۱ است پیدا کنید. برای هر سطر یک مین‌ترم بنویسید (عطف متغیرها به گونه‌ای که اگر مقدار ۱ دارند خودشان و اگر ۰ دارند نقیضشان باشد). سپس بین تمام مین‌ترم‌ها علامت فصل ({{ \lor }}) بگذارید.
  • برای ساخت FNC : تمام سطرهایی را که خروجی فرمول در آن‌ها ۰ است پیدا کنید. برای هر سطر یک مکس‌ترم بنویسید (فصل متغیرها به گونه‌ای که اگر مقدار ۱ دارند نقیضشان و اگر ۰ دارند خودشان باشد). سپس بین تمام مکس‌ترم‌ها علامت عطف ({{ \land }}) بگذارید.

۴. تمامیت تابعی مجموعه‌های رابط‌های منطقی

تعریف ۳.۳ — مجموعه کامل رابط‌ها

مجموعه‌ای از رابط‌ها را کامل می‌نامند هرگاه بتوان هر تابع بولی دلخواهی را تنها با استفاده از رابط‌های آن مجموعه بیان کرد.

  • مجموعه $\{ eg, \land, \lor\}$ کامل است.
  • مجموعه‌های دو عنصری $\{ eg, \land\}{{ و }}\{ eg, \lor\}{{ و }}\{ eg, \Rightarrow\}$ همگی کاملند.
  • مجموعه {{ \{\land, \lor\} }} ناقص است: زیرا هر فرمولی که تنها با AND و OR ساخته شود یکنواخت صعودی است و هرگز نمی‌تواند نقیض را تولید کند.

  • رابط تک‌عنصری نور (NOR / پیکان پیرس {{ \downarrow }}): به تنهایی یک مجموعه کامل است!
