Examen Partiel 2021–2022 — Exercice 2 (Complétude et NAND)

Source : partiel_2021_2022_S2.pdf (p. 2)
Semaine 3Partiel

On note {{ | }} le connecteur binaire NAND (barre de Sheffer), défini par {{ p | q \equiv \neg(p \land q) }}.

1. Exprimer la négation {{ \neg p }} en utilisant uniquement le connecteur {{ | }}.
2. Exprimer la conjonction {{ p \land q }} en utilisant uniquement le connecteur {{ | }}.
3. Exprimer la disjonction {{ p \lor q }} en utilisant uniquement le connecteur {{ | }}.
4. En déduire que le jeu de connecteurs {{ \{|\} }} est fonctionnellement complet.

Correction officielle Sorbonne :
1. Négation : Par idempotence de la conjonction ({{ p \land p \equiv p }}), on a :
{{ \neg p \equiv p \mid p }}
2. Conjonction : On nie le NAND : {{ p \land q \equiv \neg(p | q) \equiv (p | q) | (p | q) }}.
3. Disjonction : Par De Morgan, {{ p \lor q \equiv \neg(\neg p \land \neg q) \equiv \neg p | \neg q \equiv (p | p) | (q | q) }}.
4. Complétude : Puisque {{ \{\neg, \land\} }} est un jeu complet de connecteurs et que chaque connecteur de ce jeu s'exprime avec {{ | }}, le jeu {{ \{|\} }} est fonctionnellement complet.
