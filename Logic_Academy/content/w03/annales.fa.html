هفته ۳امتحان Partiel

عملگر دوتایی خط شفر یا NAND را با نماد {{ | }} نشان می‌دهیم که طبق تعریف {{ p | q \equiv \neg(p \land q) }} است.

۱. نقیض {{ \neg p }} را تنها با استفاده از {{ | }} بنویسید.
۲. عطف {{ p \land q }} را تنها با استفاده از {{ | }} بیان کنید.
۳. فصل {{ p \lor q }} را تنها با استفاده از {{ | }} بیان کنید.
۴. نتیجه بگیرید که مجموعه تک‌عضوی {{ \{|\} }} یک سیستم کامل تابعی است.

پاسخ تشریحی دانشگاه سوربن :
۱. نقیض : طبق ویژگی یکسان‌توانی ({{ p \land p \equiv p }})، داریم :
{{ \neg p \equiv p \mid p }}
۲. عطف : با نفی کردن نند : {{ p \land q \equiv \neg(p | q) \equiv (p | q) | (p | q) }}.
۳. فصل : با قانون دمورگان : {{ p \lor q \equiv \neg(\neg p \land \neg q) \equiv \neg p | \neg q \equiv (p | p) | (q | q) }}.
۴. اثبات تمامیت : چون می‌دانیم مجموعه {{ \{\neg, \land\} }} کامل است و نشان دادیم هر دو عملگر نقیض و عطف تنها با رابط {{ | }} قابل ساخت هستند، پس مجموعه تک‌عضوی {{ \{|\} }} به تنهایی کامل است.
