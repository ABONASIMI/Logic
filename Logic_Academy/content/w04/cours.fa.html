۱. مسئله SAT و نمایش فرم بندی

مسئله SAT (Satisfiabilité Booléenne) تعیین صدق‌پذیری مجموعه‌ای از بندها است. این مسئله نخستین مسئله تاریخ است که کامل‌بودن آن برای کلاس NP به اثبات رسید (قضیه کوک-لوین، ۱۹۷۱).

تعریف ۴.۱ — تئوری بندی و بند تهی

یک فرمول FNC به شکل مجموعه‌ای از بندها نمایش داده می‌شود: {{ \Sigma = \{C_1, C_2, \dots, C_m\} }}.

  • یک بند زمانی ارضا می‌شود که حداقل یکی از لیترال‌های آن ارزش ۱ بگیرد.
  • مجموعه {{ \Sigma }} زمانی ارضا می‌شود که تمامی بندهای آن به طور هم‌زمان ارضا شوند.
  • بند تهی {{ \Box }} (یا {{ \{\} }}): بندی است که هیچ لیترالی ندارد. طبق تعریف فصلی، این بند همواره نادرست (تناقض) است. اگر در حین ساده‌سازی بند تهی تولید شود، آن شاخه بلافاصله ناپذیرفتنی (UNSAT) اعلام شده و پس‌گرد انجام می‌شود.
  • مجموعه تهی {{ \emptyset }}: مجموعه‌ای از صفر بند است. طبق تعریف عطفی، این مجموعه همواره درست است. اگر تمامی بندها حذف شوند، به معنای رسیدن به پاسخ SAT (صدق‌پذیر) است!

۲. دو قاعده اساسی کاهش در الگوریتم DPLL

قاعده ۱ — قاعده بند تک‌عضوی و انتشار تک‌عضوی (UP)

اگر در {{ \Sigma }} بندی تک‌عضوی مانند {{ \{l\} }} وجود داشته باشد:

برای اینکه فرمول درست شود، چاره‌ای جز قرار دادن {{ l = 1 }} نیست. با این تخصیص، تغییرات زیر در {{ \Sigma }} اعمال می‌شود:

  1. تمامی بندهایی که حاوی {{ l }} هستند به طور کامل حذف می‌شوند (چون قبلاً ارضا شده‌اند).
  2. لیترال معکوس {{ \neg l }} از تمام بندهای دیگر حذف می‌شود (چون مقدار آن صفر شده و کمکی به ارضای آن بندها نمی‌کند).

این فرآیند به صورت آبشاری تکرار می‌شود تا هیچ بند تک‌عضوی دیگری باقی نماند.

قاعده ۲ — قاعده لیترال خالص (Pure Literal)

یک لیترال {{ l }} را خالص می‌نامند هرگاه در کل مجموعه بندها ظاهر شده باشد اما نقیض آن {{ \neg l }} در هیچ بندی وجود نداشته باشد.

توجیه معنایی: با قرار دادن {{ l = 1 }}، تمام بندهای حاوی آن ارضا می‌شوند، بدون اینکه هیچ خطر یا اثر منفی برای سایر بندها ایجاد شود (چون {{ \neg l }} وجود ندارد). بنابراین تمامی بندهای حاوی {{ l }} حذف می‌شوند.

۳. هیوریستیک انتخاب متغیر {{ h_k }} در دانشگاه سوربن

هنگامی که هیچ بند تک‌عضوی یا لیترال خالصی نباشد، باید روی یک متغیر انشعاب بزنیم. فرمول هیوریستیک سوربن عبارت است از:

تعریف ۴.۲ — فرمول هیوریستیک {{ h_k(p) }}

برای طول بند {{ k \ge 2 }} و متغیر {{ p }}:

{{ h_k(p) = \text{nbocc}(k, \Sigma, p) + \text{nbocc}(k, \Sigma, \neg p) }}

که در آن {{ \text{nbocc} }} تعداد دفعات تکرار لیترال در بندهای به طول {{ k }} است.

الگوریتم اولویت انتخاب:

  1. متغیری را انتخاب می‌کنیم که {{ h_2(p) }} آن بیشترین باشد (بندهای دوتایی سریع‌تر به بند تک‌عضوی تبدیل می‌شوند).
  2. اگر مساوی شدند، با {{ h_3(p) }} و سپس {{ h_4(p) }} مقایسه می‌کنیم.
  3. اگر باز هم مساوی بودند، به ترتیب الفبایی نام متغیرها انتخاب می‌کنیم.
  4. قرارداد انشعاب: همواره ابتدا شاخه {{ p = 0 }} (نادرست) را بررسی می‌کنیم!
