متغیرها: {{ c=1 }} (قارچ)، {{ p=2 }} (فلفل)، {{ j=3 }} (ژامبون)، {{ o=4 }} (تخم‌مرغ).

  • وتوی ماری (نبود قارچ) : $ eg c \implies$ بند -1 0.
  • وتوی نیکلا (نبود تخم‌مرغ و بودن ژامبون) : $ eg o \land j \implies$ بندهای -4 0 و 3 0.
