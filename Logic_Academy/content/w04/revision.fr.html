Points Clés de l'Algorithme DPLL

  • Propagation unitaire prioritaire : Toujours exécuter TOUTES les propagations unitaires possibles avant de faire le moindre branchement.
  • Clause vide {{ \Box }} = Backtracking : Dès qu'une clause devient vide, la branche échoue immédiatement.
  • Ensemble vide {{ \emptyset }} = SAT : Dès que toutes les clauses ont disparu, la formule est satisfiable.
