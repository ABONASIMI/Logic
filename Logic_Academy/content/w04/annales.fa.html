اجرای تشریحی الگوریتم DPLL برگرفته از امتحانات میان‌ترم دانشگاه سوربن.

امتحان میان‌ترم ۲۰۱۸–۲۰۱۹ — تمرین ۲ (اجرای صوری DPLL)

منبع رسمی: partiel_2018_2019.pdf (صفحه ۲)
هفته ۴امتحان Partiel

الگوریتم DPLL را بر روی مجموعه بندهای زیر اجرا کنید: {{ \Sigma = \{\{p, q\}, \{\neg p, r\}, \{\neg q, \neg r\}, \{p, \neg r\}\} }}

پاسخ تشریحی مطابق کلید تصحیح سوربن :
در ابتدا هیچ بند تک‌عضوی یا لیترال خالصی نیست.
۱. انشعاب روی {{ p = 0 }} (شاخه نادرست اول) :
مجموعه بندها ساده می‌شود به : {{ \Sigma_{p=0} = \{\{q\}, \{\neg q, \neg r\}, \{\neg r\}\} }}.
انتشار تک‌عضوی {{ q=1 }} و {{ r=0 }} : بند دوم با {{ \neg r }} ارضا می‌شود.
تمامی بندها حذف می‌شوند و مجموعه خالی {{ \emptyset }} حاصل می‌شود.
نتیجه: SAT ! مدل ارضاکننده: {{ p=0, q=1, r=0 }}.
