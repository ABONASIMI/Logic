Exécuter rigoureusement DPLL sur : {{ \Sigma = \{\{p, q\}, \{\neg p, r\}, \{\neg q, \neg r\}, \{p, \neg r\}\} }}

Correction complète rédigée Sorbonne :
Aucune clause unitaire ni littéral pur.
1. Branchement sur {{ p = 0 }} :
{{ \Sigma_{p=0} = \{\{q\}, \{\neg q, \neg r\}, \{\neg r\}\} }}.
Propagation unitaire de {{ q = 1 }} et {{ \neg r = 1 }} ({{ r=0 }}) dans {{ \{\neg q, \neg r\} }} : la clause est satisfaite par {{ \neg r }} !
Toutes les clauses sont éliminées : {{ \Sigma = \emptyset }}.
Résultat immédiat : SAT ! Modèle trouvé : {{ p=0, q=1, r=0 }}.
