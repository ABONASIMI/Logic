Objectifs d'apprentissage — Semaine 5 (Déduction Naturelle Intuitionniste)
  • Comprendre l'architecture d'une preuve en déduction naturelle (Gentzen) et le formalisme d'Édukera.
  • Maîtriser le cycle de vie d'une hypothèse : ouverture d'une boîte, raisonnement local, et décharge.
  • Appliquer rigoureusement les règles d'introduction et d'élimination des connecteurs : {{ \land, \lor, \Rightarrow, \neg, \bot }}.
  • Comprendre la différence capitale entre la règle intuitionniste {{ \bot E }} (ex falso quodlibet) et le raisonnement par l'absurde classique ({{ RAA }}).
  • Rédiger des preuves formelles selon le canevas universitaire : Supposons... → Montrons... → Appliquons... → Conclusion.

1. Anatomie d'un Système de Déduction Naturelle

Contrairement aux tables de vérité qui calculent la vérité par énumération exhaustive, la déduction naturelle formalise le raisonnement déductif étape par étape à partir d'hypothèses.

Définition 5.1 — Jugement de Déductibilité et Boîtes d'Hypothèses

Une preuve établit un jugement de la forme : {{ \Gamma \vdash A }}

  • {{ \Gamma }} est l'ensemble des hypothèses actives (le contexte).
  • {{ A }} est la formule cible (la conclusion ou le but).
  • Boîte de preuve (Fitch / Édukera) : Pour prouver une implication {{ A \Rightarrow B }}, on ouvre une sous-preuve avec l'hypothèse temporaire {{ A }}. Dès que {{ B }} est dérivé, la boîte est fermée (l'hypothèse {{ A }} est déchargée) et on conclut {{ A \Rightarrow B }} au niveau supérieur. L'hypothèse {{ A }} n'est plus accessible ensuite !

2. Les Règles Fondamentales de la Logique Intuitionniste

Règles de l'Implication ({{ \Rightarrow }})
  • Introduction ({{ \Rightarrow I }}) : Pour prouver {{ A \Rightarrow B }}, on suppose {{ A }} et on prouve {{ B }}. L'hypothèse {{ A }} est déchargée. {{ \frac{[A] \dots \vdash B}{\vdash A \Rightarrow B} (\Rightarrow I) }}
  • Élimination ({{ \Rightarrow E }} / Modus Ponens) : Si on a {{ A \Rightarrow B }} et qu'on a {{ A }}, on en déduit {{ B }}. {{ \frac{\Gamma \vdash A \Rightarrow B \quad \Gamma \vdash A}{\Gamma \vdash B} (\Rightarrow E) }}
Règles de la Conjonction ({{ \land }})
  • Introduction ({{ \land I }}) : Si on a {{ A }} et on a {{ B }}, on en déduit {{ A \land B }}.
  • Élimination ({{ \land E_1, \land E_2 }}) : De {{ A \land B }}, on peut déduire {{ A }} (élimination gauche) ou {{ B }} (élimination droite).
Règles de la Disjonction ({{ \lor }})
  • Introduction ({{ \lor I_1, \lor I_2 }}) : De {{ A }}, on peut déduire {{ A \lor B }}. De {{ B }}, on peut déduire {{ A \lor B }}.
  • Élimination ({{ \lor E }} / Raisonnement par cas) : Si on a {{ A \lor B }}, et qu'en supposant {{ A }} on arrive à {{ C }}, et qu'en supposant {{ B }} on arrive aussi à {{ C }}, alors on a prouvé {{ C }} sans condition sur {{ A }} ou {{ B }} ! {{ \frac{\Gamma \vdash A \lor B \quad \Gamma, [A] \vdash C \quad \Gamma, [B] \vdash C}{\Gamma \vdash C} (\lor E) }}
Règles de la Négation ({{ \neg }}) et de l'Absurde Intuitionniste ({{ \bot }})

En logique formelle, la négation {{ \neg A }} est une abréviation pour {{ A \Rightarrow \bot }} (supposer {{ A }} mène à une contradiction impossible).

  • Introduction de {{ \neg }} ({{ \neg I }}) : Si en supposant {{ A }}, on dérive la contradiction {{ \bot }}, alors on a prouvé {{ \neg A }} (décharge de {{ A }}).
  • Élimination de {{ \neg }} ({{ \neg E }}) : Si on a {{ A }} et {{ \neg A }}, on en déduit immédiatement la contradiction {{ \bot }}.
  • Élimination du faux intuitionniste ({{ \bot E }} / Ex Falso Quodlibet) : De la contradiction {{ \bot }}, on peut déduire N'IMPORTE QUELLE proposition {{ B }} ! {{ \frac{\Gamma \vdash \bot}{\Gamma \vdash B} (\bot E) }}
Exemple Fondamental Décortiqué — Preuve de $ eg A \Rightarrow (A \Rightarrow B)$

Voici la démonstration pas à pas exigée à l'examen :

  1. On veut prouver une implication dont la prémisse est {{ \neg A }}.
    Supposons {{ \neg A }} (Hypothèse 1).
  2. Le but restant est {{ A \Rightarrow B }}, qui est encore une implication.
    Supposons {{ A }} (Hypothèse 2).
  3. On a maintenant l'hypothèse 1 ($ eg A{{ ) et l'hypothèse 2 ( }}A$) dans notre boîte active.
    Appliquons la règle {{ \neg E }} entre {{ A }} et {{ \neg A }} : on obtient {{ \bot }} (contradiction).
  4. De {{ \bot }}, appliquons la règle intuitionniste {{ \bot E }} : on déduit {{ B }} !
  5. On ferme l'hypothèse 2 ({{ A }}) : par {{ \Rightarrow I }}, on conclut {{ A \Rightarrow B }}.
  6. On ferme l'hypothèse 1 ($ eg A{{ ) : par }}\Rightarrow I$, on conclut {{ \neg A \Rightarrow (A \Rightarrow B) }}. Preuve terminée !
