Annales Semaine 5 — Preuves Formelles d'Examen

Sujets réels d'examens testant la déduction naturelle intuitionniste (partiel 2016-2017 et 2017-2018).

Question d'examen classique : Prouver {{ \vdash (A \land B) \Rightarrow (B \land A) }}.
Solution : Supposer {{ A \land B }}, appliquer {{ \land E_2 }} pour {{ B }}, {{ \land E_1 }} pour {{ A }}, appliquer {{ \land I }} pour {{ B \land A }}, décharger par {{ \Rightarrow I }}.
