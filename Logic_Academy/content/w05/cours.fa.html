اهداف آموزشی و خروجی‌های یادگیری — هفته ۵ (استنتاج طبیعی شهودگرایانه)
  • درک معماری سیستم استنتاج طبیعی گنتزن و روش ساخت اثبات‌ها در پلتفرم ادوکرا (Édukera).
  • تسلط بر چرخه حیات فرضیه‌ها: باز کردن باکس فرضیه، استدلال محلی و رهاسازی (Décharge) به‌موقع.
  • به‌کارگیری دقیق قواعد معرفی و حذف رابط‌های گزاره‌ای: {{ \land, \lor, \Rightarrow, \neg, \bot }}.
  • درک تفاوت حیاتی قاعده شهودگرایانه {{ \bot E }} (خروج هر چیز از تناقض) با برهان خلف کلاسیک ({{ RAA }}).
  • نگارش تشریحی اثبات‌ها مطابق الگوی استاندارد سوربن: فرض می‌کنیم... → نشان می‌دهیم... → قاعده اعمال می‌شود... → نتیجه‌گیری.

۱. ساختار سیستم استنتاج طبیعی و باکس‌های فیتش (Édukera)

استنتاج طبیعی روشی است که نحوه استدلال منطقی ذهن ریاضیدانان را بدون نیاز به جدول درستی پیاده‌سازی می‌کند.

تعریف ۵.۱ — حکم استنتاج و باکس‌های فرضیه

هر خط اثبات بیانگر یک حکم به صورت {{ \Gamma \vdash A }} است که در آن {{ \Gamma }} فرضیه‌های فعال و {{ A }} حکم اثبات‌شده است.

  • برای اثبات یک شرطی مانند {{ A \Rightarrow B }}، یک باکس جدید باز کرده و {{ A }} را فرض می‌کنیم.
  • درون باکس با کمک {{ A }} تلاش می‌کنیم به {{ B }} برسیم.
  • به محض رسیدن به {{ B }}، باکس بسته می‌شود و فرضیه {{ A }} رهاسازی می‌گردد؛ در سطح بالاتر حکم {{ A \Rightarrow B }} ثبت می‌شود. دیگر در ادامه اثبات حق استفاده مستقیم از {{ A }} را نداریم!

۲. قواعد معرفی و حذف رابط‌ها در منطق شهودگرایانه

قواعد شرطی ({{ \Rightarrow }})
  • معرفی شرطی ({{ \Rightarrow I }}): برای اثبات {{ A \Rightarrow B }}، فرضیه {{ A }} را باز می‌کنیم و به {{ B }} می‌رسیم.
  • حذف شرطی ({{ \Rightarrow E }} / قیاس استثنایی Modus Ponens): اگر {{ A \Rightarrow B }} و {{ A }} را داشته باشیم، {{ B }} نتیجه می‌شود.
قاعده طلایی تناقض شهودگرایانه ({{ \bot E }})

در منطق شهودگرایانه نقیض {{ \neg A }} به صورت {{ A \Rightarrow \bot }} تعریف می‌شود.

اگر در فرآیند استدلال به تناقض یا گزاره ناممکن {{ \bot }} برسیم، طبق قاعده {{ \bot E }} (Ex Falso Quodlibet) می‌توانیم هر گزاره دلخواهی مانند {{ B }} را نتیجه بگیریم!

مثال تشریحی گام‌به‌گام — اثبات فرمول $ eg A \Rightarrow (A \Rightarrow B)$
  1. می‌خواهیم یک گزاره شرطی با مقدم {{ \neg A }} را اثبات کنیم.
    فرضیه ۱ را باز می‌کنیم: فرض کنیم {{ \neg A }}.
  2. هدف باقیمانده {{ A \Rightarrow B }} است که خود یک شرطی است.
    فرضیه ۲ را باز می‌کنیم: فرض کنیم {{ A }}.
  3. اکنون در باکس فعال هم {{ A }} و هم {{ \neg A }} را داریم.
    با اعمال قاعده {{ \neg E }}، تناقض {{ \bot }} به دست می‌آید.
  4. از تناقض {{ \bot }} با اعمال قاعده {{ \bot E }}، گزاره {{ B }} را نتیجه می‌گیریم!
  5. فرضیه ۲ را می‌بندیم: با قاعده {{ \Rightarrow I }}، گزاره {{ A \Rightarrow B }} اثبات می‌شود.
  6. فرضیه ۱ را می‌بندیم: با قاعده {{ \Rightarrow I }}، گزاره {{ \neg A \Rightarrow (A \Rightarrow B) }} به طور کامل اثبات شد!
