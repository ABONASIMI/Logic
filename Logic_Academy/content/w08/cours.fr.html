Objectifs d'apprentissage — Semaine 8 (LPPO Sémantique)
  • Comprendre la notion de structure {{ \mathcal{M} = \langle D, \mathcal{I} \rangle }} : domaine non vide et interprétation des symboles.
  • Évaluer des formules avec quantificateurs selon la sémantique de Tarski.
  • Évaluer rigoureusement des formules du premier ordre sur des domaines finis.
  • Définir et exécuter une substitution de terme {{ F[x \leftarrow t] }} sans capture de variable.
  • Construire des contre-modèles finis pour invalider des formules du premier ordre.

1. Structures et Interprétations

Définition 8.1 — Structure {{ \mathcal{M} = \langle D, \mathcal{I} \rangle }}

Une structure pour un langage {{ \mathcal{L} }} est la donnée de :

  • Un ensemble non vide {{ D }} appelé le domaine de discours ;
  • Pour chaque constante {{ c }}, un élément {{ c^\mathcal{M} \in D }} ;
  • Pour chaque fonction {{ f }} d'arité {{ n }}, une fonction {{ f^\mathcal{M} : D^n \to D }} ;
  • Pour chaque prédicat {{ P }} d'arité {{ n }}, une relation {{ P^\mathcal{M} \subseteq D^n }}.

2. Substitution Admissible (Sans Capture)

Définition 8.2 — Substitution {{ F[x \leftarrow t] }}

L'opération {{ F[x \leftarrow t] }} remplace toutes les occurrences libres de la variable {{ x }} par le terme {{ t }}.

Condition d'admissibilité (évitement de capture) : Le terme {{ t }} est librement substituable à {{ x }} dans {{ F }} si aucune variable de {{ t }} n'est capturée par un quantificateur englobant lors du remplacement ! Si une capture menace, on doit obligatoirement renommer d'abord la variable liée ({{ \alpha }}-conversion).
