1. Examen 2020-2021 Session 1 — Exercice 3

Énoncé Officiel

Le but de cet exercice est de prouver la formule {{ \exists x (p(x) \implies orall y p(y)) }} en utilisant la règle du Tiers Exclu.

Corrigé d'Examen

Il s'agit exactement de la décomposition modulaire en 4 sous-preuves vue au TD 9 Exercice 34. Les étudiants ayant rédigé la preuve avec les lemmes intermédiaires {{ B_1 }}, {{ B_2 }}, {{ B_3 }} ont obtenu la note maximale (5/5).

2. Examen 2022-2023 Session 1 — Exercice 2

Énoncé Officiel

Prouver en déduction naturelle classique la formule :

{{ (\forall x p(x) \implies \exists x q(x)) \implies \exists x (p(x) \implies q(x)) }}
Corrigé d'Examen

Preuve par tiers exclu sur {{ orall x p(x) }} : si {{ orall x p(x) }} est vrai, alors par hypothèse {{ \exists x q(x) }} est vrai ; soit {{ c }} tel que {{ q(c) }}, alors {{ p(c) \implies q(c) }} est vrai. Si $ eg orall x p(x){{ est vrai, il existe }}c{{ tel que }} eg p(c){{ , d'où }}p(c) \implies q(c){{ est vrai par ex falso. Conclusion par }}\exists I$.
