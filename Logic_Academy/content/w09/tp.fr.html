1. Manipulation des Règles Quantificateurs dans Édukera

Dans Édukera, chaque règle est représentée par un bloc graphique :

  • Pour {{ orall I }} : Édukera crée automatiquement une boîte indentée étiquetée avec un nom de variable fraîche (ex: x_0). Il est impossible de faire référence à une variable déjà liée ou libre dans le contexte !
  • Pour {{ orall E }} : Vous devez fournir au système le terme exact avec lequel instancier la variable quantifiée (ex: c, f(a), etc.).
  • Pour {{ \exists I }} : Vous devez glisser le témoin dans le slot d'entrée de la règle.
  • Pour {{ \exists E }} : Édukera ouvre une sous-boîte en introduisant une nouvelle constante de Skolem locale. Toute tentative de faire fuiter cette variable hors de la boîte déclenche une erreur de validité logique.
Règle de l'échiquier Édukera pour les contre-modèles

Pour chaque formule non valide proposée par Édukera, vous devez poser au moins une pièce de chaque type sur l'échiquier pour construire un contre-modèle fini.
