1. Les 4 Règles d'Inférence des Quantificateurs

En Logique des Propositions, la déduction naturelle manipulait des connecteurs booléens ($\land, \lor, \implies, eg{{ ). En LPPO, nous ajoutons les quantificateurs }} orall{{ et }}\exists{{ . Chaque quantificateur possède une règle d'introduction ( }}I{{ ) et une règle d'élimination ( }}E$).

Règle {{ \forall I }} (Introduction du Pour-Tout)

Pour prouver qu'une propriété {{ A }} est vraie pour TOUT élément ({{ orall x A }}), on prouve qu'elle est vraie pour un élément arbitraire représenté par une nouvelle variable {{ y }}.

{{ \frac{A[x \leftarrow y]}{\forall x A} (\forall I) }}

Condition critique de fraîcheur (Side Condition) : La variable {{ y }} doit être fraîche. C'est-à-dire que {{ y }} ne doit apparaître libre dans aucune hypothèse active dont dépend {{ A[x \leftarrow y] }}.

Règle {{ \forall E }} (Élimination du Pour-Tout)

Si l'on sait que {{ \forall x A }} est vrai, alors la propriété est vraie pour n'importe quel terme {{ t }} constructible dans le langage !

{{ \frac{\forall x A}{A[x \leftarrow t]} (\forall E) }}

Condition : Le terme {{ t }} doit être librement substituable à {{ x }} dans {{ A }} (aucune variable de {{ t }} ne doit être capturée par un quantificateur interne de {{ A }}).

Règle {{ \exists I }} (Introduction de l'Existant)

Pour prouver qu'il existe un élément vérifiant {{ A }} ({{ \exists x A }}), il suffit de trouver un exemple concret (un témoin {{ t }}) pour lequel {{ A[x \leftarrow t] }} est vrai.

{{ \frac{A[x \leftarrow t]}{\exists x A} (\exists I) }}
Règle {{ \exists E }} (Élimination de l'Existant)

Si l'on sait qu'il existe au moins un élément vérifiant {{ A }} ({{ \exists x A }}), et que l'on veut prouver une conclusion {{ C }}, on ouvre une sous-preuve en supposant que cet élément s'appelle {{ y }} (inconnu mais fixé) :

{{ \frac{\exists x A \quad [A[x \leftarrow y]] \vdash C}{C} (\exists E) }}

Condition critique de fraîcheur : Le paramètre {{ y }} ne doit apparaître libre :

  1. Dans aucune des hypothèses actives résiduelles (en dehors de l'hypothèse locale {{ A[x \leftarrow y] }} qui est déchargée).
  2. Ni dans la conclusion finale {{ C }} ! (On ne peut pas faire sortir le nom de la variable locale de sa portée).

2. Le Paradoxe du Buveur (Drinker's Paradox)

Théorème 9.1 — Le Paradoxe du Buveur

Dans tout bar (non vide), il existe une personne {{ x }} telle que : si cette personne boit, alors tout le monde boit !

{{ \vdash \exists x (P(x) \implies \forall y P(y)) }}
Principe et Intuition de la Preuve

Ce résultat semble magique ou paradoxal dans le langage courant, mais il est purement classique et découle du Tiers Exclu appliqué à la formule {{ \forall y P(y) }} :

  • Cas 1 : Tout le monde boit ({{ orall y P(y) }} est vrai).
    Prenons n'importe qui dans le bar, disons Alice ({{ a }}). L'implication {{ P(a) \implies orall y P(y) }} a une conclusion vraie, donc l'implication est vraie ! Alice est le buveur cherché.
  • Cas 2 : Quelqu'un ne boit pas ($ eg orall y P(y){{ est vrai, donc }}\exists y eg P(y)$).
    Soit Bob ({{ b }}) une personne qui ne boit pas ($ eg P(b){{ ). Dans l'implication }}P(b) \implies orall y P(y){{ , la prémisse }}P(b){{ est fausse ! Or, en logique, faux implique n'importe quoi ( }}F \implies Q \equiv V$). Donc l'implication est vraie pour Bob ! Bob est le buveur cherché.

Dans tous les cas, un tel buveur existe toujours !

Pourquoi je me trompe ? — Les Erreurs Fatales en Déduction Naturelle LPPO

Erreur 1 : Utiliser une variable déjà mentionnée dans {{ orall I }}. Si vous posez {{ y }} alors que {{ y }} apparaît dans une hypothèse active (par exemple dans {{ P(y) }}), vous prouvez en réalité {{ P(y) \implies orall x P(x) }}, ce qui est complètement faux sémantiquement !

Erreur 2 : Faire sortir la variable témoin de l'élimination existentielle {{ \exists E }}. Si vous partez de {{ \exists x P(x) }}, supposez {{ P(y) }}, et concluez immédiatement {{ P(y) }} hors de la boîte, vous avez violé la règle car {{ y \in Free(C) }} ! Vous venez de déduire « tout {{ y }} vérifie {{ P }} » à partir d'un simple existant !
