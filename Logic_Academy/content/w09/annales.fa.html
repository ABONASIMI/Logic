منتخب سؤالات امتحانات نهایی دانشگاه سوربن در موضوع اثبات‌های صوری با سورها.

۱. امتحان ۲۰۲۰–۲۰۲۱ نوبت اول — سؤال ۳

صورت رسمی سؤال

هدف این سؤال اثبات فرمول {{ \exists x (p(x) \implies orall y p(y)) }} با استفاده از قاعده طرد شق ثالث است.

پاسخ تشریحی امتحانی

این سؤال دقیقاً همان تمرین ۳۴ کتابچه تمرینات دانشگاه است که در بخش TD هفته ۹ به تفصیل با لم‌های {{ B_1 }} و {{ B_2 }} و {{ B_3 }} به طور کامل حل کردیم.

۲. امتحان ۲۰۲۲–۲۰۲۳ نوبت اول — سؤال ۲

صورت رسمی سؤال

اثبات فرمول زیر در استنتاج طبیعی کلاسیک:

{{ (\forall x p(x) \implies \exists x q(x)) \implies \exists x (p(x) \implies q(x)) }}
پاسخ تشریحی امتحانی

اثبات با طرد شق ثالث روی {{ orall x p(x) }}: اگر همه عناصر در {{ p }} صدق کنند، با فرض مساله شاهدی برای {{ q }} پیدا می‌شود و شرط برقرار است. اگر عضوی در {{ p }} صدق نکند، مقدم شرط نادرست شده و باز هم کل رابطه شرطی با آن شاهد برقرار است.
