تمرین ۳۳ — اثبات فرمول‌های سوردار (صفحه ۱۹)

اثبات دقیق هر ۷ فرمول به روش استنتاج طبیعی.

سؤال ۱ : {{ F_1 = (\forall x p(x) \lor \forall x q(x)) \implies \forall x (p(x) \lor q(x)) }}

حل تشریحی گام‌به‌گام سؤال ۱

استراتژی: مقدم شرط را فرض می‌کنیم {{ h_1 : \forall x p(x) \lor \forall x q(x) }}. چون این فرض یک فصل ({{ \lor }}) است، قاعده حذف فصل ({{ \lor E }}) را روی دو شاخه اجرا می‌کنیم. در هر شاخه، یک متغیر تازه مانند {{ y }} برمی‌داریم، با قاعده {{ orall E }} ویژگی {{ p(y) }} یا {{ q(y) }} را استخراج می‌کنیم، سپس با {{ \lor I }} به {{ p(y) \lor q(y) }} می‌رسیم و نهایتاً با {{ orall I }} سور کلی {{ orall x }} را می‌سازیم.

۱ فرض اصلی {{ h_1 : orall x p(x) \lor orall x q(x) }}
۲ زیربرهان حالت اول: {{ h_2 : orall x p(x) }}
۳ فرض متغیر تازه {{ y }}
۴ {{ p(y) }} با {{ orall E }} روی خط ۲ با جایگزینی {{ x \leftarrow y }}
۵ {{ p(y) \lor q(y) }} با معرفی فصل راست {{ \lor I }}
۶ {{ orall x (p(x) \lor q(x)) }} با قاعده {{ orall I }} روی ۳–۵ (چون {{ y }} تازه است)
۷ زیربرهان حالت دوم: {{ h_3 : orall x q(x) }}
۸ فرض متغیر تازه {{ y }}
۹ {{ q(y) }} با {{ orall E }} روی خط ۷ با {{ x \leftarrow y }}
۱۰ {{ p(y) \lor q(y) }} با معرفی فصل چپ {{ \lor I }}
۱۱ {{ orall x (p(x) \lor q(x)) }} با قاعده {{ orall I }} روی ۸–۱۰
۱۲ {{ orall x (p(x) \lor q(x)) }} با حذف فصل {{ \lor E }} روی خطوط ۱، ۲–۶، ۷–۱۱
۱۳ {{ ( orall x p(x) \lor orall x q(x)) \implies orall x (p(x) \lor q(x)) }} با معرفی شرط {{ \implies I }} و تخلیه فرض ۱

سؤال ۳ : {{ F_3 = (\exists x \forall y r(x, y)) \implies (\forall y \exists x r(x, y)) }}

قاعده طلایی دامنه‌ها در جابجایی سورها ({{ \exists orall \implies orall \exists }})

فرض می‌کنیم {{ h_1 : \exists x orall y r(x, y) }}. برای حذف سور وجود ({{ \exists E }})، یک پارامتر تازه به نام {{ a }} و فرض محلی {{ h_2 : orall y r(a, y) }} تعیین می‌کنیم. حال برای اثبات سور کلی بیرون یعنی {{ orall y }}， یک متغیر تازه دیگر به نام {{ b }} می‌گیریم ({{ orall I }}). با اعمال {{ orall E }} روی {{ h_2 }} با ترم {{ b }} به {{ r(a, b) }} می‌رسیم. سپس با {{ \exists I }} و قرار دادن شاهد {{ a }} به {{ \exists x r(x, b) }} دست می‌یابیم. با بستن جعبه متغیر {{ b }}، به {{ orall y \exists x r(x, y) }} می‌رسیم و در نهایت با حذف وجود، جعبه {{ a }} را می‌بندیم. حکم کاملاً اثبات شد!

تمرین ۳۴ — برهان‌های تو در تو: پارادوکس می‌خوار (صفحات ۱۹ و ۲۰)

هدف اثبات فرمول {{ \exists x (p(x) \implies orall y p(y)) }} در ۴ مرحله مدولار دانشگاهی است.

حل بخش ۱: برهان {{ B_1 }} با فرض {{ h_1 : orall y p(y) }}

تحت فرض {{ h_1 }}، یک متغیر دلخواه تازه مانند {{ z }} انتخاب می‌کنیم. اگر فرض موقت {{ p(z) }} را اضافه کنیم، چون تالی یعنی {{ orall y p(y) }} از خط ۱ آماده است، شرط {{ p(z) \implies orall y p(y) }} صادق است. سپس با معرفی سور وجود ({{ \exists I }}) و قرار دادن شاهد {{ z }}، فرمول نهایی به دست می‌آید.

حل بخش ۲: برهان {{ B_2 }} برای $( eg orall y p(y)) \implies (\exists y eg p(y))$

این رابطه هم‌ارزی دمورگان سورها در حالت کلی نیازمند منطق کلاسیک و برهان خلف (RAA) است. برای اثبات $\exists y eg p(y){{ ، فرض خلف }} eg \exists y eg p(y){{ را می‌گذاریم. به کمک آن نشان می‌دهیم که برای هر }}z{{ دلخواه، }}p(z){{ برقرار است، لذا }} orall y p(y){{ نتیجه می‌شود که با فرض }} eg orall y p(y)$ تناقض دارد؛ پس حکم اثبات می‌شود.

حل بخش ۳: برهان {{ B_3 }} تحت فرض $h_2 : eg orall y p(y)$

با برهان {{ B_2 }} نتیجه می‌گیریم $\exists y eg p(y){{ . حال با }}\exists E{{ متغیر تازه }}z{{ و فرض }}h_3 : eg p(z){{ را باز می‌کنیم. درون این جعبه، اگر فرض کنیم }}p(z){{ ، با }} eg p(z){{ تناقض }}(ot){{ می‌دهد و طبق قاعده از تناقض هر چیزی برمی‌آید ( }}ot E{{ )، گزاره }} orall y p(y){{ حاصل می‌شود؛ لذا }}p(z) \implies orall y p(y){{ درست است و با شاهد }}z$ به فرمول مطلوب می‌رسیم.

حل بخش ۴: ترکیب نهایی با طرد شق ثالث (Tiers Exclu)

طبق اصل طرد شق ثالث کلاسیک، گزاره $ orall y p(y) \lor eg orall y p(y)$ همواره صادق است. در شاخه اول برهان {{ B_1 }} و در شاخه دوم برهان {{ B_3 }} هر دو مستقلاً فرمول را ثابت می‌کنند. با حذف فصل، بدون هیچ فرض باقی‌مانده‌ای، برهان کامل می‌شود!
