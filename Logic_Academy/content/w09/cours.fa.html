اهداف یادگیری — هفته ۹ (استنتاج طبیعی در منطق مرتبه اول LPPO)
  • تسلط بر ۴ قاعده استنتاج سورها: {{ \forall I }} (معرفی برای‌هر)، {{ \forall E }} (حذف برای‌هر)، {{ \exists I }} (معرفی وجود)، و {{ \exists E }} (حذف وجود).
  • فهم عمیق شرط متغیر تازه (Eigenvariable Condition) در {{ \forall I }} و {{ \exists E }} و چرایی باطل شدن برهان در صورت نقض آن.
  • مهارت در پیاده‌سازی نمونه‌سازی کلی ({{ orall E }}) و شاهد وجودی ({{ \exists I }}).
  • تسلط بر حذف سور وجود ({{ \exists E }}) به شکل یک جعبه فرض محلی با پارامتر تازه.
  • درک و اثبات رسمی پارادوکس مشهور می‌خوار (Drinker's Paradox): {{ \exists x (P(x) \implies \forall y P(y)) }} با استفاده از طرد شق ثالث.

۱. چهار قاعده اصلی استنتاج برای سورها

در منطق گزاره‌ای با عملگرهای بولی ($\land, \lor, \implies, eg{{ ) کار می‌کردیم. در منطق مرتبه اول (LPPO)، سورهای }} orall{{ و }}\exists$ اضافه می‌شوند. برای هر سور یک قاعده معرفی (I) و یک قاعده حذف (E) داریم.

قاعده {{ \forall I }} (معرفی سور کلی - Pour-tout)

برای اثبات این‌که یک ویژگی {{ A }} برای همه عناصر برقرار است ({{ orall x A }})، ثابت می‌کنیم که برای یک عنصر کاملاً دلخواه و اختیاری با نماد متغیر تازه {{ y }} درست است.

{{ \frac{A[x \leftarrow y]}{\forall x A} (\forall I) }}

شرط حیاتی تازگی (Eigenvariable) : نماد {{ y }} باید تازه باشد؛ یعنی {{ y }} نباید در هیچ‌یک از فرض‌های فعال که {{ A[x \leftarrow y] }} به آن‌ها وابسته است، به صورت آزاد ({{ Free }}) ظاهر شده باشد.

قاعده {{ \forall E }} (حذف سور کلی)

اگر بدانیم {{ \forall x A }} صادق است، آن ویژگی برای هر ترم دلخواهی مثل {{ t }} که در زبان ساخته شود صادق خواهد بود!

{{ \frac{\forall x A}{A[x \leftarrow t]} (\forall E) }}

شرط: ترم {{ t }} باید بتواند آزادانه جایگزین {{ x }} شود (متغیرهای درون {{ t }} در دامنه سورهای درونی {{ A }} به دام نیفتند).

قاعده {{ \exists I }} (معرفی سور وجود)

برای اثبات وجود عنصری با ویژگی {{ A }} ({{ \exists x A }})، کافی است فقط یک مثال مشخص و عینی (یک ترم شاهد {{ t }}) ارائه دهیم که {{ A[x \leftarrow t] }} برای آن برقرار باشد.

{{ \frac{A[x \leftarrow t]}{\exists x A} (\exists I) }}
قاعده {{ \exists E }} (حذف سور وجود)

اگر بدانیم حداقل یک عنصر با ویژگی {{ A }} وجود دارد ({{ \exists x A }})، و هدف ما اثبات نتیجه‌ای مانند {{ C }} باشد، یک برهان فرعی باز می‌کنیم و فرض می‌کنیم نام آن عنصر {{ y }} باشد (موجودی ناشناخته اما معین):

{{ \frac{\exists x A \quad [A[x \leftarrow y]] \vdash C}{C} (\exists E) }}

شرط اساسی تازگی: پارامتر موقت {{ y }} نباید به صورت آزاد ظاهر شود:

  1. در هیچ‌یک از فرضیات فعال دیگر (به جز فرض محلی {{ A[x \leftarrow y] }} که در انتهای جعبه بسته و تخلیه می‌شود).
  2. در خود نتیجه نهایی {{ C }} نیز نباید آزاد باشد! (نام متغیر محلی درون جعبه هرگز نباید به بیرون درز کند).

۲. پارادوکس می‌خوار (Drinker's Paradox)

قضیه ۹.۱ — پارادوکس می‌خوار

در هر میخانه (غیرخالی)، همواره شخصی مانند {{ x }} وجود دارد به طوری که: اگر او بنوشد، آنگاه همه در میخانه می‌نوشند!

{{ \vdash \exists x (P(x) \implies \forall y P(y)) }}
شهود و چرایی اثبات با طرد شق ثالث

این گزاره در زبان روزمره شگفت‌انگیز یا ناممکن به نظر می‌رسد، اما یک تاتولوژی منطق کلاسیک است که از طرد شق ثالث روی {{ \forall y P(y) }} حاصل می‌شود:

  • حالت اول: همه در حال نوشیدن هستند ({{ orall y P(y) }} صادق است).
    هر شخصی را در میخانه در نظر بگیرید، مثلاً سهراب ({{ a }}). در این شرط، تالی ({{ Q }}) یعنی «همه می‌نوشند» درست است؛ پس شرط {{ P(a) \implies orall y P(y) }} به طور بدیهی درست است! سهراب همان شخص مورد نظر است.
  • حالت دوم: حداقل یک نفر نمی‌نوشد ($ eg orall y P(y){{ صادق است، یعنی }}\exists y eg P(y)$).
    فرض کنیم رستم ({{ b }}) شخصی است که نمی‌نوشد ($ eg P(b){{ ). در عبارت شرطی }}P(b) \implies orall y P(y){{ ، مقدم شرط ( }}P(b){{ ) نادرست است! و می‌دانیم در منطق گزاره‌ای، از نادرست هر نتیجه‌ای حاصل می‌شود ( }}F \implies Q \equiv V$). پس این رابطه شرطی برای رستم برقرار است! رستم همان شخص است.

بنابراین در تمام جهان‌های ممکن، همیشه چنین شخصی وجود دارد!

چرا اشتباه می‌کنم؟ — خطاهای ویرانگر در استنتاج طبیعی LPPO

خطای ۱: انتخاب متغیری که قبلاً در فرضیات آمده است در قاعده {{ orall I }}. اگر برای متغیر دلخواه نامی بگذارید که در فرضیات فعال وجود دارد (مثلاً {{ y }} در فرض {{ P(y) }})، شما عملاً {{ P(y) \implies orall x P(x) }} را نتیجه می‌گیرید که کاملاً غلط است!

خطای ۲: بیرون آوردن متغیر محلی در قاعده {{ \exists E }}. اگر با فرض {{ P(y) }} از {{ \exists x P(x) }} نتیجه بگیرید {{ P(y) }} و جعبه را ببندید، چون {{ y }} در نتیجه باقی مانده است، کل برهان باطل است؛ زیرا شما از «وجود حداقل یک مورد» نتیجه گرفته‌اید که «فلان متغیر مشخص» همواره آن ویژگی را دارد!
