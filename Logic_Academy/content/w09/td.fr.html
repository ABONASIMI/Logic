Exercice 33 — Preuves de Formules Quantifiées (p. 19)

Prouver rigoureusement chacune des 7 formules ci-dessous en déduction naturelle.

Question 1 : {{ F_1 = (\forall x p(x) \lor \forall x q(x)) \implies \forall x (p(x) \lor q(x)) }}

Correction détaillée Question 1

Stratégie : On suppose l'hypothèse de gauche {{ h_1 : \forall x p(x) \lor \forall x q(x) }}. Il s'agit d'une disjonction, donc on effectue une élimination de la disjonction {{ (\lor E) }} avec deux sous-preuves. Dans chaque cas, on choisit une variable fraîche {{ y }}, on instancie le quantificateur universel {{ (\forall E) }} avec {{ y }}, puis on introduit la disjonction {{ (\lor I) }} et enfin le quantificateur universel {{ (\forall I) }}.

1 Hypothèse {{ h_1 : orall x p(x) \lor orall x q(x) }}
2 Sous-preuve Cas 1 : {{ h_2 : orall x p(x) }}
3 Soit {{ y }} une variable fraîche
4 {{ p(y) }} par {{ orall E }} sur 2 avec {{ x \leftarrow y }}
5 {{ p(y) \lor q(y) }} par {{ \lor I_g }} sur 4
6 {{ orall x (p(x) \lor q(x)) }} par {{ orall I }} sur 3–5 ({{ y }} fraîche)
7 Sous-preuve Cas 2 : {{ h_3 : orall x q(x) }}
8 Soit {{ y }} une variable fraîche
9 {{ q(y) }} par {{ orall E }} sur 7 avec {{ x \leftarrow y }}
10 {{ p(y) \lor q(y) }} par {{ \lor I_d }} sur 9
11 {{ orall x (p(x) \lor q(x)) }} par {{ orall I }} sur 8–10 ({{ y }} fraîche)
12 {{ orall x (p(x) \lor q(x)) }} par {{ \lor E }} sur 1, 2–6, 7–11
13 {{ ( orall x p(x) \lor orall x q(x)) \implies orall x (p(x) \lor q(x)) }} par {{ \implies I }} déchargeant 1

Question 2 : {{ F_2 = (\exists x (p(x) \lor q(x))) \implies (\exists x p(x) \lor \exists x q(x)) }}

Correction détaillée Question 2

Stratégie : Supposons {{ h_1 : \exists x (p(x) \lor q(x)) }}. Pour éliminer cet existentiel {{ (\exists E) }}, on introduit une variable fraîche {{ y }} et l'hypothèse locale {{ p(y) \lor q(y) }}. On élimine ensuite la disjonction : si {{ p(y) }}, alors {{ \exists x p(x) }} par {{ \exists I }} (témoin {{ y }}), puis {{ \exists x p(x) \lor \exists x q(x) }} par {{ \lor I }}. De même si {{ q(y) }}. La conclusion ne contenant pas {{ y }}, la règle {{ \exists E }} est valide !

Question 3 : {{ F_3 = (\exists x \forall y r(x, y)) \implies (\forall y \exists x r(x, y)) }}

Correction détaillée Question 3 (Inversion {{ \exists orall \implies orall \exists }})

Règle d'or des portées : On suppose {{ h_1 : \exists x orall y r(x, y) }}. On applique {{ \exists E }} en fixant une variable fraîche {{ a }} et {{ h_2 : orall y r(a, y) }}. Maintenant, pour prouver {{ orall y \exists x r(x, y) }}, on se donne une nouvelle variable fraîche {{ b }} ({{ orall I }}). Par {{ orall E }} sur {{ h_2 }} avec le terme {{ b }}, on obtient {{ r(a, b) }}. Par {{ \exists I }} avec le témoin {{ a }}, on obtient {{ \exists x r(x, b) }}. Par {{ orall I }} sur {{ b }}, on obtient {{ orall y \exists x r(x, y) }}. Enfin par {{ \exists E }}, on décharge {{ a }}. CQFD !

Exercice 34 — Preuves Imbriquées : Le Paradoxe du Buveur (p. 19-20)

Le but est de prouver {{ \exists x (p(x) \implies orall y p(y)) }} en 4 étapes modulaires.

Correction Q1 : Preuve {{ B_1 }} sous l'hypothèse {{ h_1 : orall y p(y) }}

Sous l'hypothèse {{ h_1 }}, choisissons une variable fraîche quelconque {{ z }}.

1 Hypothèse {{ h_1 : orall y p(y) }}
2 Sous-hypothèse {{ h' : p(z) }}
3 {{ orall y p(y) }} Répétition de 1
4 {{ p(z) \implies orall y p(y) }} par {{ \implies I }} déchargeant 2
5 {{ \exists x (p(x) \implies orall y p(y)) }} par {{ \exists I }} avec le témoin {{ z }}
Correction Q2 : Preuve {{ B_2 }} de $( eg orall y p(y)) \implies (\exists y eg p(y))$

Cette dualité n'est pas intuitionniste ; elle nécessite le Raisonnement par l'Absurde classique (RAA) : pour prouver $\exists y eg p(y){{ , on suppose sa négation }} eg \exists y eg p(y){{ . Pour toute variable }}z{{ , si }} eg p(z){{ , alors }}\exists y eg p(y){{ , contradiction avec l'hypothèse ! Donc par RAA, }}p(z){{ est vrai. Comme }}z{{ est fraîche, }} orall y p(y){{ est vrai par }} orall I{{ . Contradiction avec }} eg orall y p(y){{ ! Donc par RAA, }}\exists y eg p(y)$ est prouvé.

Correction Q3 : Preuve {{ B_3 }} sous l'hypothèse $h_2 : eg orall y p(y)$

Par la preuve {{ B_2 }}, on déduit $\exists y eg p(y){{ . On applique }}\exists E{{ avec une variable fraîche }}z{{ et l'hypothèse }}h_3 : eg p(z)$.

1 Hypothèse $h_2 : eg orall y p(y)$
2 $\exists y eg p(y)$ par application de la preuve {{ B_2 }} sur 1
3 Soit {{ z }} frais, hypothèse $h_3 : eg p(z)$
4 Sous-hypothèse {{ h_4 : p(z) }}
5 {{ ot }} par $ eg E$ sur 4 et 3
6 {{ orall y p(y) }} par {{ ot E }} (ex falso) sur 5
7 {{ p(z) \implies orall y p(y) }} par {{ \implies I }} déchargeant 4
8 {{ \exists x (p(x) \implies orall y p(y)) }} par {{ \exists I }} avec le témoin {{ z }}
9 {{ \exists x (p(x) \implies orall y p(y)) }} par {{ \exists E }} sur 2 et 3–8
Correction Q4 : Synthèse par le Tiers Exclu

Par la règle du Tiers Exclu classique {{ (TE) }}, on a $ orall y p(y) \lor eg orall y p(y)$.

  • Dans la première branche ({{ orall y p(y) }}), la preuve {{ B_1 }} conclut {{ \exists x (p(x) \implies orall y p(y)) }}.
  • Dans la seconde branche ($ eg orall y p(y){{ ), la preuve }}B_3{{ conclut }}\exists x (p(x) \implies orall y p(y))$.

Par {{ \lor E }}, on conclut sans aucune hypothèse résiduelle : {{ dash \exists x (p(x) \implies orall y p(y)) }}. Preuve complète achevée !
